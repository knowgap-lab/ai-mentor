# Пакет 1 проверки каталога готов

**Сделано.** Пакет `content/catalog_ci/` проверяет каталог по правилам schema.md: схема файлов (по `catalog.schema.json`), идентификаторы, дубли, ссылки, предпосылки и циклы, часы уровней, формат ответа, появления, временные ключи. 13 кодов проблем, режимы `pr` и `main`, команда `python -m catalog_ci check <каталог> [--mode pr|main] [--json]`. Тесты (42) написаны отдельной сессией по брифу `briefs/catalog-ci-1.md` и заморожены до кода; код написан другой сессией, тесты не менялись. `tools/check.sh` теперь запускает и эти тесты.

**Проверка.** Я сам запустил все 42 теста: зелёные. Дополнительно проверил на мутациях демо-каталога вне тестов: skill с появлением, несуществующие типы и элементы, `minutes=0`, лишнее поле в блоке дают ожидаемые коды. Запрещённых вызовов (сеть, git, subprocess) в коде нет, зависимости только `jsonschema` и `pyyaml`.

**Оговорка.** Задание Codex на этапе кода закончилось ошибкой `timeout` на очистке (572 с), но код был записан полностью; приёмка записана с `accept-failed-transport` после моей проверки.
