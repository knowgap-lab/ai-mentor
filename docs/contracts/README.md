# Контракты

> Единственный источник схем для Go, Python и TypeScript (D97). Типы генерируются, ручные дубли запрещены; совпадение проверяет CI.

| Файл | Формат | Что описывает | Решения |
|---|---|---|---|
| `core-api.yaml` | OpenAPI | публичный HTTP-API `core` для `web` | D97, D121, D166 |
| `internal-api.yaml` | OpenAPI | внутренний API `core`: загрузка каталога, перепроверка, предложения агента | D123, D158, D170, D173 |
| `catalog.schema.json` | JSON Schema | формат каталога в git (вход загрузчика и выход скилла) | D114–D116, D149–D151, D160 |
| `events.schema.json` | JSON Schema | события журнала (с `schema_version`) | D87, D175, D180 |
| `queue.schema.json` | JSON Schema | задания очереди и повод для агента | D156, D162 |
| `compute-views.schema.json` | JSON Schema | представления `compute.*`, которые читает Go | D157 |
| `subject-package.schema.json` | JSON Schema | правила ответа, баллов и нормализации пакета предмета | D103, D185 |

Миграции базы лежат в одном месте и в одном порядке для всех схем (D97, D127).

## Проверка

Примеры лежат в `fixtures/*.cases.yaml`: допустимые и недопустимые документы с ожидаемым результатом. Запуск:

```bash
tools/check.sh        # контракты и все примеры
```

`tools/check.sh` запускает проверку контрактов (`docs/contracts/check.py`) и примеров (`tools/examples/`). Нужны `jsonschema`, `pyyaml`, `openapi-spec-validator`. Схема выражает форму документа; связи между документами (висячие ссылки, циклы, порядок часов, уникальность id) проверяет CI по [schema.md](../catalog/schema.md) и [variants.md](../catalog/variants.md).

## CI и генерация типов

- **Проверки.** `.github/workflows/docs-check.yml` запускает `tools/check.sh` на каждом PR и на `main`. Зависимости — `tools/requirements.txt`. Работа воспроизведена локально в чистом окружении только из этого файла.
- **Генерация типов (не настроена).** По D97 типы для Go, Python и TypeScript генерируются из этих файлов и не пишутся вручную, а CI проверяет, что сгенерированный код совпадает с контрактами. Генераторы выбирает напарник вместе со структурой Go-проекта. Кандидаты: `oapi-codegen` (Go, из OpenAPI), `datamodel-code-generator` (Python, из OpenAPI и JSON Schema), `openapi-typescript` и `json-schema-to-typescript` (TypeScript). Они не запускались: окружение сессии запретило скачивание внешних генераторов, поэтому версии и флаги не проверены.
- **Решение для напарника.** Хранить сгенерированный код в репозитории (CI сверяет перегенерацию с закоммиченным) или генерировать в сборке. D97 говорит о проверке совпадения, то есть о первом варианте.
