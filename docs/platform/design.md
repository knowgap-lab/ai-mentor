| Поле | Значение |

## 1. Назначение

Один вид для всех экранов [web.md](web.md): экраны собираются из темы и общих компонентов, а не придумывают свой стиль. Тогда экраны, написанные разными исполнителями, выглядят как одно приложение.

## 2. Вход и выход

| Вход | Откуда | Контракт |
|---|---|---|
| Состав экранов и тексты | [web.md](web.md) | — |

| Выход | Куда | Контракт |
|---|---|---|
| Тема Mantine | `web/src/design/theme.ts` | — |
| Статические CSS-переменные темы | `web/src/design/theme.css` (генерируется `npm run theme:css`) | — |
| Общие компоненты | `web/src/ui/` | — |
| Образец | маршрут `/design` (только при `vite dev`) | — |

## 3. Характер

Тетрадь и ручка. Ученик решает задачи с телефона, репетитор проверяет. Основной цвет — синие чернила, ошибки отмечены красной ручкой, лист задачи — тетрадь в клетку. Остальное спокойно: светлый фон, графитовый текст, без украшений. Смелость ровно одна — клетка на листе задачи.

## 4. Правила

### Цвет и тема

- **DS-R1.** Цвета задаются только в `web/src/design/`. В остальном коде `web/src` нет шестнадцатеричных цветов, `rgb(`, `hsl(` и именованных цветов CSS; компоненты используют цвета темы (`ink`, `gray`, `green`, `red`, `yellow`) или CSS-переменные `--am-*` и `--mantine-*`.
- **DS-R2.** Основной цвет — `ink`, оттенок 7 (`#2F4AA8`). Текст — `gray.9`, второстепенный текст — `gray.7`, фон страницы — `gray.0`, лист — белый.
- **DS-R3.** Состояния задачи и выдачи показываются только компонентом `StatusBadge` с фиксированными цветом и подписью (таблица ниже). Цвет никогда не единственный признак: у каждого состояния есть подпись.
- **DS-R4.** Контраст текста к фону не меньше 4.5:1, крупного текста и значков — не меньше 3:1.
- **DS-R5.** `web/src/design/theme.css` всегда совпадает с выводом `npm run theme:css`; руками не правится. Mantine не вставляет переменные во время работы (`withCssVariables={false}`), потому что CSP запрещает встроенные стили (D167).

| Состояние | Подпись | Цвет |
|---|---|---|
| `not_answered` | не отвечено | `gray` |
| `correct` | верно | `green` |
| `partial` | частично | `yellow` |
| `wrong` | неверно | `red` |
| `closed` | закрыто | `gray`, тёмный |
| `submitted` | сдано | `ink` |
| `awaiting_review` | ждёт просмотра | `ink`, контур |
| `overdue` | просрочено | `red`, контур |

### Текст

- **DS-R6.** Шрифт интерфейса — Golos Text (переменный, OFL), подключается из пакета `@fontsource-variable/golos-text`, без внешних запросов. Формулы — шрифты KaTeX.
- **DS-R7.** Основной размер 16 px (поля ввода не меньше 16 px, иначе телефон увеличивает страницу); шкала: 13, 14, 16, 18, 20 px; заголовки 24, 20, 18 px; межстрочный интервал текста 1.5. Числа баллов и сроков — табличными цифрами.

### Размеры и сетка

- **DS-R8.** Любой нажимаемый элемент не меньше 44 × 44 px (WB-R1). Кнопка по умолчанию — размер `md` высотой 44 px.
- **DS-R9.** Отступы — только шкала темы: 4, 8, 12, 16, 24, 32 px. Скругление по умолчанию 10 px, у мелких элементов 6 px.
- **DS-R10.** Ширина содержимого не больше 640 px, по центру; на 360 px нет горизонтальной прокрутки (WB-R1). Главное действие экрана — в нижней панели `ActionBar`, доступной большим пальцем.

### Компоненты

- **DS-R11.** Экраны собираются из `web/src/ui/` и компонентов Mantine. Новый общий вид элемента добавляется в `web/src/ui/` с тестом, а не стилями внутри экрана.

| Компонент | Назначение |
|---|---|
| `Screen` | каркас экрана: заголовок, кнопка «назад», содержимое шириной до 640 px, место под `ActionBar` |
| `ListRow` | строка списка (ученик, выдача, задача, урок): заголовок, подпись, справа `StatusBadge` или значение; вся строка — одна ссылка |
| `StatusBadge` | состояние по таблице DS-R3 |
| `TaskSheet` | лист задачи в клетку: условие, формулы, поле ответа |
| `ActionBar` | нижняя панель с одним главным действием и, при нужде, одним второстепенным |
