# Импорт результатов РТ

| Поле | Значение |
|---|---|
| Область | platform |
| Владелец (утверждает) | напарник (D144); разметку вариантов РТ утверждает пользователь |
| Реализуют | core (Go) |
| Выпуск | 2 и позже (в выпуске 1 нет, D88) |
| Решения | D11, D45, D87, D88, D122, D138, D182, D253, D254 |
| Статус | на ревью |

## 1. Назначение

Репетиционное тестирование (РТ) ученик проходит вне платформы. Модуль вносит его результаты в журнал попыток, чтобы они учитывались как пробник: вес такой же, одна попытка на задачу (D45, глоссарий «пробник»). Модуль не выдаёт РТ ученику и не показывает ему задания: ответы вводит репетитор по бланку ученика.

## 2. Вход и выход

| Вход | Откуда | Контракт |
|---|---|---|
| Тест РТ с размеченными задачами (тип, сложность, ключ) | `catalog.*`, раздел `tests/` | `catalog.schema.json` |
| Ответы ученика по номерам задач, сессия и тест | форма репетитора | `core-api.yaml` |

| Выход | Куда | Контракт |
|---|---|---|
| События `attempt_recorded` с источником `rt` и вердикты | журнал ([attempts](attempts.md)) | `events.schema.json` |
| Наблюдения | журнал (AT-R20) | `events.schema.json` |
| Задание пересчёта (факт «импортированные РТ») | очередь ([queue](queue.md), QU-R2) | `queue.schema.json` |

## 3. Правила

### Предпосылка: разметка

- **RI-R1.** Разметка варианта РТ (задача → тип и сложность) — общая работа над каталогом, делается один раз на вариант РТ двумя ИИ с разбором расхождений репетитором (D88). Вариант РТ без разметки импортировать нельзя: `422 test_not_marked`.
- **RI-R2.** Ключ и опции берутся из каталога; ответ ученика проверяется так же, как в [answer-check](answer-check.md) по формату задачи.

### Ввод

- **RI-R3.** Репетитор открывает форму для ученика, сессии и теста; форма содержит поле на каждую задачу (до 30) в формате ответа этой задачи (D88). Загрузка PDF с предзаполнением и подтверждением репетитором — позже и в этот модуль выпуска 2 не входит.
- **RI-R4.** Репетитор может внести только ответы своих учеников (AU-R4); иначе `403 forbidden`.
- **RI-R5.** Ключ импорта — ученик + сессия + тест; повторный импорт тех же ключа — идемпотентное обновление (upsert), а не дубль (D122). Обновлённый ответ даёт новый вердикт и новую ревизию наблюдения; прежние записи остаются (журнал только пополняется, AT-R1).
- **RI-R6.** Пустой ответ означает «не отвечал». Для такой задачи записывается попытка с отметкой «пропуск» и нулевым баллом (D253).

### Запись

- **RI-R7.** Для каждой задачи с ответом создаётся одна попытка с источником `rt`, местом `home` и баллами по правилам оценки типа (AT-R8, D182). Попытка не связана с выдачей: импорт РТ — единственное исключение из AT-R10.
- **RI-R8.** Неверный ответ сопоставляется с ловушками типа, как при обычной проверке (D11).
- **RI-R9.** После записи вычисляется наблюдение по каждой задаче (AT-R20) с весом пробника.
- **RI-R10.** Импорт целиком атомарен: все попытки теста записываются в одной транзакции или не записывается ни одна. В той же транзакции ставится задание пересчёта (QU-R1, QU-R2) (D254).
- **RI-R11.** Результат, исправленный репетитором по спору, идёт через ручной вердикт (D138), а не через повторный импорт.

## 4. Таблицы примеров

Файл `rt-import.examples.yaml` (D133). Ключевые строки:

| Правило | Ситуация | Ожидаемый результат |
|---|---|---|
| RI-R1 | тест РТ без разметки | `422 test_not_marked` |
| RI-R3 | форма теста из 30 задач | 30 полей по форматам |
| RI-R4 | чужой ученик | `403 forbidden` |
| RI-R5 | повторный импорт с тем же ключом, ответ изменён | новая ревизия наблюдения, старая запись цела |
| RI-R5 | повтор без изменений | ничего не добавлено |
| RI-R6 | задача без ответа | попытка «пропуск», 0 баллов |
| RI-R7 | верный ответ части В | попытка `rt`, место `home`, полный балл |
| RI-R8 | неверный ответ части А, совпал с ловушкой | причина по ловушке записана |
| RI-R10 | ошибка при записи 17-й задачи | не записана ни одна, задания пересчёта нет |
| RI-R10 | успешный импорт | задание `model` создано в той же транзакции |

## 5. Ошибки

| Ситуация | Ответ | Код |
|---|---|---|
| Тест без разметки | 422 | `test_not_marked` |
| Задача не принадлежит тесту | 422 | `task_unknown` |
| Ответ не по формату | 422 | `malformed` |
| Чужой ученик или нет прав | 403 | `forbidden` |

Открытых вопросов нет. По умолчанию, для ревью напарника: D253 (пропуск записывается как попытка с нулём), D254 (импорт атомарен и ставит задание в той же транзакции).
