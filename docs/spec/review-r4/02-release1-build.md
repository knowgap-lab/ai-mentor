# R4-02 Можно ли собрать выпуск 1

1. **[critical] Импорт плана: в статичном плане нет данных, совпадающих с календарём и id каталога** (D100, D105, D106, D114, D120). В PLAN.md и frontmatter есть только понедельник недели и коды M01; нет дня недели, времени, длительности и сопоставления с постоянными id; неясно, разовый ли импорт. Рекомендация: разовый импорт из frontmatter; расписание задаётся правилом D105; M01 → id темы через таблицу в пакете каталога.
2. **[high] Бот может не иметь права писать ученику после входа через Telegram** (D86, D93, D94, D102, D108). Рекомендация: виджет запрашивает request_access=write; если сообщение не дошло, репетитор видит «не доставлено»; ссылка на ДЗ остаётся в кабинете. Привязка Telegram самого репетитора не определена.
3. **[high] Не сказано, где запускается загрузчик и как он попадает в staging и prod** (D98, D118, D120, D127, D128, D130). Рекомендация: CI собирает подписанный артефакт каталога; на сервере его забирает одноразовый контейнер loader (по образцу migrate) — сначала staging, потом prod по команде.
4. **[high] Модель ДЗ в L-файлах (пн–сб, блоки A/B/C, порог 80 %, повторение) против алгоритма D107** (D39, D96, D100, D107). Рекомендация: только D107, темы review добавляются четвёртым приоритетом; минуты на вариант ставит скилл, бюджет ученика — репетитор.
5. **[high] Уроки-диагностики и уроки с тестами в статичном плане не имеют смысла в выпуске 1** (D85, D95, D100, D104, D137). Рекомендация: импортировать как обычные уроки; бланки печатать в PDF, ответы не вносить.
6. **[medium] Условные шаги L-файла и задачи, решённые на уроке** (D82, D96, D101, D120, D137). Рекомендация: скилл разворачивает условия в линейный порядок; у каждого варианта есть ссылка на блок теории; варианты, использованные на уроке, считаются показанными, но попытками не записываются.
7. **[medium] В процессе согласия нет даты рождения, канала доставки и владельца текста** (D93, D108, D109, D110, D139). Рекомендация: репетитор вводит дату рождения (это ПДн); текст согласия лежит в репозитории с версией; ссылку для родителя репетитор копирует из кабинета.
8. **[medium] Не определены действия репетитора при просмотре собранного ДЗ** (D100, D101, D102, D107, D117). Рекомендация: убрать или добавить вариант из пула, изменить срок, выдать; после выдачи — только отозвать целиком до первого ответа.
