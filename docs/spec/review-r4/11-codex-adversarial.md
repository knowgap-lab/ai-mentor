# R4-11 Враждебный обзор (Codex, gpt-5.6-terra)

1. **[critical] Выпуск 1 превратился в еженедельную фабрику контента, а не в MVP** (D83, D85, D98, D100, D101, D119). Каждый урок требует скилл → PR → CI → ревью и 5–10 вариантов на тип; одно расхождение ключа блокирует поставку. Рекомендация Codex: в выпуске 1 статичные материалы и вручную выбранные готовые задачи; библиотеку, PR на каждый урок и автосборку ДЗ отложить.
2. **[critical] Постоянный каталог строится до выхода спецификации 2027** (D1, D2, D85, D100, D101, D103, D114, D115). Рекомендация: до спецификации 2027 выпуск 1 — пилотное подмножество с явной версией правил 2026, постоянство каталога не обещать.
3. **[critical] Бэкапы не убирают единую точку отказа — один сервер** (D33, D91, D111, D128–D130). Рекомендация Codex: управляемые сервисы с проверяемым RTO; альтернатива — принять RTO 24–48 ч и раз в квартал репетировать восстановление на новом хосте.
4. **[high] У выданного и отредактированного ДЗ нет неизменяемого факта** (D35, D100, D104, D111, D117, D120). Рекомендация: выдача, одобрение, отзыв и Submit — неизменяемые события core с полным снимком вариантов и правил.
5. **[high] Ревью упирается в одного репетитора** (D74, D83, D98, D99, D100, D119, D131). Рекомендация: за репетитором остаются только учебный контент и юридические тексты; инженерные PR второй участник сливает сам по CI.
6. **[high] Go и Python делят семантику, а не только контракты** (D75, D76, D80, D90, D92, D97, D99, D133). Рекомендация: Go пишет версионированное каноническое событие-наблюдение, Python его только потребляет; сквозные replay-векторы.
7. **[high] Замороженные тесты могут навсегда закрепить ошибку ИИ** (D72, D99, D103, D131–D134). Рекомендация: небольшой набор, вручную подтверждённый по официальным правилам и реальным случаям репетитора, — независимый приёмочный black-box, который имеет право опровергать таблицы.
