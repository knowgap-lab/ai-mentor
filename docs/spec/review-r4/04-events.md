# R4-04 Каталог событий и очередей

Около 29 событий: факты журнала, ограничения, задания очереди, outbox и алерты. У каждого указаны отправитель, получатель и выпуск. Полный список — в отчёте агента. Выпуск не определён у `checkpoint_test_finished`, `mock_exam_finished` и `manual_verdict`. Не указан отправитель у алерта задержки и у служебных алертов.

## Пробелы

1. **[high] Факты выпуска 1 копятся без потребителя, правила дозаливки нет** (D126, D85, D87, D89, D95). Рекомендация: при первом запуске worker проигрывает журнал каждого ученика с нуля; то же самое проверяет ночная проверка восстановления.
2. **[high] В выпуске 2 факты запускают пересчёт «модель + план», который ничего не делает** (D87, D95, D81, D85). Рекомендация: в выпуске 2 простое правило «провал типа → повтор»; в выпуске 3 его заменяет модель.
3. **[medium] Часть событий журнала не отнесена ни к фактам, ни к ограничениям** (D87, D104, D105, D106, D109, D138, D95). Рекомендация: ручной вердикт и ручная отметка типа — факты; отмена урока и расписание — ограничения; архив отменяет задания ученика.
4. **[medium] У события «новая версия каталога» нет разрешённого писателя в core.*** (D87, D92, D118, D124, D123). Рекомендация: загрузчик вызывает внутренний API Go; Go пишет одно глобальное событие и задания с ключом «ученик + catalog_version».
5. **[medium] Таблица очереди нарушает правило одного писателя** (D92, D33, D91, D125, D14). Рекомендация: отдельная схема queue.*; вставка только через функцию; аренду и статус меняет только worker; права проверяет CI.
6. **[medium] У outbox нет ключа против дублей, порядка и правила для ПДн** (D102, D109, D121, D139). Рекомендация: ключ = тип + id события + получатель; Telegram id берётся в момент отправки; при архиве или обезличивании сообщение отменяется.
7. **[medium] Перепроверка меняет баллы, но не создаёт уведомления и события** (D123, D126, D117, D102, D87). Рекомендация: одно событие на ученика и correction_id; одно сообщение репетитору со списком изменённых ДЗ.
8. **[low] Не определены отправители и каналы алертов и предупреждений** (D91, D129, D125, D101, D106, D102). Рекомендация: периодическая проверка в Go шлёт алерты через outbox; предупреждения — плашка в кабинете плюс Telegram репетитору.
