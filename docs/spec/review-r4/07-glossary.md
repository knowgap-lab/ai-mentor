# R4-07 Применение глоссария (D112)

Ошибка в задании проверяющему: глоссарий — это **D112**, а не D125 (D125 — аренда заданий очереди). Проверка шла по D112.
Важно: текст D44–D67 есть только в превью и в redteam-round2, его нет в `decisions-D1-D71.md`. При сборке журнала их нужно извлечь.

## Решения, которые нужно перечитать через D112 (главное)

- «вариант» = **тест** в D3 и D88; = **опция** в D11.
- «задача» = **вариант** в D3, D9, D15, D21, D39 и S3; = **задание очереди** в D33 и S4.
- «блок» = **этап урока** в D9, P7 и A5; = **серия** в P2; финальные блоки пробников = **фаза пробников**.
- «элемент» = **часть ответа** в D23; в D113 — элемент каталога с цитатой.
- «уровень» в D43 — сложность примера, а не уровень освоения.
- «пакет» перегружен: пакет оптимизатора (D68), пакет предмета (A1), пакет каталога (D41, D95), пакет контекста агента (D15).
- «сессия» перегружена: экзаменационная сессия, сеанс входа (D86 и др.), сессия агента (D72), «тест» как программный тест (D30, D131, D134).
- В D82 и D96 непонятно, на что указывает отметка теории: на этап урока или на блок библиотеки. Снимок урока D120 должен хранить и этапы, и варианты в них.

## Термины, которых не хватает (предложенные определения)

- **подвариант**: структурная разновидность типа (что дано, что найти), постоянный id; варианты внутри отличаются только числами.
- **ловушка**: заранее известный неверный ответ с id причины.
- **уровень освоения**: «база» или «автоматизм» по типу; это не сложность блока.
- **пакет предмета**: данные предмета поверх ядра (каталог, форматы, баллы, нормализация, guess/slip).
- **профиль**: описание программы для составителя (источники и их роли).
- **срез**: контрольная выдача по расписанию из резерва, одна попытка, полный вес.
- **пробник**: полный тест в формате ЦТ в финальной фазе; РТ имеет тот же вес.
- **сессия**: экзаменационная сессия (год + этап). Вход на сайт — «сеанс входа», работа ИИ — «сессия агента».
- **выдача**: набор вариантов, выданный ученику; вид выдачи (ДЗ, урок, срез, пробник, диагностика) задаёт попытки, показ и вес.
- **шаблон**: параметрическое описание подварианта, которое CI разворачивает в варианты.
- **страховка**: типы с частотой 0, отдельная квота часов, только «база».
- **попытка**: неизменяемая запись журнала; вердикт вычисляется.
