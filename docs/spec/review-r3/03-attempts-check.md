# R3-03 Журнал попыток и проверка ответов

1. **[high] Жизненный цикл попытки: проверка задачи vs «Сдать»; две попытки В vs показ ответа** (D11, D12, D17, D45, D81, D85). Рекомендация: каждый ответ сразу проверяется и становится неизменяемой попыткой; после первой неверной в В — только «неверно», ответ и решение — после второй; «Сдать» закрывает ДЗ и запускает пересчёт; единица лимита — задача в выдаче.
2. **[high] Нет схемы баллов для В1/В2 и А6/А10 с несколькими верными** (D23, D80, D51, P1). Рекомендация: копируем официальную шкалу ЦТ по формату и фиксируем таблицей примеров в пакете ЦТ; нормализация ввода (пробелы, разделители, пустой ответ) — тоже таблицей.
3. **[high] Попытка → наблюдение для модели знаний** (D45, D51, D81, D87, D88, P2, A4). Рекомендация: доля от максимума баллов (0..1) с первой и итоговой попытки, вес по таблице источников; пропуск в сданном ДЗ = 0 с меткой «пропуск» и пониженным весом.
4. **[medium] Споры и перепроверка в неизменяемом журнале** (D22, D35, D57, D87, A6, S6). Рекомендация: спор решает репетитор — исправить ключ (PR → CI → перепроверка) или создать событие «ручной вердикт»; вердикт всегда вычисляется из журнала; если первая попытка стала верной, вторая игнорируется.
5. **[medium] Флаг «дома»/«на уроке»: значения, кто ставит, влияние** (D27, D41, D45, D88, P2). Рекомендация: два поля — source (ДЗ, урок, срез, пробник, диагностика, РТ) задаёт вес; place ставит система, только для анализа.
