# R3-07 ИИ-агент

1. **[critical] Не заданы параметры, ограничения и срок действия allowed_actions; можно ли трогать замороженный урок** (D5, D9, D15, D24, D79, D92, D97, P8, A7). Рекомендация: строгая JSON-схема на каждое действие, только существующие id; замороженные уроки не трогать; срок — по умолчанию 4 урока.
2. **[high] Ожидающие предложения устаревают при каждом пересчёте; жизненный цикл, карточка, автоприменение** (D14, D24, D79, D87, D89, D92). Рекомендация: Go перепроверяет предложение на новой версии плана — если ещё применимо, оставляет с пометкой «план обновлён», иначе expired с причиной; карточка: повод, разница, объяснение, одобрить/отклонить; автоприменение включает только репетитор.
3. **[high] Таймаут, повторы, невалидный вывод, переход облако ↔ локальная модель** (D14, D28, D33, D36, D91, S7). Рекомендация: 60 с; один повтор при ошибке сети или невалидном JSON, один повтор с причиной отказа Go; потом failed без расхода суточного лимита; при сбое облака или исчерпании лимита — локальная модель.
4. **[medium] Пороги поводов, кто их обнаруживает, как выбираются ~10 типов** (D14, D15, D81, D87, D91, S7). Рекомендация: recalc проверяет поводы после пересчёта (падение p ≥ 0,15 или p < 0,6; нижняя граница прогноза ниже цели); «не понял» и «не успели» — события из Go; в пакет — типы 3 ближайших уроков и типы с наибольшим падением, не больше 10.
5. **[medium] Журнал промптов, хранение, проверка исходящего запроса на ПДн** (D17, D84, D92, D94, D98, S7). Рекомендация: полный журнал в compute.agent_calls на 180 дней; фильтр по схеме полей перед отправкой, нарушение блокирует вызов; журнал виден в кабинете.
