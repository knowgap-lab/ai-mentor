# R3-04 Модель знаний

1. **[critical] Нет формального определения «база» и «автоматизм», нет связи с правилом D46** (D71, D46, D44, D6, D90). Рекомендация: база = P ≥ 0,7 и выполнено D46; автоматизм = P ≥ 0,92 плюс два верных ответа с первой попытки в срезах или пробниках; без учёта времени.
2. **[high] У забывания нет формулы, единиц и значения по умолчанию** (D6, D44, D25). Рекомендация: экспоненциальное затухание по календарным дням; стартовый период полураспада общий, потом подгоняется под ученика; уровень снимается только ниже порога минус гистерезис.
3. **[high] У весов D45 нет чисел и механизма обновления** (D45, D44, D88, D27, D41). Рекомендация: вес — показатель степени правдоподобия; срез, пробник, РТ, смешанный блок и диагностика = 1,0; однотипный блок А в ДЗ = 0,5; попытка на уроке = 0,5; таблица хранится в пакете предмета.
4. **[high] Засев из диагностики и судьба ручных отметок после выпуска 3** (D95, D90, D41, D46, D78, D71). Рекомендация: «известно» = порог базы, «не освоено» = 0,1, «не проверено» = из предпосылок, но не выше 0,5; отметка репетитора — событие журнала, которое ставит P на порог уровня, дальше P меняют попытки, репетитору приходит уведомление.
5. **[medium] Пересчёт: полный повтор журнала или инкрементальный; запускает ли смена параметров пересчёт** (D35, D89, D87, D44, D99). Рекомендация: при каждом пересчёте журнал повторяется с нуля по версии пакета предмета; смена параметров или версии каталога пересчитывает модель, а не только план (поправка к D87).
