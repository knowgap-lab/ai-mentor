# R3-01 Схема каталога и версии

1. **[high] Открытое ДЗ при новой версии каталога** (D21, D22, D57, D87, D81, D96, A6). Что происходит с выданным, но не сданным ДЗ, если вариант устарел, получил исправленный ключ или был разделён/слит? Рекомендация: ДЗ остаётся на версии выдачи; исправленный ключ применяется через перепроверку D22.
2. **[high] Формат карты переноса и судьба прошлых попыток** (D21, D70, D71, D95, D35). Как попытки и отметки репетитора переходят на новые id при делении/слиянии? Рекомендация: явная карта до уровня подвариантов; без привязки — оценка-наследство с потолком.
3. **[high] Схема id: уровни, формат, повторное использование** (D21, D43, D53, D70, D85, I1, A1). Рекомендация: постоянный id на каждом уровне (тема, элемент, тип, подвариант, вариант, блок), префикс пакета предмета + непрозрачный код, повторно никогда.
4. **[medium] Что такое версия каталога; какие правки сохраняют id** (D57, S3, A6, D21, D22, D27, D98). Рекомендация: версия = merge-коммит; опечатки сохраняют id; смена чисел/условия/ответа — новый вариант; исправление ошибочного ключа — тот же id + перепроверка.
5. **[medium] Кратность иерархии и подвариант как сущность** (D70, D37, D39, D27, D3, D68). Рекомендация: у типа один основной элемент, остальные — предпосылки; подвариант — сущность с id; резерв для срезов — флаг на варианте.
