# R3-02 Шаблоны и генерация вариантов

1. **[high] Исчерпание пула, размер резерва, что считается «виденным»** (D27, D37, D39, D41, D53, D61, D88). Рекомендация: резерв — фиксированная доля пула, общая; CI блокирует PR при пуле ниже минимума; при исчерпании — предупреждение репетитору; «виденным» считается любой показ (урок, ДЗ, PDF, срез).
2. **[high] Правка шаблона и постоянные id** (D22, D53, D57, A6). Рекомендация: детерминированная генерация (seed = id шаблона + номер); правка только ключа сохраняет id + перепроверка; правка условия или чисел — новые id, старые снимаются с выдачи, но остаются в истории.
3. **[high] Независимая проверка ключа: что считается независимым, блокирует ли CI** (D53, D56, S2, D75, D80, D98, D99). Рекомендация: подстановка, иначе второй решатель из отдельной сессии; точная арифметика (Fraction/SymPy только в CI); готовые экземпляры — решение вторым ИИ; любое расхождение блокирует PR.
4. **[medium] Конкретные task_rules однозначного ответа** (D23, D27, D64, D80). Рекомендация: В3–В20 — точное целое, знак и разрядность по бланку, масштаб только фразой из шаблона-списка; В1 — биекция; В2 — цифры по возрастанию без повторов.
5. **[medium] Дистракторы части А в шаблонах** (D11, D23, D27, D46, D80). Рекомендация: дистрактор = формула ловушки с id причины; CI проверяет, что 5 вариантов различны, ни один дистрактор не равен ключу, число верных задано явно (А6/А10).

Заметка проверяющего: D53, D56 и D64 — в превью только однострочные; полный текст — в redteam-round2.md (A6, S2).
