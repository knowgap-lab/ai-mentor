# R3-06 План, горизонт, уроки

1. **[critical] Нет источника календаря уроков** (D8, D15, D42, D87). Рекомендация: репетитор задаёт правило (дни, время, длительность), система разворачивает его в даты до экзамена, отдельные уроки можно править.
2. **[critical] Пропущенный, отменённый или перенесённый урок** (D8, D9, D81, D87, D96). Рекомендация: отмена — это ограничение: содержимое переезжает на следующую дату, замороженные уроки сдвигаются, пересчитывается только план, ДЗ не выдаётся.
3. **[high] Вместимость блоков урока и переполнение при переносе** (D9, D49, D68, D96, A7). Рекомендация: у каждого блока есть оценка в минутах; урок = длительность минус разбор ошибок; лишнее с конца уходит в первый незамороженный урок.
4. **[high] Объём ДЗ, срок, отметки не поставлены, прошлое ДЗ не сдано** (D39, D42, D81, D96, D37). Рекомендация: объём ≤ бюджета часов между уроками; приоритет: недорешённое → закрепление → новое; срок — следующий урок; если отметок нет N часов, приходит напоминание.
5. **[medium] Плановые срезы: формат и место в замороженном горизонте** (D48, D27, D12, D87, P6). Рекомендация: срез — отдельный блок урока; его состав фиксируется, когда урок замораживается.
