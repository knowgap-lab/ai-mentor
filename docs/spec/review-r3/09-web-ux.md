# R3-09 Интерфейс выпуска 1

1. **[critical] Без планировщика непонятно, кто собирает урок и ДЗ** (D85, D96, D39, D82, D9, D37, D40, D95). Рекомендация: урок репетитор собирает вручную из блоков; ДЗ после двух отметок система собирает автоматически по D96/D39, репетитор просматривает, при необходимости меняет и выдаёт.
2. **[high] Когда сохраняется ответ; плохая сеть** (D10, D11, D17, D45, D80, D81, D22). Рекомендация: каждый ответ сразу уходит на сервер с ключом идемпотентности; без сети он помечается «не отправлено» и ждёт; повторная отправка дубля не создаёт.
3. **[high] Что делает «Сдать» и что после этого видит ученик** (D81, D87, D85, D12, D11, D22). Рекомендация: сдать можно с пропусками после подтверждения; сдача окончательная; ученику показывается итог, решения и список «разобрать на уроке» (кнопка «не понял»); репетитор получает уведомление.
4. **[high] Формат содержимого блоков: формулы, виджеты, рисунки, PDF** (D43, D85, D65, D40, D53, D97). Рекомендация: Markdown + LaTeX (KaTeX); виджет = {widget, params} по JSON Schema; рисунки SVG; PDF рендерится на сервере, у каждого виджета есть статичная печатная версия.
5. **[medium] Ввод ответа на телефоне для каждого формата ЦТ** (D23, D11, D40, D51, D80, D43). Рекомендация: отдельный компонент на каждый формат; синтаксис проверяется до отправки, неверный по форме ввод не считается попыткой.
