## Порядок написания

1. `schema.md` — первой (от неё зависит всё).
2. `answer-rules.md` — нужна проверке ответов.
3. `variants.md`, `loader.md`, `plan-import.md`.
4. `composer.md` — когда понятен формат, который он должен выдавать.
