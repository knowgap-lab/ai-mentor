# Конспект урока

| Поле | Значение |
|---|---|
| Область | personalization |
| Владелец (утверждает) | пользователь (содержание), напарник (реализация, D144) |
| Реализуют | core (Go) — состав и PDF; web — вывод |
| Выпуск | 1 |
| Решения | D40, D43, D120, D135, D140, D167, D193, D220, D230, D248, D265, D266 |

## 1. Назначение

Показывает ученику и репетитору теорию урока: конспект собирается из блоков библиотеки по снимку урока и выводится на странице или в PDF. Текст блоков общий для всех учеников; ИИ для ученика текст не пишет (D43).

## 2. Вход и выход

| Вход | Откуда | Контракт |
|---|---|---|
| Снимок урока: блоки и их порядок, версия каталога | [lessons](lessons.md) (LS-R10) | `core-api.yaml` |
| Тексты блоков, виджеты, рисунки | `catalog.*` | `catalog.schema.json` |
| Файл урока (запасной путь) | репозиторий каталога | — |

| Выход | Куда | Контракт |
|---|---|---|
| Страница конспекта | [web](../platform/web.md) | `core-api.yaml` |
| PDF конспекта | пользователь | — |

## 3. Правила

### Состав

- **CN-R1.** Конспект урока — блоки снимка урока в порядке этапов; блок берётся в версии каталога, на которой сделан снимок (D120, LD-R7).
- **CN-R2.** В конспект выводятся блоки видов `theory`, `rule`, `summary`, `worked_example`, `typical_error`, `widget`. Блоки вида `flashcard` в выпуске 1 не выводятся: карточек в ДЗ нет (D220, D230).
- **CN-R3.** Блоки, перенесённые с прошлого урока, стоят в начале конспекта отдельным разделом «Перенесено с урока N» (LS-R14).
- **CN-R4.** В выпуске 1 состав конспекта одинаков для всех учеников. Персональный состав (повторение слабых предпосылок, уровень примеров, свои типичные ошибки первыми) появится с моделью знаний (D43, [knowledge-model](knowledge-model.md)).
- **CN-R5.** Платформа не генерирует текст конспекта для ученика; пояснения — работа репетитора (D43).
- **CN-R6.** Варианты практики урока в конспект не входят; они показываются как задачи (D193).

### Вывод

- **CN-R7.** Текст блока — Markdown с формулами LaTeX через KaTeX с `trust: false`; сырой HTML не выводится (D135, D167).
- **CN-R8.** Виджет выводится компонентом общей библиотеки по паре `{widget, params}`; параметры проверяются по JSON Schema виджета. У каждого виджета есть статичная версия для печати (D43, D135).
- **CN-R9.** Рисунки — SVG, очищенные от опасных элементов; страница работает под строгой политикой CSP без встроенных скриптов (D167).

### PDF

- **CN-R10.** PDF формирует сервер из тех же блоков и той же вёрстки; виджеты выводятся статичными версиями (D135, D248). Печать — сервисом Gotenberg во внутренней сети, повторяемость — хранением первого PDF снимка (D301).
- **CN-R11.** В PDF нет ключей, решений и сведений об ученике (имени, Telegram id); в заголовке — предмет, номер урока и тема (D17, D168).
- **CN-R12.** Один и тот же снимок урока даёт тот же PDF (детерминированная сборка).

### Запасной путь и доступ

- **CN-R13.** Если блоки урока не готовы, урок показывается **только репетитору** по файлу урока в PDF или HTML (ученик не видит ничего, пока блоки не готовы), а ДЗ репетитор подбирает вручную (D140, D266, LS-R13). Урок не блокируется содержимым.
- **CN-R14a.** Ученик видит конспект урока только после того, как урок проведён (`held`): блоки до последнего объяснённого блока по отметке теории и перенесённые с прошлого урока (LS-R16). Репетитор видит конспект целиком до урока (D265, D38).
- **CN-R14.** Ученик видит конспект только своих уроков, репетитор — уроков своих учеников; иначе `403` (AU-R4).

## 4. Таблицы примеров

Файл `conspect.examples.yaml` (D133). Ключевые строки:

| Правило | Ситуация | Ожидаемый результат |
|---|---|---|
| CN-R1 | снимок на версии 6, сейчас версия 8 | блоки версии 6 |
| CN-R2 | блок `flashcard` в снимке | не выводится |
| CN-R3 | с прошлого урока перенесён блок | раздел «Перенесено с урока N» в начале |

| CN-R7 | формула `\frac{a}{b}` | выведена KaTeX |
| CN-R7 | блок содержит `<script>` | не выводится (CI отклоняет при загрузке) |
| CN-R8 | виджет с параметрами не по схеме | отклонён при загрузке |

| CN-R11 | PDF конспекта | без ключей, решений и имени ученика |
| CN-R12 | два запроса PDF одного снимка | одинаковое содержимое |
| CN-R13 | блоков урока нет | файл урока виден репетитору, ученику ничего не показано |
| CN-R14 | ученик открывает чужой урок | `403 forbidden` |
| CN-R14a | урок ещё не проведён | ученику конспект недоступен, репетитору виден целиком |
| CN-R14a | отмечен объяснённым блок 2 из 4 | ученик видит блоки 1–2 и перенесённое |

## 5. Ошибки

| Ситуация | Ответ | Код |
|---|---|---|
| Чужой урок | 403 | `forbidden` |
| Урок не заморожен, снимка нет | 409 | `lesson_not_frozen` |
| Ученик открывает конспект до проведения урока | 409 | `lesson_not_held` |
| Блок отсутствует в версии каталога | 500 | `block_missing` (тревога) |
| Не удалось сформировать PDF | 503 | `pdf_unavailable` |
