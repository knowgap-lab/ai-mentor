## 1. Назначение

После того как репетитор поставил две отметки урока, система собирает **черновик ДЗ**: один список вариантов для этого ученика. Репетитор просматривает черновик, правит его и выдаёт (D100, D195). Модуль решает, **какие варианты** попадут в домашку и **сколько**; показ, проверка и сдача живут в [attempts](../platform/attempts.md) и [answer-check](../platform/answer-check.md).

## 3. Правила

### Когда и что собирается

- **HW-R1.** Черновик собирается после сохранения **обеих** отметок урока; до этого ДЗ нет (D96, D100). Отменённый урок и урок, где обе отметки «нет», ДЗ не дают (D106, D274).
- **HW-R2.** У урока ровно одно ДЗ: один список вариантов, без деления на дни и на части (D229, D230).
- **HW-R3.** Источник каждого варианта в списке — одно из `reinforcement`, `unsolved`, `new_topic`, `threshold`, `review`, `ct_format`; `threshold` — добавка по порогу 80 % (HW-R13), `review` объединяет повторение из рецепта и повторение 1-3-7-15; он записывается в снимок выдачи (AT-R5, D230).
- **HW-R4.** Порядок списка: сначала `unsolved` и `reinforcement`, затем `new_topic` по возрастанию сложности, затем `threshold`, затем `review` вперемешку, затем `ct_format` (D230, D146).
- **HW-R5.** Весь список проверяется автоматически по D104; таймеров и «без конспекта» в платформе нет (D227).

### Закрепление и недорешённое

- **HW-R6.** Каждая практическая задача, решённая на уроке (до второй отметки), даёт в ДЗ вариант **того же подварианта с другими числами** (`reinforcement`) (D39).
- **HW-R7.** Недорешённые задачи, теория которых объяснена, идут в ДЗ (`unsolved`) теми же вариантами, какими были на уроке: это перенос самих задач (D96), а не новая выдача, поэтому HW-R11 к ним не применяется; недорешённые с необъяснённой теорией в ДЗ не попадают и переходят в начало следующего урока вместе с теорией ([lessons](lessons.md), D96).
- **HW-R8.** Для закрепления у каждого подварианта темы урока в каталоге не менее 2 вариантов (D188); если свободного варианта нет, закрепление по нему пропускается и репетитору уходит `variants_needed` с указанием типа и подварианта (D101). Гарантия VR-R2 исчерпание не исключает: вариант, показанный на уроке или раньше, уже не свободен.

### Новое, повторение, формат ЦТ

- **HW-R9.** Серии `new_topic`, `review`, `ct_format` берутся из рецепта шаблона урока: типы, сложность, источник (D146, CP-R18). `review` добавляет задачи по темам, пройденным 1, 3, 7 и 15 уроков назад (считаются проведённые уроки; пропущенные не считаются и не учитываются как пройденные темы); репетитор может убрать любую из них в черновике (D258).
- **HW-R10.** Варианты, помеченные как резерв срезов (`checkpoint_reserve`), в ДЗ не берутся (D149, [variants](../catalog/variants.md), VR-R3).

### Без повторов

- **HW-R11.** Ученику не выдаётся вариант, который он уже видел (в ДЗ, срезе, пробнике, диагностике и на уроке) (D27, D193). Если для типа не осталось невиданных вариантов, тип в ДЗ пропускается и репетитору уходит `variants_needed` (D101).

### Пороги и размер

- **HW-R12.** Доля верных по теме считается по последнему сданному ДЗ ученика: задачи темы, у которых балл **первой** попытки равен максимуму, к числу задач темы (D45).
- **HW-R13.** Если доля по теме **ниже 80 %**, в следующее ДЗ добавляются задачи по этой теме; их столько, сколько задач темы не удались с первой попытки в последнем сданном ДЗ (D255, D263).
- **HW-R14.** Если доля по теме **ниже 60 %**, репетитор дополнительно видит пометку «тему лучше разобрать на следующем уроке». Платформа урок не перестраивает (D256).
- **HW-R15.** Размер ДЗ определяет рецепт урока (D262). В ДЗ попадают только типы, теория которых объяснена на уроке; остальные в ДЗ не попадают и не заменяются. Тип считается объяснённым, если `theory_block` его вариантов входит в блоки снимка этого урока до последней отметки теории или принадлежит прошлым проведённым урокам; серии `review` и `ct_format` относятся к прошлым урокам и всегда допустимы. Серии `new_topic`, `review`, `ct_format` имеют размер рецепта, а `reinforcement`, `unsolved` и `threshold` добавляются сверх него (D274).
- **HW-R15a.** Если ДЗ больше числа практических задач, решённых на уроке, умноженного на `HOMEWORK_RATIO` (по умолчанию 2), в черновике показывается подсказка «на уроке решено N, в ДЗ M»; она ничего не меняет (D261, D262).
- **HW-R16.** Платформа не считает часы и не ограничивает ДЗ по времени (D260).

### Просмотр и выдача

- **HW-R17.** Черновик не факт. Репетитор может убрать вариант, добавить вариант из пула, изменить срок и выдать. После выдачи ДЗ можно только отозвать целиком, пока ученик не ответил ни разу (D195, AT-R4, AT-R6).
- **HW-R18.** Срок по умолчанию — начало следующего не пропущенного урока по этому предмету (AT-R7). Если у урока нет даты (правила расписания нет, LS-R3), срок по умолчанию не определён, и выдача без срока невозможна: `422 deadline_required`.
- **HW-R19.** Если блоки урока не готовы, репетитор собирает ДЗ вручную из уже загруженных вариантов; автосборка работает, как только блоки и варианты есть (D140). Урок не блокируется содержимым.
- **HW-R20.** Сборка детерминирована: одинаковые входные данные дают тот же черновик. Порядок среди равных определяется стабильным ключом (id варианта) (D30).

## 5. Ошибки

| Ситуация | Ответ | Код |
|---|---|---|
| Отметки урока не поставлены | 409 | `lesson_not_marked` |
| Урок отменён | 409 | `lesson_cancelled` |
| Вариант уже виден ученику (добавление вручную) | 409 | `variant_seen` |
| Нет ни одного подходящего варианта | 200 | пустой черновик и `variants_needed` |
| Выдача уже есть | 409 | `already_issued` |
