# План (статичный, выпуск 1)

| Поле | Значение |
|---|---|
| Область | personalization |
| Владелец (утверждает) | пользователь (D144) |
| Реализуют | core (Go) |
| Выпуск | 1 (адаптивная часть — выпуск 2, [optimizer](optimizer.md)) |
| Решения | D8, D95, D100, D105, D106, D148, D157, D163, D175, D197, D219, D267, D268 |
| Статус | на ревью |

## 1. Назначение

Хранит и показывает **текущий план** ученика по предмету: порядок уроков, их темы и недели. В выпуске 1 план статичный: это импортированный план 0 плюс правки репетитора (перенос, отмена, добавление, смена порядка). Модуль ничего не пересчитывает сам. Он отвечает за то, как план хранится, как правится и как сравнивается с планом 0.

## 2. Вход и выход

| Вход | Откуда | Контракт |
|---|---|---|
| План 0: уроки с номером, неделей, видом, темами, повторениями | [plan-import](../catalog/plan-import.md) | `internal-api.yaml` |
| Правки репетитора: смена порядка, пропуск, перенос, отмена, добавление | кабинет ([web](../platform/web.md)) | `core-api.yaml` |

| Выход | Куда | Контракт |
|---|---|---|
| Текущий план: упорядоченный список уроков | кабинет репетитора | `core-api.yaml` |
| Отчёт расхождений с планом 0 | кабинет репетитора | `core-api.yaml` |
| Правки как ограничения | журнал, в выпуске 2+ очередь ([queue](../platform/queue.md), QU-R2) | `events.schema.json` |

## 3. Правила

### Хранение

- **PL-R1.** План 0 — неизменяемый снимок импорта с хешами исходных файлов; он хранится в `core.*` как версия 0 и служит эталоном (D163, D197, LP-R15).
- **PL-R2.** Текущий план = план 0 + правки репетитора. Правки добавляются событиями журнала (перенос, отмена, добавление, пропуск — [lessons](lessons.md); смена порядка — этот модуль), план 0 не меняется (D105, D106, LP-R14).
- **PL-R3.** Урок сохраняет постоянный id шаблона (`ct-math:L07`) независимо от своего места в плане; номер места и id урока — разные вещи (CS-R30).

### Правки

- **PL-R4.** Репетитор может поменять порядок не замороженных и не проведённых уроков. Замороженные и проведённые урокам место не меняют (D8, LS-R9).
- **PL-R4a.** Репетитор может пометить не проведённый урок как «пропущен» (`lesson_skipped`): урок остаётся в плане с пометкой, ДЗ по нему не выдаётся, следующие уроки сдвигаются на одно занятие раньше; пропущенный урок слота не занимает и в `plan_does_not_fit` не считается ([lessons](lessons.md), LS-R2, LS-R7). Пропуск не означает, что тема освоена; отметка «тип освоен» появится в выпуске 2 (D268, D95).
- **PL-R5.** Смена порядка, при которой тема встаёт раньше своих предпосылок, допускается, но репетитору показывается предупреждение `prereq_order` со списком тем; запрета нет, решение принимает репетитор (D267).
- **PL-R6.** Любая правка плана — ограничение, а не факт (D175): в выпуске 1 она меняет план и даты, в выпуске 2+ ставит задание пересчёта плана ([queue](../platform/queue.md)).
- **PL-R7.** Для другого ученика тот же план привязывается со сдвигом `shift_weeks` в целых неделях; остальное правится в кабинете (D219, LP-R11).

### Показ и сравнение

- **PL-R8.** Для каждого урока кабинет показывает: место, название, вид, темы, дату или неделю, состояние (`planned`, `frozen`, `held`, `skipped`) и пометку «перенесено» или «добавлено» (LS-R8).
- **PL-R9.** Отчёт расхождений сравнивает текущий план с планом 0: перенесённые, добавленные, отменённые и пропущенные уроки, смена порядка, сдвиг недель. Это справка репетитору, а не ошибка и не критерий тестов (D197, LP-R15).
- **PL-R10.** Если после правок до экзамена уроков больше, чем занятий, показывается предупреждение `plan_does_not_fit` (LS-R7, D106).

### Что не делается в выпуске 1

- **PL-R11.** План сам не пересчитывается и не сжимается: нет оптимизатора, модели знаний и агента (D95, D100). Адаптация придёт с выпуском 2, когда оптимизатор станет писать `compute.plan`, а Go будет применять его к не замороженным урокам (D157, D163).

## 4. Таблицы примеров

Файл `plan.examples.yaml` (D133). Ключевые строки:

| Правило | Ситуация | Ожидаемый результат |
|---|---|---|
| PL-R1 | попытка изменить план 0 | отказ: снимок неизменяем |
| PL-R2 | репетитор перенёс урок 9 | событие, план 0 цел, текущий план изменён |
| PL-R3 | урок 9 стал третьим по порядку | id остался `ct-math:L09` |
| PL-R4 | смена порядка заморожённого урока | `409 lesson_frozen` |
| PL-R4 | смена порядка не замороженного урока | принята |
| PL-R4a | урок 12 помечен «пропущен» | урок остался в плане с пометкой, ДЗ нет, уроки после него на одно занятие раньше |
| PL-R5 | урок темы M14 поставлен раньше урока темы M13 | принято, предупреждение `prereq_order` |
| PL-R7 | `shift_weeks: 4` | недели сдвинуты на 4, номера те же |
| PL-R8 | урок перенесён | пометка «перенесено» |
| PL-R9 | два переноса и одно добавление | отчёт перечисляет все три |
| PL-R10 | занятий на 2 меньше, чем уроков | `plan_does_not_fit`, недостаёт 2 |
| PL-R11 | сдан ДЗ с низким результатом | порядок уроков не меняется сам |

## 5. Ошибки

| Ситуация | Ответ | Код |
|---|---|---|
| Смена порядка замороженного или проведённого урока | 409 | `lesson_frozen` |
| Чужой ученик | 403 | `forbidden` |
| Несуществующий или чужой урок | 403 | `forbidden` |
