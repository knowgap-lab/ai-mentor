## Что сделать

1. Ветка `feat/mvp-s0` от свежего `main`.
2. Структура:
   ```
   backend/
     pyproject.toml          # Python 3.12; fastapi, sqlalchemy 2, alembic, psycopg, pydantic 2, pyyaml, pytest
     src/mentor/
       core/                 # чистая логика, без БД и фреймворков (в S0 — граф: загрузка, проверки)
       content/importer.py   # импорт из каталога ct-2027
       db/models.py          # SQLAlchemy-модели по разделу 5 DESIGN.md
       db/migrations/        # alembic
       api/main.py           # FastAPI: GET /health, GET /nodes, GET /nodes/{id}, GET /plan/{subject}
     tests/
   docker-compose.yml        # db (postgres:16), api
   .env.example              # DATABASE_URL, CONTENT_ROOT
   ```
3. Модели БД — все сущности раздела 5 DESIGN.md (Subject, Node, TaskType, Template,
   TaskInstance, Attempt, Mastery, PlanLesson, TutorEvent). Поле `student` пока —
   внешний ключ на таблицу `Student(id, name, created_at)`. Первая миграция alembic.
4. Импортёр `python -m mentor.content.importer --root $CONTENT_ROOT`:
   - узлы и рёбра пререквизитов из front matter карточек;
   - типы задач — каждая строка таблицы «Банк типов задач»: `bank_no`, текст типа,
     пример условия, ответ-строка, уровень, позиция ЦТ (`—` → пусто);
     `answer_format` определить эвристикой: целое / дробь / десятичное / вариант / текст;
   - уроки плана из `plan/L*.md`;
   - идемпотентно (повторный запуск не создаёт дублей), с отчётом: сколько узлов,
     рёбер, типов, уроков.
5. В `core/graph.py` — проверки как в `build.py`: несуществующие пререквизиты, циклы,
   тема в уроке раньше пререквизита. Импортёр падает с понятной ошибкой, если граф битый.
6. Тесты (pytest), без сети:
   - импорт на копии реальных данных (фикстура читает `$CONTENT_ROOT`, тест
     пропускается, если переменная не задана) → ровно 82 узла, 63 урока, у каждого
     узла уровня A/B не меньше 10 типов задач;
   - юнит-тесты проверок графа на маленьких синтетических графах (цикл, висячий
     пререквизит, нарушенный порядок);
   - тест эвристики `answer_format` на 10 примерах строк из банков.
7. `README` раздел «Запуск MVP» в `backend/README.md`: `docker compose up -d db`,
   миграции, импорт, тесты.
