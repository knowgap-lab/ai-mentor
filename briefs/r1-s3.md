## Находки ревью, которые надо закрыть

- `POST /consent/{token}` не смотрит Origin. Замороженные тесты G6 шлют этот запрос **без** заголовка `Origin` и ждут успех. Совместимая правка: запрос с заголовком `Origin`, который не равен адресу приложения, отклоняется так же, как это делает AU-R24; запрос без `Origin` проходит, как сейчас. Тест на отказ запросу без `Origin` не писать: это конфликт с заморозкой, его ведёт оркестратор.
- Обезличивания через 7 дней после отзыва нет. Нужна задача в процессе сервера. Интерфейс: `func (s *Service) AnonymiseDue(ctx context.Context, now time.Time) (int, error)` — обезличивает всех, у кого срок по правилам PV вышел к моменту `now`, возвращает число учеников. Таймер в сервере повесит оркестратор; пакет даёт только эту функцию. Число дней и условия берите из `privacy.md`, не из этого брифа.
- PV-R8, PV-R17, PV-R18, PV-R19 не покрыты тестами (так написано в `core/internal/privacy/harness_test.go`). Покрыть.
- Отзыв согласия гасит сеансы ученика (уже влито): тестом закрепить.

## Тесты

Один тест на каждый номер PV-R, который относится к операциям выше, плюс границы: чужой ученик у другого репетитора, ученик на операциях репетитора, повтор `archive` и `anonymise`, повторное создание ссылки согласия, просроченная и использованная ссылка. Сценарии `privacy.examples.yaml` для этих операций привязать к прогонщику `core/internal/scenario`; файл примеров не менять. События — по разделу «События журнала» общих правил (`student_archived`, `student_unarchived`, `student_anonymised`, `consent_given`, `consent_revoked`, `consent_revocation_cancelled`).
