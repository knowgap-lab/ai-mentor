# Бриф: G10, сборка ДЗ

Для агента-исполнителя. Отметки и расписание не переписывайте: они в `core/internal/lessons`. Сеть нет.

## Источники

- `docs/personalization/homework.md` (HW-R1…HW-R20) и `docs/personalization/homework.examples.yaml`
- операции `getHomeworkDraft`, `patchHomeworkDraft`, `issueHomework` и схемы `HomeworkDraft`, `DraftPatch` в `docs/contracts/core-api.yaml`
- коды раздела 5 и коды, уже названные в правилах: `lesson_not_marked`, `lesson_cancelled`, `variant_seen`, `variants_needed`, `already_issued`, `deadline_required` (HW-R18), `has_answers` (пример HW-R17)

## Пути

`core/internal/homework/`, миграция `migrations/09001_homework.sql`.

Таблица `core.homework_draft` уже есть (`id`, `lesson_id`, `items`, `deadline`). Её можно только расширять. `core/internal/lessons` не править.

## Поведение

- Черновик после обеих отметок. Одна отметка, отмена урока и обе отметки «нет» — строки ДЗ нет (HW-R1).
- Один список на урок. Источник варианта: `reinforcement`, `unsolved`, `new_topic`, `threshold`, `review`, `ct_format` (HW-R2, HW-R3).
- Порядок: `unsolved` и `reinforcement`, затем `new_topic` по сложности, затем `threshold`, затем `review`, затем `ct_format`. Среди равных — по id варианта (HW-R4, HW-R20).
- Закрепление — другой вариант того же подварианта. Нет свободного — пропуск и `variants_needed` (HW-R6, HW-R8).
- Недорешённое с объяснённой теорией — тот же вариант в ДЗ. С необъяснённой — не в ДЗ (HW-R7). Резерв срезов не берётся (HW-R10). Уже виденный ученику вариант не выдаётся (HW-R11).
- Порог 80 % и 60 % — как HW-R12…HW-R14. Платформа урок не перестраивает. `HOMEWORK_RATIO` по умолчанию 2, подсказка ничего не меняет (HW-R15a).
- Срок по умолчанию — начало следующего не пропущенного урока. Без даты выдача без срока — `422 deadline_required` (HW-R18).
- После выдачи правка черновика — `409 already_issued`. Отзыв целиком, пока нет ответов. Есть ответ — `409 has_answers` (HW-R17).
