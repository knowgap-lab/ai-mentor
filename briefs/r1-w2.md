# Бриф: W2, экран репетитора

Для агента-исполнителя. Телефонный экран: войти локально, увидеть своих учеников и их попытки. Ключей ответов на этом экране нет.

## Источники

- `docs/platform/web.md`: экран «Ученики» и «Ученик», WB-R4, WB-R22
- локальный вход уже есть: `POST /auth/dev`

## Пути

`web/src/tutor/` и тесты `web/src/tutor/*.test.tsx`. В `web/src/App.tsx` можно добавить маршрут `/tutor`.

## Поведение

- Страница `/tutor` на узком экране. Сначала форма локального входа: `telegram_id` и роль `tutor`, кнопка «Войти». Запрос `POST /auth/dev`.
- После входа список учеников. Чужой ученик в список не попадает.
- Выбор ученика показывает его попытки: сырой ввод и вердикт, если API их отдал. Текста ключа на этом экране нет, кнопки «показать ключ» нет (WB-R4, WB-R22).
- Выход возвращает к форме входа.

Данные в тестах подменяются. Настоящий сервер не обязателен.

## Тесты

Vitest. Имена содержат `wb-r4`. Минимум: свой ученик виден, чужой не виден, на экране попыток нет ключа `12`.

Тест-исполнитель страницу не пишет. Команда из `web/`: `npm test -- --run src/tutor`.
