# Бриф: G12, конспект без PDF

Для агента-исполнителя. PDF в этом пакете не собирается: способ не выбран, вопрос человеку уже записан. Сеть нет.

## Источники

- `docs/personalization/conspect.md` (CN-R1…CN-R9, CN-R13, CN-R14, CN-R14a) и `docs/personalization/conspect.examples.yaml`
- операция `getConspect` и схема `Conspect` в `docs/contracts/core-api.yaml`
- коды: `forbidden`, `lesson_not_frozen`, `lesson_not_held`, `block_missing`
- `getConspectPdf` отвечает `503` с кодом `pdf_unavailable` и пустым телом без байтов PDF

## Пути

`core/internal/conspect/`, миграция `migrations/11001_conspect.sql`, если без новой таблицы код не собирается. `core/internal/lessons` не править.

## Поведение

- Конспект — блоки снимка в порядке этапов, версия каталога снимка, не текущая (CN-R1).
- Виды `theory`, `rule`, `summary`, `worked_example`, `typical_error`, `widget`. `flashcard` не выводится (CN-R2).
- Перенесённое — первый раздел с заголовком «Перенесено с урока N» (CN-R3).
- Состав в выпуске 1 одинаков для учеников одного снимка (CN-R4). Текст платформа не генерирует (CN-R5). Практику в конспект не кладёт (CN-R6).
- Markdown остаётся текстом. Фрагмент `<script>` в блоке не попадает в ответ (CN-R7). Виджет с чужими параметрами не попадает в ответ (CN-R8).
- Нет блоков — репетитор видит запасной файл, ученик не видит ничего (CN-R13).
- Ученик видит конспект только своего `held` урока и только блоки до отметки теории плюс перенесённое. Репетитор видит свой урок целиком до проведения. Чужой — `403 forbidden` (CN-R14, CN-R14a).

Строки примеров CN-R10, CN-R11, CN-R12 проверяют только ответ `503 pdf_unavailable`, не содержимое PDF.

## Тесты

По тесту на каждую строку `conspect.examples.yaml`, имя содержит номер правила. База — `dbtest`. Нет Docker — `t.Skip`. Комментарий в начале `harness_test.go` фиксирует интерфейс. Реализацию тест-исполнитель не пишет.
