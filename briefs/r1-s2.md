# Бриф: S2, вход, сеансы, приглашения

Для тест-исполнителя, затем для код-исполнителя. Источники целиком: `docs/platform/auth.md`, `docs/platform/auth.examples.yaml`, `docs/platform/notifications.md` (NT-R19, NT-R20), `docs/contracts/core-api.yaml`, `docs/contracts/internal-api.yaml` (только `telegramWebhook`).

## Пути

`core/internal/auth/`, `core/internal/telegram/`. Файл `core/cmd/server` не трогать: подключение сделает оркестратор после приёмки.

Новые маршруты повесить на `Handler()` того пакета, которому операция ближе по спецификации. Уже существующие маршруты `POST /auth/dev`, `POST /auth/logout`, `GET /me` не менять в поведении.

## Операции

- `loginTelegram` `POST /auth/telegram`
- `getInvite` `GET /invite/{token}`
- `createInvite` `POST /students/{id}/invites`
- `listSessions` `GET /me/sessions`
- `revokeAllSessions` `POST /me/sessions/revoke-all`
- `studentRevokeSessions` `POST /students/{id}/revoke-sessions`
- `studentUnbindTelegram` `POST /students/{id}/unbind-telegram`
- `telegramWebhook` `POST /telegram/webhook`

Реальный Telegram не вызывать. Секреты не создавать. Имена переменных — из `deploy/secrets.md`: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_WEBHOOK_SECRET`.

## Находки, которые надо закрыть

- Вход проверяет подпись Telegram (AU-R12) на том обработчике, которым пойдёт реальный запрос, а не только в отдельной чистой функции, если запрос её не зовёт.
- Приглашение требует согласия (AU-R8) и единственно (AU-R11).
- Webhook без верного `X-Telegram-Bot-Api-Secret-Token` — `403` (NT-R19).

Замороженные тесты не менять. Если правка, которую требует правило, роняет замороженный тест, не менять тест: написать `ОШИБКА ТЕСТА` и оставить эту часть. Остальное довести до зелёного.

## Тесты

Один тест на каждый номер правила, которое относится к этим операциям, имя содержит номер (`TestAU_R12_...`). Плюс границы: чужой ученик, повтор приглашения, подпись не сходится, webhook без секрета. Сценарии из `auth.examples.yaml` для этих операций привязать к прогонщику, файл примеров не менять.

Тест-исполнитель реализацию не пишет. Красные тесты допустимы только из-за отсутствия новых операций.
