# Бриф: E1, сквозной прогон скелета

Для агента-исполнителя. Один путь через базу и HTTP: ученик отвечает, репетитор видит попытку, ключ до разрешения не утекает, повтор с тем же ключом не создаёт вторую попытку.

## Почему путь такой

`tools/` не может импортировать `core/internal`. Прогон на Go лежит в `core/internal/e2e/`. Сценарий Playwright, если дойдёт, лежит в `tools/e2e/`.

## Что уже есть

- `auth.Open` — `POST /auth/dev`, `POST /auth/logout`, `GET /me`
- `answercheck.Open` — `POST /assignments/{id}/items/{item}/answer`
- `attempts.Open` — `GET /assignments/{id}/attempts`
- `dbtest.Start` — Postgres 16.15, том удаляется
- миграции в `migrations/`

Нет маршрута `GET /students` и общей сборки обработчиков. Её пишет код-исполнитель в `core/internal/compose`: функция `Handler(auth, answers, attempts http.Handler) http.Handler`, которая склеивает три обработчика и добавляет `GET /students`. Список учеников — только те, у кого `owner_tutor_id` равен вошедшему репетитору. Поля: `user_id`, `role`. Чужих учеников нет.

## Сценарий теста

`TestWalkSkeleton` в `core/internal/e2e/walk_test.go`:

1. Поднять базу `dbtest`, применить все `migrations/*.sql` (секция Up).
2. Вставить репетитора `tutor-demo` и ученика `student-demo` с `owner_tutor_id=tutor-demo`, `telegram_id` `tg-demo-tutor` и `tg-demo-student`, `status=active`.
3. Вставить выдачу `asg-demo` ученику: два элемента. `item-a` — `ct.choice1`, ключ `[3]`, часть A. `item-b` — `ct.integer`, ключ `12`, часть B. Состояние выдачи `issued`, элементов `open`.
4. Войти учеником через `POST /auth/dev`, `Origin: http://localhost`.
5. Ответ на `item-a` с телом `{"answer":[3],"idempotency_key":"k-a"}`. Код 200, вердикт correct. Повторить тот же запрос: попытка по этому элементу по-прежнему одна.
6. Ответ на `item-b` с `{"answer":"13","idempotency_key":"k-b"}`. Код 200, в JSON нет ключа `12` и нет поля `show`.
7. Войти репетитором. `GET /assignments/asg-demo/attempts` отдаёт оба сырых ввода `"[3]"` или `3` и `"13"`. `GET /students` содержит `student-demo` и не содержит чужого id.

Если Docker недоступен, `t.Skip`.

Тест-исполнитель не пишет `compose` и не меняет чужие пакеты. Сборка может быть красной из-за отсутствия `compose`.
