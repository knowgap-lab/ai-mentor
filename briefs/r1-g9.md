## Поведение

Функции пакета, имена можно уточнить, набор операций — нет:

- `PutSchedule` сохраняет правило пары (ученик, предмет): `weekdays` 1–7, `start_time`, `duration_min` (LS-R2).
- Раскладка: уроки плана по номерам на слоты от ближайшего занятия до даты экзамена, не включая саму дату экзамена. Пропущенные (`skipped`) слот не занимают (LS-R2, LS-R8).
- Нет правила — урок остаётся «неделя с понедельника `planned_week`» (LS-R3).
- `Move` пишет `lesson_moved`, номера уроков не меняет (LS-R4). Занятый слот — `409 slot_taken`.
- `Add` — слот без содержимого плана, следующие уроки сдвигаются на одно занятие (LS-R5).
- `Cancel` — урок на следующую дату, следующие сдвигаются, черновик ДЗ не создаётся, событие `lesson_cancelled` (LS-R6).
- Нехватка слотов до экзамена — предупреждение `plan_does_not_fit` с числом недостающих уроков; план сам не сжимается (LS-R7).
- Состояния: `planned`, `frozen`, `held`, `skipped`. Перенос и отмена состояние не меняют (LS-R8).
- Заморожены `LESSON_FROZEN_COUNT` ближайших не проведённых и не пропущенных, по умолчанию 2 (LS-R9). Заморозка пишет неизменяемый снимок и `lesson_frozen` (LS-R10). Снимок не меняется, кроме переноса недорешённого (LS-R12).
- Практика — из невиданных вариантов, не из резерва срезов. Вариант урока становится виденным, попытки по нему не пишутся (LS-R11).
- Нет блоков — источник `l_file`, снимка нет, ДЗ вручную (LS-R13). Файл урока этот пакет не генерирует.
- Состав = шаблон + перенесённое в начало отдельным этапом (LS-R14). Не влезло с конца — на первый не замороженный урок (LS-R15).
- `Mark` — две отметки или, для урока без снимка, `coverage: all | none` (LS-R16, LS-R20). Обе «нет» — весь урок на начало следующего, черновика ДЗ нет (LS-R17).
- Перенос по LS-R18: необъяснённая теория и задачи к ней — на начало следующего не пропущенного урока, событие `lesson_carried_over`. Задача с уже объяснённой теорией, которая не решена, в следующий урок не переносится; её id попадает в `core.homework_draft.items` этого урока. Рецепт закрепления, бюджет и выдачу не считайте.
- Пока черновик не выдан, отметки исправляются новой записью `lesson_marked`. После выдачи — `409 already_marked` (LS-R19a). Чужой ученик — `403 forbidden`. Элемент не из состава — `422 mark_not_in_lesson`. Не проведён и не текущий — `409 lesson_not_held` (LS-R19).
- Урок `diagnostic` хранится как обычный урок. Ответы этот пакет не принимает и PDF не строит (LS-R22, PDF — G12).

Якорь только для строки `lessons-01`, чтобы ожидание «4 занятия» проверялось, а не подгонялось: `now = 2026-11-02T00:00:00Z` (понедельник), экзамен `2026-11-16T00:00:00Z`, дни 1 и 4, `18:00`, 60 минут. Дата экзамена слотом не является.
