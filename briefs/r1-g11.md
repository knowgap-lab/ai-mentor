# Бриф: G11, статичный план

Для агента-исполнителя. Только выпуск 1: план 0, правки репетитора, горизонт, отчёт расхождений. Оптимизатора нет. Сеть нет.

## Источники

- `docs/personalization/plan.md` (PL-R1…PL-R11) и `docs/personalization/plan.examples.yaml`
- операции `getPlan`, `reorderPlan`, `getPlanDivergence` и схемы `PlanView`, `Lesson`, `Divergence` в `docs/contracts/core-api.yaml`
- коды раздела 5: `lesson_frozen`, `forbidden`. Предупреждения `prereq_order` и `plan_does_not_fit`

## Пути

`core/internal/plan/`, миграция `migrations/10001_plan.sql`.

`core/internal/lessons` не править. Пропуск урока, если он уже есть в уроках, отсюда только читается.

## Поведение

- План 0 — неизменяемый снимок. Попытка его изменить отклоняется (PL-R1). Текущий план = план 0 плюс события журнала (PL-R2).
- `template_id` урока не меняется при смене места (PL-R3). В примере план-03 id остаётся `ct-math:L09`.
- Порядок меняется только у уроков не `frozen` и не `held`. Иначе `409 lesson_frozen` (PL-R4).
- Тема раньше предпосылки допускается, в ответе предупреждение `prereq_order` (PL-R5). Запрета нет.
- `shift_weeks` сдвигает недели, номера уроков те же (PL-R7).
- Отчёт расхождений — справка, не ошибка (PL-R9).
- План сам не перестраивается из-за низкого ДЗ (PL-R11).
