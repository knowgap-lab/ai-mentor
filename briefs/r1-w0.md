# Бриф: W0, готовые экраны на дизайн-систему

Для код-исполнителя. Тестов писать не нужно: тесты W1, W2, W3 и E1 уже заморожены. Сначала прочитайте `briefs/r1-finish-common.md`. Источники целиком: `docs/platform/design.md` (DS-R1…DS-R12), `docs/platform/web.md` (состав экранов, раздел «Состояния и ошибки», WB-R1), `web/src/design/` (тема), `web/src/ui/` (общие элементы), `web/src/design/DesignPage.tsx` (образец, маршрут `/design` при `npm run dev`).

## Что сделать

Пять экранов свёрстаны простым HTML без темы: «Главная», «Урок», «Выдача (ДЗ)», «Задача» ученика и «Ученики» репетитора. Перевести их на `Screen`, `List`, `ListRow`, `StatusBadge`, `TaskSheet`, `ActionBar` из `web/src/ui/` и компоненты Mantine. **Поведение не меняется**: те же запросы, те же тексты, те же роли и доступные имена элементов, те же маршруты. Меняется только разметка и вид.

## Пути

`web/src/student/`, `web/src/task/`, `web/src/tutor/`, `web/src/ui/`, `web/src/App.tsx`. Не хватает общего элемента — добавить его в `web/src/ui/` с тестом в `web/src/ui/ui.test.tsx` или новом файле рядом (DS-R11). `web/src/design/` менять только если без этого экран нельзя собрать по `design.md`, и назвать это в отчёте. `web/screens.json` и маршруты не менять: новых экранов в этом пакете нет.

## Заморожено (не менять)

`web/src/student/student.test.tsx`, `web/src/task/TaskPage.test.tsx`, `web/src/tutor/TutorPage.test.tsx`, `web/src/App.test.tsx`, `web/src/ui/ui.test.tsx` (можно только дописывать новые тесты для новых элементов, существующие не трогать), `tools/e2e/`. Если тест привязан к разметке, которую дизайн-система требует убрать, — строка `ОШИБКА ТЕСТА`, тест не менять, этот элемент оставить как есть.

## Правила

- DS-R1: своих цветов нет, только тема (`python3 tools/check_design.py` из корня worktree).
- Своих размеров и отступов нет: только токены темы и свойства компонентов.
- WB-R1: ширина 360 px без горизонтальной прокрутки, кнопки не меньше размера из правила.
- Доступность: роли и подписи сохраняются; `eslint-plugin-jsx-a11y` без новых предупреждений.
- Новых зависимостей не добавлять. Нужна — строка `ВОПРОС`.
- Документацию Mantine читать через Context7 под версию из `web/package-lock.json`.

Находка ревью W3, которая входит в этот пакет: вёрстка кабинета ученика без дизайн-системы. Остальные находки W3 (тексты ошибок WB-R6, кнопка «Ответить» после сдачи WB-R16) — пакет W4, не трогать.

## Приёмка

`web/node_modules` в worktree уже установлен оркестратором (`npm ci --ignore-scripts`).

```bash
(cd web && npm test && npm run typecheck && npm run lint)
python3 tools/check_design.py
git diff HEAD --stat -- 'web/src/**/*.test.tsx' tools/e2e   # существующие тесты не изменены
```

Сквозной прогон в браузере (`tools/e2e`) и снимки экранов 360 px делает оркестратор на приёмке.
