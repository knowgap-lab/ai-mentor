# Бриф: G5, проверка входа Telegram

Для агента-исполнителя. Сеть к Telegram не вызывать. Подпись — чистая функция.

## Источники

- `docs/platform/auth.md`: AU-R9, AU-R10, AU-R12, AU-R13, AU-R15, AU-R16
- `docs/contracts/core-api.yaml`, схема `TelegramLogin`

## Пути

`core/internal/telegram/`. Существующий пакет `core/internal/auth` не менять.

## Поведение

`Check(data map[string]string, botToken string, now time.Time) error`

- Строка проверки: все поля, кроме `hash`, в алфавитном порядке, как `ключ=значение` через `\n`.
- `hash` должен равняться HMAC-SHA256 от этой строки, ключ HMAC — SHA-256 от токена бота (байты токена, не hex). Иначе ошибка `login_invalid`.
- `now - auth_date` больше 300 секунд — `login_stale`. 299 секунд ещё годится.
- Функция не пишет имя, фамилию, username и фото. Наружу из данных входа годится только `id`.

`Invite`: токен 32 байта, в базе только SHA-256. Срок 72 часа. `GET` не меняет строк. Второй обмен и ссылка старше 72 часов — `invite_gone`. Один `telegram_id` — один пользователь; второй — `telegram_already_bound`.

Таблица `core.telegram_invite`: `token_hash` bytea, `student_id` text, `expires_at`, `used_at` null. Миграция `migrations/06001_telegram.sql`.
