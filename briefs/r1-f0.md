# Бриф: F0, каркас выпуска 1

Для код-исполнителя. Библиотеки уже выбраны решением D300. Не меняйте набор. Документацию библиотек читайте через Context7 (`resolve-library-id`, затем `query-docs`) или из установленных модулей. Не пишите API по памяти.

## Цель

Пустой каркас, в который следующие пакеты добавляют код, не правя общие файлы без нужды. Проверки каркаса зелёные.

## Пути

`core/`, `web/`, `gen/`, `migrations/`, `deploy/`, `tools/check-code.sh`, `.github/workflows/code-check.yml`, `.golangci.yml`.

Не менять `docs/`, `content/`, `legal/`, контракты и тесты Python.

## Что должно появиться

- `core/go.mod` модуля `github.com/knowgap-lab/ai-mentor/core`. Зависимости по D300 с версиями в `go.sum`: chi, pgx/v5, sqlc и oapi-codegen как `tool`, goose. Пока ни одного маршрута продукта. `core/cmd/server/main.go` поднимает chi и отвечает `GET /healthz` текстом `ok`.
- `migrations/` пустой каталог с `README` на русском: файлы SQL, только расширяющие, номера выдаёт оркестратор.
- `gen/` с `README`: сгенерированные типы коммитятся, CI сверяет перегенерацию. Генераторов ещё не запускать: контракты не трогать, пустые заготовки не выдавать за типы.
- `deploy/README` на русском: здесь будут compose-файлы. Образ Postgres — официальный `postgres:16`, точный патч запишите комментарием, образ не скачивайте, если его ещё нет локально.
- `web/`: Vite, React, TypeScript, Mantine, React Router. Одна страница с текстом «ИИ-ментор» и ссылкой «дальше». `npm ci --ignore-scripts` не нужен в этой сессии: ставьте зависимости обычным `npm install`, lock-файл коммитится. Скрипты `lint`, `typecheck`, `test`, `build`. ESLint с `eslint-plugin-jsx-a11y`, Prettier, Vitest с одним тестом, что страница показывает этот текст. `tsc --noEmit` чистый.
- `tools/check-code.sh`: из корня репозитория, с `PATH` на `.venv/bin`, запускает `gofmt -l` (пусто), `go test ./...` в `core/`, `go vet ./...`, веб-команды `npm test`, `npm run typecheck`, `npm run lint` если скрипт есть, и `ruff` только если бинарь есть в `.venv` (нет — пропуск с явной строкой, не ошибка). Ненулевой код при ошибке.
- `.github/workflows/code-check.yml` вызывает `tools/check-code.sh` и `tools/check.sh`. Файл только в репозитории, не отправлять.
- `.golangci.yml` с linters staticcheck, errcheck, gosec, govet, ineffassign, unused. Если `golangci-lint` не установлен, скрипт проверки пишет это и не падает: поставить его в этой сессии нельзя без отдельной загрузки.

## Запреты

Сеть к внешним сервисам из кода. Секреты. `git commit`, `git push`. GPL и AGPL. Правки вне путей выше.

## Критерий

`bash tools/check-code.sh` из корня worktree завершается нулём. `cd web && npm test` и `npm run typecheck` зелёные. `cd core && go test ./...` зелёный.
