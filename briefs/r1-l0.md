Для агента-исполнителя. Поднять на этой машине базу, миграции, синтетических людей и демо-каталог. Реальных учеников нет.

## Пути

`tools/dev-up.sh`, `tools/dev_seed.py`, раздел «Локальный запуск» в корневом `README.md` (остальной README не переписывать).

## Поведение

`tools/dev-up.sh`:

1. Если контейнер `ai-mentor-dev` не запущен, запускает `postgres:16.15` с именем `ai-mentor-dev`, базой `ai_mentor`, пользователем `postgres`, trust, порт `127.0.0.1:5432`. Том не оставлять безымянным: `-v ai-mentor-dev-data:/var/lib/postgresql/data`.
2. Ждёт готовности базы.
3. Применяет все `migrations/*.sql` по порядку имён (goose или `psql` по файлам, только Up).
4. Вызывает `tools/dev_seed.py`.

`dev_seed.py` на DSN из `DATABASE_URL` или `postgres://postgres@127.0.0.1:5432/ai_mentor?sslmode=disable`:

- репетитор `user_id=tutor-demo`, `telegram_id=tg-demo-tutor`, роль `tutor`;
- ученик `user_id=student-demo`, `telegram_id=tg-demo-student`, роль `student`, `owner_tutor_id=tutor-demo`;
- повторный запуск не создаёт вторых строк;
- собирает артефакт демо-каталога через `catalog_artifact` и грузит его в `staging` через `loader.load_artifact`. Повтор не создаёт вторую версию.

Скрипт печатает DSN и две команды входа: `POST /auth/dev` с этими `telegram_id`. Паролей и настоящих имён нет.
