# Бриф: F2, прогонщик таблиц примеров

Для агента-исполнителя. Пакет не реализует правила предметов. Он только гоняет сценарии `given → steps → expect` и сравнивает ответ.

## Источники

- `tools/examples/check_scenarios.py` — формат шага и раскрытие `$repeat`
- `docs/platform/answer-check.examples.yaml` — образец полей, не подключать его к живому серверу
- `docs/contracts/core-api.yaml` — откуда берутся путь и метод по `operationId`

## Пути

Только `core/internal/scenario/`. Не менять контракты, примеры, `content/`, `web/`.

## Интерфейс

```go
type Bindings struct {
    Path   map[string]string // имя параметра пути → значение
    Header map[string]string // заголовки запроса, например Cookie
}

type Loader func(given map[string]any) (Bindings, error)

type Options struct {
    Spec      []byte // OpenAPI YAML
    Scenarios []byte // список сценариев, как в *.examples.yaml
    Handler   http.Handler
    Load      Loader
    Journal   func() map[string]any // снимок журнала после шага; nil значит журнала нет
}

func Run(t *testing.T, opts Options)
```

`Run` для каждого сценария:

1. Вызывает `Load(given)`.
2. Раскрывает `$repeat` в запросе так же, как `check_scenarios.py`: значение `{$repeat: [строка, число]}` заменяется повтором строки.
3. Находит в OpenAPI единственную операцию с этим `operationId`, берёт метод и путь.
4. Подставляет параметры пути из `Bindings.Path`. Нехвативший параметр — ошибка теста.
5. Шлёт запрос на `httptest.Server` с телом `request` (JSON) и заголовками из `Bindings`.
6. Сравнивает ответ.

Сравнение:

- `expect.http` — точный код.
- `expect.body` — каждый ключ должен совпасть. Лишние ключи ответа допустимы.
- `expect.no_fields` — этих ключей в теле нет.
- `expect.error.code` — в теле есть `error.code` с этим значением. Тело при ошибке может не содержать `body`.
- `expect.journal` — снимок `Journal()` после шага сравнивается так же, как `body`. Если журнал ожидается, а `Journal` равен nil, тест падает.
- `expect.headers` — указанные заголовки ответа совпадают без учёта регистра имени.
- Шаг `parallel` выполняет вложенные шаги и не требует порядка. Для F2 достаточно выполнить их по очереди: гонок в прогонщике нет.

Числа из YAML приходят как int или float64. Сравнение чисел считает `1` и `1.0` равными. Строки и списки сравниваются точно.

## Тесты

Файл `core/internal/scenario/run_test.go`. Свой маленький OpenAPI и свои сценарии в тесте, не файлы `docs/`. Минимум:

- совпавший ответ проходит;
- чужой `http` и чужое поле `body` роняют тест;
- `no_fields` ловит лишний ключ и молчит, когда ключа нет;
- `$repeat` раскрывается до вызова;
- параметр пути подставляется;
- `journal` сравнивается;
- повтор сценария с тем же телом вызывает обработчик дважды (идемпотентность проверяет обработчик, прогонщик просто не склеивает шаги);
- неизвестный `operationId` роняет тест.

Импорт пакета внутри теста не обязателен: пакет и есть реализация. Тест-исполнитель пишет тесты так, чтобы они не компилировались без `Run`, либо компилировались и были красными. Сборку `go test -c` или `go test` запустить.

## Запреты

Не вызывать сеть. Не менять `docs/contracts/`. `git commit` нельзя. База в этом пакете не обязательна: обработчик в тесте — обычный `http.Handler`.

## Критерий

`cd core && go test ./internal/scenario/` зелёный у код-исполнителя. `gofmt -l` по каталогу пуст.
