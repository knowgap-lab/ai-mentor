# P18. Основы МКТ: количество вещества, молярная масса, температура, основное уравнение МКТ

## Зачем эта тема

Это первая тема раздела «МКТ и термодинамика» (7 заданий из 30, почти четверть теста), и всё, что идёт дальше в этом разделе (уравнение состояния газа, тепловые процессы, тепловые двигатели), построено на формулах отсюда. Напрямую тема даёт задание **А4** (единицы СИ и основное уравнение МКТ — решаемость 80 % / 66 % по годам 2023/2024, то есть «наше» задание) и часть задания **В8** (ν = m/M, среднеквадратичная скорость — решаемость 51 % / 52 % / 82 %, 2 балла).

Для ученика: *«Здесь всего пять идей: "пачка частиц" (моль), "вес одной пачки" (молярная масса), "температура — это просто энергия", "давление — это удары молекул" и три формулы, которые их связывают. Это не новая физика с нуля — это те же навыки "выразить из формулы" и "перевести единицы", что мы уже тренировали, просто на новом материале»*.

## Результат: после темы ученик умеет

- [ ] объяснить, что значит «количество вещества ν = 2 моль» (это «две пачки» по Nₐ ≈ 6·10²³ частиц в каждой) и найти ν по массе и молярной массе (m = 90 г воды, M = 18 г/моль → ν = 5 моль);
- [ ] найти молярную массу вещества по таблице Менделеева в г/моль и перевести её в кг/моль для подстановки в формулы (M(O₂) = 32 г/моль = 0,032 кг/моль);
- [ ] переходить между тремя формулами количества вещества: ν = m/M = N/Nₐ (найти число молекул N по известному ν: ν = 0,1 моль → N = 6·10²²);
- [ ] найти массу одной молекулы m₀ = M/Nₐ (молекула O₂: m₀ ≈ 5,3·10⁻²⁶ кг);
- [ ] перевести температуру из °C в K (T = t + 273) и объяснить физический смысл температуры как меры средней кинетической энергии теплового движения молекул;
- [ ] посчитать среднюю кинетическую энергию одной молекулы E₀ = (3/2)·k·T при известной T (T = 100 К → E₀ ≈ 2,07·10⁻²¹ Дж);
- [ ] применить основное уравнение МКТ p = (1/3)·n·m₀·v²ср = (2/3)·n·E₀ и его следствие p = n·k·T для связи давления, концентрации и температуры;
- [ ] найти среднеквадратичную скорость молекул vкв = √(3p/ρ) = √(3kT/m₀) = √(3RT/M) (ρ = 2 кг/м³, p = 60 кПа → vкв = 300 м/с).

## Входная проверка (5 минут)

| № | Вопрос | Ответ | Что проверяет |
|---|---|---|---|
| 1 | Из формулы ν = m/M выразите M | M = m/ν | навык «выразить величину» (тема P02) |
| 2 | Посчитайте: 6·10²³ · 0,5 | 3·10²³ | умножение чисел в стандартном виде (порядок степени не теряем) |
| 3 | Переведите 27 °C в кельвины | 300 К | новое правило T = t + 273, проверяем, что ученик готов его применять |
| 4 | Сократите единицы: (кг/моль) : (1/моль) | кг | проверка формулы по единицам (тема P02) |
| 5 | Посчитайте: 3·10⁵ · 2·10⁻³ | 600 | арифметика со степенями десяти — без неё не считаются задачи этой темы |

Всё верно — теорию проходим в быстром темпе, основной акцент на шагах 6–7 (основное уравнение МКТ) и сразу переходим к практике. Ошибки в №2 и №5 — перед теорией 5 минут повторяем умножение чисел в стандартном виде (числа вида 6·10²³ не считаются «на глаз»).

## Теория: сценарий объяснения

### Шаг 1. Количество вещества: считаем частицы «пачками»

**Суть.** Молекул в любом видимом кусочке вещества — огромное, неудобное для расчётов число (в стакане воды их больше, чем звёзд в видимой Вселенной). Чтобы не писать каждый раз число вида 3 000 000 000 000 000 000 000 000, физики договорились считать молекулы «пачками» по Nₐ штук — как яйца считают не штуками, а десятками. Такая «пачка» называется **моль**, а число частиц в одной пачке — **число Авогадро**.

**Наглядно.** Нарисовать коробку яиц (10 штук = «десяток») рядом с колбой газа: «1 моль = Nₐ частиц», подписать Nₐ ≈ 6·10²³ моль⁻¹ (точное значение 6,02·10²³, для расчётов на простом калькуляторе округляем до 6·10²³ — договоримся об этом один раз и используем везде в этой теме).

**Правило.**
> ν — количество вещества, единица — **моль**. N — число молекул (частиц), число без единицы. ν = N/Nₐ, то есть N = ν·Nₐ. Nₐ ≈ 6·10²³ моль⁻¹ — сколько частиц в одном моле любого вещества (не зависит от того, что это за вещество).

**Мини-пример.** ν = 2 моль → N = 2 · 6·10²³ = 1,2·10²⁴ частиц.

### Шаг 2. Молярная масса: «вес одной пачки»

**Суть.** Молярная масса M — это масса одного моля вещества. Удобство: число M в граммах на моль **совпадает** с относительной молекулярной массой Mr из таблицы Менделеева (просто складываем массы атомов в молекуле), поэтому её не нужно вычислять заново — она уже «написана» в формуле вещества.

**Наглядно.** На доске: формула H₂O → 1·2 (два атома H по Ar = 1) + 16 (один атом O) = 18 → M(H₂O) = 18 г/моль. Рядом — та же пачка из шага 1: «одна пачка (1 моль) воды весит 18 граммов».

**Правило.**
> M [г/моль] = Mr (сумма относительных атомных масс атомов в молекуле по таблице Менделеева). Для подстановки в физические формулы (с k, R) нужны единицы СИ: **M [кг/моль] = M [г/моль] : 1000**.

**Мини-пример.** M(CO₂) = 12 + 16·2 = 44 г/моль = 0,044 кг/моль.

**Ловушка (сказать вслух).** 44 г/моль ≠ 44 кг/моль — забыть разделить на 1000 перед подстановкой в формулу с R или k — одна из самых частых ошибок темы, результат получается в 1000 раз больше правильного.

### Шаг 3. Три формулы количества вещества и масса одной молекулы

**Суть.** Количество вещества ν можно получить тремя разными путями — по массе, по числу частиц или (позже, в теме P19) по объёму газа. Все три формулы — это просто разные способы спросить «сколько пачек?».

**Наглядно.** Схема с ν в центре и стрелками к нему: от массы m (разделить на M), от числа частиц N (разделить на Nₐ); третья стрелка (от объёма газа) появится в теме P19. Любую из трёх величин (m, M, N) можно найти, если знать две остальные или ν.

**Правило.**
> ν = m/M = N/Nₐ. Отсюда масса одной молекулы: **m₀ = M/Nₐ** — так же, как масса одной груши = масса мешка / число груш в мешке.

**Мини-пример.** Масса молекулы кислорода (M = 0,032 кг/моль): m₀ = 0,032 / 6·10²³ ≈ 5,3·10⁻²⁶ кг — одна молекула весит примерно в 2·10²² раз меньше грамма, поэтому в бытовых единицах такие числа никогда не записывают, только в стандартном виде.

**Проверка размерности.** [m₀] = [M]/[Nₐ] = (кг/моль) / (1/моль) = кг — то, что и должно получиться.

### Шаг 4. Температура: не «горячо-холодно», а мера энергии молекул

**Суть.** В быту температура — это ощущение, но в физике у неё точный смысл: **T — это мера средней кинетической энергии хаотического (теплового) движения молекул**. Чем быстрее в среднем «мечутся» молекулы — тем выше температура. При температуре T = 0 К (абсолютный нуль, −273 °C) тепловое движение прекращается полностью — это самая низкая возможная температура, ниже некуда.

**Наглядно.** Два сосуда с шариками-«молекулами»: в холодном шарики еле двигаются, в горячем — быстро мечутся и чаще бьются о стенки. Шкала термометра рядом: 0 °C = 273 К, 100 °C = 373 К — всегда разница ровно 273.

**Правило.**
> T [К] = t [°C] + 273. T называется **абсолютной температурой** и не может быть отрицательной. В формулах МКТ и термодинамики — **всегда** T в кельвинах, никогда t в градусах Цельсия.

**Мини-пример.** Комнатная температура t = 20 °C → T = 20 + 273 = 293 К.

**Ловушка (сказать вслух).** «Температура выросла с 20 °C до 40 °C — выросла в 2 раза» — неверно: в кельвинах это 293 К и 313 К, то есть рост меньше чем на 7 %. Во «сколько раз» температура изменилась — считаем **только** в кельвинах.

### Шаг 5. Концентрация и плотность

**Суть.** Концентрация n — это не «процент» (как в химии), а **число частиц в единице объёма**: сколько молекул «набито» в один кубический метр. Это нужно, чтобы связать микромир (отдельные молекулы) с макромиром (давление, которое можно измерить манометром).

**Наглядно.** Куб со стороной 1 м, внутри — точки-молекулы: «сколько точек в этом кубе — это и есть n».

**Правило.**
> n = N/V, единица — м⁻³ (частиц на кубический метр). Если каждая молекула имеет массу m₀, то масса в единице объёма — это плотность: **ρ = n·m₀ = m/V**.

**Мини-пример.** Если в 1 м³ воздуха n = 2,7·10²⁵ молекул и масса одной молекулы воздуха m₀ ≈ 4,8·10⁻²⁶ кг, то ρ = n·m₀ ≈ 1,3 кг/м³ — это и есть обычная плотность воздуха, которую мы уже использовали в теме P16 (гидростатика).

### Шаг 6. Основное уравнение МКТ: давление — это удары молекул

**Суть.** Газ давит на стенки сосуда не потому, что «хочет расшириться», а потому, что миллиарды молекул непрерывно бьются о стенку и толкают её. Чем больше молекул в объёме (n), чем они тяжелее (m₀) и чем быстрее летят (v²ср — средний квадрат их скорости), тем сильнее суммарный толчок — то есть давление.

**Наглядно.** Стенка сосуда крупным планом, в неё со всех сторон летят и отскакивают шарики-молекулы; подписать три «рычага» давления: n (сколько шариков), m₀ (насколько тяжёлый шарик), v²ср (как быстро летит).

**Правило.**
> **Основное уравнение МКТ:** p = (1/3)·n·m₀·v²ср. Так как средняя кинетическая энергия одной молекулы E₀ = (1/2)·m₀·v²ср, то же уравнение можно записать как **p = (2/3)·n·E₀**.

**Мини-пример.** n = 3·10²⁵ м⁻³, m₀ = 5·10⁻²⁶ кг, v²ср = 2·10⁵ (м/с)² → p = (1/3)·3·10²⁵·5·10⁻²⁶·2·10⁵ = 100 000 Па = 100 кПа.

**Проверка размерности.** [n]·[m₀]·[v²] = м⁻³ · кг · (м/с)² = кг/(м·с²) = Н/м² = Па — совпадает с давлением.

**Ловушка (сказать вслух).** Множитель 1/3 (или 2/3) — не «лишняя мелочь», его нельзя терять: без него ответ будет втрое или в полтора раза больше правильного, а на ЦТ это сразу 0 баллов за задание В.

### Шаг 7. Следствия: p = nkT и среднеквадратичная скорость

**Суть.** Из E₀ = (3/2)kT (это новый факт: средняя кинетическая энергия молекулы зависит только от температуры — доказывается в полном курсе, здесь принимаем как данное) и основного уравнения МКТ p = (2/3)·n·E₀ получается простая и очень полезная формула, которая прямо связывает давление, концентрацию и температуру.

**Наглядно.** Цепочка на доске: T → (умножить на (3/2)k) → E₀ → (подставить в p = (2/3)nE₀) → p = nkT. Каждая стрелка — одна подстановка, ничего нового считать не нужно.

**Правило.**
> p = n·k·T, где k ≈ 1,38·10⁻²³ Дж/К — **постоянная Больцмана**. Среднеквадратичная скорость молекул (корень из v²ср) считается тремя равносильными способами:
> **vкв = √(3kT/m₀) = √(3RT/M) = √(3p/ρ)**, где R = Nₐ·k ≈ 8,31 Дж/(моль·К) — универсальная газовая постоянная.

**Мини-пример.** Газ с плотностью ρ = 2 кг/м³ под давлением p = 60 000 Па: vкв = √(3·60000/2) = √90000 = 300 м/с.

**Проверка правдоподобия.** Скорости молекул газа при обычных условиях — сотни метров в секунду (у лёгких газов — до нескольких км/с). Если получилось 3 м/с или 3 000 000 м/с — где-то забыт корень, множитель 3 или перепутаны кг/моль с г/моль.

### Чего сейчас не объясняем

- Уравнение Менделеева–Клапейрона pV = νRT и изопроцессы (изотермический, изобарный, изохорный) — отдельная тема P19, она использует формулы отсюда как готовый инструмент.
- Внутренняя энергия, работа газа и первый закон термодинамики — тема P20.
- Насыщенный пар и влажность воздуха — тема P23 (резерв, уровень C).
- Распределение молекул по скоростям (почему v²ср — это *средний* квадрат, а не скорость каждой молекулы) — за рамками школьного курса ЦТ, достаточно знать, что такое среднее существует и его можно посчитать.

## Разобранные примеры

### Пример 1 (уровень 1, формат части В — ответ целым числом в молях)

В стакане m = 90 г воды (M(H₂O) = 18 г/моль). Найдите количество вещества ν в молях.

1) ν = m/M.
2) ν = 90/18 = 5.

**Ответ: 5 моль.**

### Пример 2 (уровень 1)

Сколько молекул содержится в ν = 0,1 моль газа? Число Авогадро Nₐ = 6·10²³ моль⁻¹.

1) N = ν·Nₐ.
2) N = 0,1 · 6·10²³ = 6·10²².

**Ответ: 6·10²² молекул.** (Используем округлённое Nₐ ≈ 6·10²³ — договорённость из шага 1.)

### Пример 3 (уровень 2)

Найдите массу одной молекулы кислорода O₂ (M = 32 г/моль, Nₐ = 6·10²³ моль⁻¹).

1) Переводим в СИ: M = 32 г/моль = 0,032 кг/моль.
2) m₀ = M/Nₐ = 0,032 / 6·10²³ ≈ 5,3·10⁻²⁶.
3) Проверка единиц: (кг/моль) : (1/моль) = кг — верно.

**Ответ: ≈ 5,3·10⁻²⁶ кг.**

### Пример 4 (уровень 2)

Найдите среднюю кинетическую энергию теплового движения молекулы газа при температуре T = 100 К. Постоянная Больцмана k = 1,38·10⁻²³ Дж/К.

1) E₀ = (3/2)·k·T.
2) E₀ = 1,5 · 1,38·10⁻²³ · 100 = 2,07·10⁻²¹.
3) Проверка правдоподобия: такие энергии (10⁻²¹–10⁻²⁰ Дж) типичны для одной молекулы при обычных температурах — порядок величины верный.

**Ответ: ≈ 2,07·10⁻²¹ Дж.**

### Пример 5 (уровень 3)

Концентрация молекул газа n = 2·10²⁵ м⁻³, температура T = 300 К, k = 1,38·10⁻²³ Дж/К. Найдите давление газа p.

1) p = n·k·T.
2) p = 2·10²⁵ · 1,38·10⁻²³ · 300 = 82 800.
3) Проверка: атмосферное давление ≈ 10⁵ Па, наш ответ того же порядка — правдоподобно.

**Ответ: ≈ 82,8 кПа.**

### Пример 6 (уровень 3, формат части А)

Плотность газа ρ = 2 кг/м³, давление p = 60 кПа. Чему равна среднеквадратичная скорость молекул этого газа?

1) 100 м/с  2) 173 м/с  3) 300 м/с  4) 600 м/с  5) 90000 м/с

**Решение.** vкв = √(3p/ρ) = √(3 · 60000 / 2) = √90000 = 300 м/с. **Ответ: 3.**

**Разбор неверных вариантов.** Каждый вариант — конкретная ошибка на одном из шагов формулы:
- 1) 100 — разделили на 3 вместо того, чтобы умножить: √(p/(3ρ)) = √(60000/6) = 100;
- 2) 173 — забыли множитель 3 вовсе: √(p/ρ) = √30000 ≈ 173;
- 4) 600 — умножили на ρ вместо деления: √(3pρ) = √(3 · 60000 · 2) = √360000 = 600;
- 5) 90000 — не извлекли корень: это промежуточное значение 3p/ρ = v²ср, а не сама скорость vкв.

Ученику: после вычисления всегда проверяй правдоподобие — скорость молекул газа при обычных условиях — сотни метров в секунду, поэтому 90000 м/с (в десятки раз больше) сразу выдаёт забытый корень. Варианты 100, 173 и 600 по порядку правдоподобны, их отсекает только аккуратная запись формулы √(3p/ρ). Корень и множитель 3 — те места, где теряется больше всего баллов.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Путает число молекул N и количество вещества ν | «ν = 2 моль, значит N = 2» | N получается только через N = ν·Nₐ; спросить себя: «это число молей (несколько единиц) или число частиц (огромное число)?» |
| Не переводит молярную массу из г/моль в кг/моль | подставляет M = 18 вместо 0,018 в формулу с k или R | правило: в формулах с k, R — всё в СИ; M в г/моль делить на 1000 перед подстановкой |
| Путает °C и К | подставляет t = 20 вместо T = 293 в E₀ = (3/2)kT | первое действие в любой задаче МКТ — проверить, в каких единицах дана температура, и перевести в К |
| Забывает извлечь корень в формуле vкв | получает «vкв = 90000 м/с» | проверка правдоподобия: скорость молекул — сотни-тысячи м/с, не больше; если число огромное — забыт корень |
| Путает концентрацию n (на 1 м³) и полное число частиц N (во всём объёме) | подставляет N вместо n в p = nkT, ответ в разы больше правильного | n = N/V всегда; записывать единицу n (м⁻³) и N (без единицы) рядом с числом, чтобы не путать |
| Теряет множитель 1/3 (или 2/3) в основном уравнении МКТ | p = n·m₀·v²ср вместо (1/3)·n·m₀·v²ср | проговаривать формулу полностью каждый раз, не держать в голове «укороченную» версию |
| Путает v²ср (средний квадрат скорости) и vкв (сама скорость) | считает, что vкв = v²ср, без корня | чётко различать: v²ср — промежуточное число под корнем, vкв = √(v²ср) — финальный ответ в м/с |
| Теряет порядок степени десяти при счёте на калькуляторе | «6·10²³ · 0,5 = 6·0,5 = 3» вместо 3·10²³ | складывать степени десяти отдельно от коэффициентов (навык из темы P01); проверять порядок величины ответа |
