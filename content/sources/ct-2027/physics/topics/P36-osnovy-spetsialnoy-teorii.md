# P36. Основы специальной теории относительности

## Зачем эта тема

**Тема изучается, только если план идёт с опережением.** Уровень C: в плане под неё нет урока (0 часов урока, 1 час дома), и ни одна позиция ЦТ на карте теста (`strategy/exam-physics.md`) прямо с ней не связана. По спецификации на раздел «оптика и СТО» приходится 2 задания из 30, но на карте теста оптические позиции заняты геометрической и волновой оптикой (P34, P35). Если опережения нет, тему пропускаем без потерь для цели 60–70. Если время есть, тема берётся за один час дома: два постулата, одна формула сложения скоростей на «чистых» дробях c и формула E = mc². Это страховка на случай, если на ЦТ появится качественный вопрос по СТО.

Для ученика: *«Это самая "фантастическая" тема физики: ракеты почти со скоростью света. Но считать здесь легко — дроби вроде 0,5 и 0,8 и одна формула. Если план идёт с запасом — это бонус»*.

## Результат: после темы ученик умеет

- [ ] формулировать два постулата СТО (законы физики одинаковы во всех инерциальных системах; скорость света в вакууме c одна и та же для всех наблюдателей);
- [ ] отвечать, с какой скоростью свет от движущейся ракеты летит относительно Земли (ракета 0,6c, фары вперёд → c, а не 1,6c);
- [ ] складывать скорости по формуле СТО (0,5c и 0,5c навстречу → 0,8c, а не c);
- [ ] объяснять, почему скорость тела не может превысить c (сумма по формуле всегда меньше c);
- [ ] вычислять энергию покоя E₀ = mc² (m = 1 г, c = 3·10⁸ м/с → 9·10¹³ Дж = 90 ТДж);
- [ ] по энергии находить массу (E = 4,5·10¹⁶ Дж → m = 0,5 кг) и объяснять, почему «изменение массы» нагретого чайника не заметно.

| 3 | Вычислите (3·10⁸)² | 9·10¹⁶ | степени десяти (P01) |

| 5 | Вычислите 1,0 : 1,25 | 0,8 | деление на десятичную дробь |

Всё верно → шаг 1 за 2 минуты, сразу к сложению скоростей. Ошибки в № 1–2 → сначала повторить P06 и P14: без «обычного» сложения скоростей и понятия энергии тема не имеет смысла.

## Теория: сценарий объяснения

### Шаг 1. Где ломается привычная физика

**Суть.** В P06 скорости просто складывались: 20 м/с + 2 м/с = 22 м/с. Это верно для поездов, машин и самолётов. Но если ракета летит со скоростью 0,6c и включает фары, по «старому» правилу свет летел бы 1,6c. Опыты (Майкельсон, конец XIX века) показали: свет всегда летит со скоростью c, кто бы на него ни смотрел. Эйнштейн в 1905 году сделал это законом.

**Наглядно.** На доске: Земля, ракета со стрелкой «0,6c», из носа — луч со стрелкой «c». Подпись: «относительно Земли тоже c, а не 1,6c». **Мини-пример.** Ракета улетает со скоростью 0,8c и светит назад. Скорость света относительно Земли — c (не 0,2c).

### Шаг 2. Два постулата СТО

**Суть.** Постулат — исходное утверждение, на котором строится теория; его не выводят, а проверяют опытом.

**Правило.**
> **Постулат 1 (принцип относительности).** Все физические законы одинаковы во всех инерциальных системах отсчёта. Никаким опытом внутри закрытой каюты нельзя узнать, движется корабль равномерно или стоит.
> **Постулат 2.** Скорость света в вакууме c ≈ 3·10⁸ м/с одинакова во всех инерциальных системах и не зависит от скорости источника и приёмника.
> Следствие: **никакое тело и никакой сигнал не движутся быстрее c.**

**Мини-пример.** Может ли частица в ускорителе иметь скорость 1,1c? Нет — скорость любого тела меньше c.

### Шаг 3. Сложение скоростей в СТО

**Суть.** При скоростях, близких к c, «просто сложить» нельзя: сумма получилась бы больше c. Формула Эйнштейна делит обычную сумму на число больше единицы. **Наглядно.** Ракета (скорость v относительно Земли) запускает вперёд зонд (скорость u′ относительно ракеты). Рисунок: Земля → ракета «v» → зонд «u′». Ищем u — скорость зонда относительно Земли.

**Правило.**
> u = (u′ + v) / (1 + u′·v / c²)
> Удобно писать скорости в долях c: 0,5c → 0,5. Тогда u/c = (a + b) / (1 + a·b).
> При малых скоростях (машины, самолёты) a·b ≈ 0 и формула превращается в обычную u = u′ + v.

**Мини-пример.** a = b = 0,5: (0,5 + 0,5) / (1 + 0,25) = 1 / 1,25 = 0,8. Ответ 0,8c, а не c. Проверка постулата: зонд — это свет, a = 1: (1 + b)/(1 + b) = 1 → ровно c при любой скорости ракеты.

### Шаг 4. Энергия покоя E = mc²

**Суть.** Любое тело с массой m хранит энергию даже в покое. Её очень много, потому что c² огромно. Если тело получает или отдаёт энергию, его масса меняется на Δm = ΔE / c², но для бытовых энергий это ничтожно мало.

**Наглядно.** На доске: изюминка 1 г → «90 ТДж» → «почти столько электростанция мощностью 1 ГВт вырабатывает за сутки (≈ 86 ТДж)». Ядерный реактор превращает в энергию крошечную долю массы топлива (связь с P38).

**Правило.**
> E₀ = m·c²; [E] = кг·(м/с)² = кг·м²/с² = Дж (как в P14: Eк = mv²/2 тоже в кг·м²/с²).
> ΔE = Δm·c²; c² = 9·10¹⁶ м²/с².

**Мини-пример.** m = 1 г = 10⁻³ кг: E₀ = 10⁻³ · 9·10¹⁶ = 9·10¹³ Дж = 90 ТДж (1 ТДж = 10¹² Дж).

### Чего сейчас не объясняем

- Вывод формул из постулатов и относительность одновременности — для ЦТ это не нужно, а времени у ученика нет.
- Релятивистский импульс и формулу кинетической энергии с корнем — только упоминание, что при v → c импульс и энергия растут без предела (поэтому до c не разогнать).
- Замедление времени и сокращение длины — тема уровня C, ученику хватит постулатов, сложения скоростей и E = mc².

## Опорный конспект

> **Постулаты.** 1) Законы физики одинаковы во всех инерциальных системах. 2) c = 3·10⁸ м/с — одинаковая для всех; быстрее c ничего не движется.
> **Сложение скоростей** (в долях c): u = (a + b) / (1 + a·b). Навстречу и вдогонку — тот же смысл, что в P06, только знаменатель.
> **Удобные числа:** 0,5c ⊕ 0,5c = 0,8c; c/3 ⊕ c/3 = 0,6c; c ⊕ любая = c.
> **Энергия покоя:** E₀ = mc², масса в кг, c = 3·10⁸ м/с, E в Дж. ΔE = Δm·c².

**Образец оформления.** Дано: m = 2 г = 2·10⁻³ кг; c = 3·10⁸ м/с. Найти E₀. Решение: E₀ = mc² = 2·10⁻³ · 9·10¹⁶ = 1,8·10¹⁴ Дж = 180 ТДж. Проверка размерности: кг·м²/с² = Дж. Ответ: 180 ТДж.

## Разобранные примеры

### Пример 1 (уровень 1). Свет от движущейся ракеты

Ракета летит от Земли со скоростью 0,8c и включает фары, направленные вперёд. Скорость света в вакууме c = 3·10⁸ м/с. С какой скоростью свет фар движется относительно Земли?

По второму постулату скорость света не зависит от скорости источника: **c = 3·10⁸ м/с.** Проверка формулой: (1 + 0,8)/(1 + 1·0,8) = 1,8/1,8 = 1 → c. Ловушка: сложить по P06 и получить 1,8c — больше c не бывает.

### Пример 2 (уровень 2). Сложение скоростей

Ракета движется относительно Земли со скоростью c/3 и запускает вперёд зонд со скоростью c/3 относительно ракеты (c = 3·10⁸ м/с). Найдите скорость зонда относительно Земли.

1) Доли c: a = b = 1/3. 2) u/c = (1/3 + 1/3)/(1 + 1/9) = (2/3)/(10/9) = (2/3)·(9/10) = 0,6. 3) u = 0,6·3·10⁸ = 1,8·10⁸ м/с. 4) Проверка: 0,6c < c; классика дала бы 2c/3 ≈ 0,67c — СТО даёт чуть меньше. **Ответ: 0,6c = 1,8·10⁸ м/с.**

### Пример 3 (уровень 2, формат части В — целое число). Энергия покоя

Найдите энергию покоя тела массой 2 г. Скорость света c = 3·10⁸ м/с. Ответ дайте в тераджоулях (1 ТДж = 10¹² Дж).

1) m = 2 г = 2·10⁻³ кг (граммы в килограммы — обязательно). 2) E₀ = mc² = 2·10⁻³ · (3·10⁸)² = 2·10⁻³ · 9·10¹⁶ = 1,8·10¹⁴ Дж. 3) В ТДж: 1,8·10¹⁴ / 10¹² = 180. **Ответ: 180.** Ловушки: забыть возвести c в квадрат (получится 6·10⁵ Дж); подставить 2 вместо 2·10⁻³ (ответ в 1000 раз больше).

### Пример 4 (уровень 2, формат части А с 5 вариантами)

Две ракеты летят навстречу друг другу, каждая со скоростью 0,5c относительно Земли (c — скорость света в вакууме). Скорость одной ракеты относительно другой равна:

1) 0  2) 0,5c  3) 0,8c  4) c  5) 1,25c

**Решение.** Навстречу — скорости складываются (как в P06), но по формуле СТО: (0,5 + 0,5)/(1 + 0,25) = 0,8. **Ответ: 3.**

**Разбор неверных вариантов:**
- 1) 0 — скорости вычли, хотя ракеты летят навстречу;
- 2) 0,5c — взяли скорость одной ракеты относительно Земли;
- 4) c — сложили по-классически; тело не может двигаться относительно другого тела со скоростью c;
- 5) 1,25c — перепутали числитель и знаменатель; любая скорость больше c сразу отбрасывается.
- Ученику: в задачах СТО сначала вычеркни все варианты ≥ c для тел — обычно остаётся два-три.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Складывает по-классически | 0,5c + 0,5c = c | при скоростях в долях c всегда пишем знаменатель 1 + a·b; ответ ≥ c для тела — сразу ошибка |
| Прибавляет скорость источника к свету | ракета 0,6c → «свет 1,6c» | второй постулат вслух: «свет всегда c» |
| Не возводит c в квадрат | E = 10⁻³·3·10⁸ = 3·10⁵ Дж | в Дано сразу писать c² = 9·10¹⁶ м²/с² |
| Масса в граммах | E = 2·9·10¹⁶ вместо 2·10⁻³·9·10¹⁶ | первая строка решения — перевод в кг |
| Ошибка в степенях при переводе в ТДж | 1,8·10¹⁴ Дж = «1,8 ТДж» | 10¹⁴ / 10¹² = 10² → 180; прикидка по типу 6: 1 г ≈ 90 ТДж |

## Домашняя работа по теме

- **Когда.** Только при опережении плана, одним блоком на 1 час (структура по `strategy/methodology.md`), не вместо обязательных тем.
- **Блок A. Новое (≈ 25 минут).** Перечитать шаги 1–4, затем 7 задач: типы 1, 2, 4, 6 (уровень 1–2), затем типы 3, 7, 8. Ответы в конце. Тип 5 — «звёздочка».
- **Блок B. Повторение (≈ 15 минут).** 3 задачи на энергию из P14 (кинетическая энергия, мощность) и 2 задачи на классическое сложение скоростей из P06 — чтобы видеть разницу «машины против ракет».
- **Блок C. Формат ЦТ (≈ 10 минут).** 2 задания с 5 вариантами, как пример 4 (одно на сложение скоростей, одно на постулат), и 1 задача с целым ответом в ТДж, как пример 3.
- **Блок D. Карточки (≈ 5 минут).** 9 карточек раздела «Карточки» добавить в колоду с низким приоритетом.
- **Самопроверка.** В каждой задаче на скорость проверить: ответ для тела меньше c. В задачах на энергию — размерность кг·м²/с² = Дж. Ошибки — в журнал (задача → что сделал → в чём ошибка → верная идея).
