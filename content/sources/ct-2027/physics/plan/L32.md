Одна типичная — не больше 2 минут внутри карты, не отдельным блоком. Если журнал урока 31 пуст — сразу карта финального пробника. Срез из‑за этого не учить заново.

Вероятные сбои пробника по `review` (и по карточке «Типичные ошибки»):

- P20: знак A при сжатии «+»; литры как 0,02 м³ вместо 0,002; A = p·V₂ вместо p·ΔV; «отдал» как Q > 0; изохора = адиабата (A = 0 путает с Q = 0); ответ 4,5 вместо целого в кДж.

Подготовить:
