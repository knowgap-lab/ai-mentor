# M32. Чётность, нечётность и периодичность функций

## Зачем эта тема

Тема даёт напрямую задание В9 («нечётная функция, значение выражения»): на ЦЭ-2025 его решили 56,6 % участников, за него дают 2 балла, ответ — целое число. В карте теста это позиция уровня B — резерв, который поднимает результат с 60 к 70 баллам. Задание почти всегда устроено одинаково: функция задана формулой только для x ≥ 0, а спрашивают про отрицательные x — найти значение или сосчитать корни. Решается оно по алгоритму в 3–4 строки, если твёрдо знать два равенства: f(−x) = f(x) и f(−x) = −f(x).

Периодичность в В9 иногда добавляют «вторым слоем» (нечётная и периодическая одновременно), и она же понадобится в тригонометрии (M13, M14) и при разборе графиков в пробниках.

Для ученика: *«В9 — это 2 балла за три строчки. Формулу дают только для положительных x, а минус ты "переносишь" сам по одному правилу. Выучишь правило — задание твоё»*.

## Результат: после темы ученик умеет

- [ ] подставлять −x в формулу и упрощать: для f(x) = x³ − 2x получить f(−x) = −x³ + 2x;
- [ ] определять по формуле многочлена, чётная функция, нечётная или ни то ни другое (x⁴ − 3x² — чётная, x³ + 5x — нечётная, x² + x — ни то ни другое);
- [ ] объяснять смысл чётности и нечётности на графике: симметрия относительно оси Oy и относительно начала координат;
- [ ] находить значение в отрицательной точке по значению в положительной: если f нечётная и f(2) = 5, то f(−2) = −5; если чётная, то f(−2) = 5;
- [ ] решать задание В9: нечётная функция задана при x > 0 формулой x² − 6x + 5, найти f(−4) + 2·f(−3) (ответ 11);
- [ ] считать корни нечётной функции по корням при x ≥ 0 (корни 0, 2, 5 при x ≥ 0 → всего 5 корней);
- [ ] пользоваться периодом: если период равен 4 и f(1) = 3, то f(13) = 3 и f(−7) = 3;
- [ ] в части А выбирать нечётную или чётную функцию из пяти вариантов, проверяя f(1) и f(−1).

## Входная проверка (5 минут)

|---|---|---|---|
| 1 | Вычислите (−3)² | 9 | чётная степень отрицательного числа |
| 2 | Вычислите (−2)³ | −8 | нечётная степень отрицательного числа |
| 3 | f(x) = x² + 1. Найдите f(−2) | 5 | подстановка отрицательного числа в формулу |
| 4 | f(x) = x³. Запишите f(−x) | −x³ | подстановка выражения вместо x |
| 5 | График симметричен относительно оси Oy. Какая это функция (по M29)? | чётная | связь с темой M29 |

Всё верно — шаги 1–4 проговариваем за 5 минут и сразу переходим к задачам В9 (шаги 6–7). Ошибки в №1–2 — сначала 5 минут на знаки степеней: (−a)² = a², (−a)³ = −a³; без этого тема не пойдёт.

## Теория: сценарий объяснения

### Шаг 1. Что значит f(−x)

**Суть.** f(−x) — это та же формула, только вместо x везде подставлено число с противоположным знаком. Делаем это в скобках, чтобы не потерять минус.

**Наглядно.** На доске: f(x) = x² + 3x. Под каждым x рисуем «окошко» и вписываем в окошки (−x): f(−x) = (−x)² + 3·(−x) = x² − 3x.

**Правило.**
> Чётная степень «съедает» минус: (−x)² = x², (−x)⁴ = x⁴. Нечётная степень минус сохраняет: (−x)³ = −x³, (−x)⁵ = −x⁵, (−x)¹ = −x. Число без x (свободный член) от подстановки не меняется.

**Мини-пример.** f(x) = x³ − 2x: f(−x) = (−x)³ − 2·(−x) = −x³ + 2x. Проверка числом при x = 2: f(−2) = −8 + 4 = −4, а −2³ + 2·2 = −4 — совпало.

### Шаг 2. Чётная функция

**Суть.** Функция чётная, если при смене знака x значение не меняется: в точках 3 и −3 одно и то же значение, в точках 5 и −5 — одно и то же.

**Наглядно.** Парабола y = x² из M29: точки (2; 4) и (−2; 4), (3; 9) и (−3; 9). Сложить лист по оси Oy — левая половина ложится на правую.

**Правило.**
> f чётная, если для каждого x из области определения −x тоже входит в область определения и f(−x) = f(x). График чётной функции симметричен относительно оси Oy.

**Мини-пример.** f(x) = x⁴ − 3x²: f(−x) = (−x)⁴ − 3(−x)² = x⁴ − 3x² = f(x) — чётная.

### Шаг 3. Нечётная функция

**Суть.** Функция нечётная, если при смене знака x значение тоже меняет знак: f(3) = 7 означает f(−3) = −7.

**Наглядно.** Кубическая парабола y = x³: точки (1; 1) и (−1; −1), (2; 8) и (−2; −8). Повернуть рисунок на 180° вокруг начала координат — график совпадает сам с собой.

**Правило.**
> f нечётная, если для каждого x из области определения −x тоже входит в область определения и f(−x) = −f(x). График нечётной функции симметричен относительно начала координат. Если нечётная функция определена в точке 0, то f(0) = 0 (потому что f(0) = −f(0), а такое число одно — ноль).

**Мини-пример.** f(x) = x³ + 5x: f(−x) = −x³ − 5x = −(x³ + 5x) = −f(x) — нечётная. f(0) = 0.

### Шаг 4. Ни чётная, ни нечётная

**Суть.** Большинство функций не подходят ни под одно правило. Чтобы это доказать, достаточно одного числа, на котором правило ломается.

**Наглядно.** Таблица на доске для f(x) = x² + x: в столбце x = 1 пишем f(1) = 2, в столбце x = −1 пишем f(−1) = 0. Для чётности нужно 0 = 2, для нечётности 0 = −2. Ни то, ни другое.

**Правило.**
> Алгоритм проверки: 1) область определения симметрична относительно 0? Если нет — сразу «ни то ни другое». 2) Найти f(−x) и упростить. 3) Совпало с f(x) — чётная; совпало с −f(x) — нечётная; иначе — ни то ни другое (подтвердить одним числом, например x = 1).

**Мини-пример.** f(x) = x² на отрезке [−3; 5]: точка 5 есть, а −5 нет — область несимметрична, функция ни чётная, ни нечётная.

### Шаг 5. Быстрый признак для многочлена

**Суть.** У многочлена всё решают показатели степеней. Свободный член считаем слагаемым чётной степени (x⁰).

**Наглядно.** Обвести кружком каждый показатель степени в многочлене и посмотреть: все кружки чётные, все нечётные или смесь.

**Правило.**
> Только чётные степени (и, может быть, свободный член) — функция чётная: 2x⁴ − x² + 7. Только нечётные степени и нет свободного члена — нечётная: x⁵ − 3x³, 5x. Есть и чётные, и нечётные (или нечётные плюс число) — ни то ни другое: x³ + x², x³ + 1.

**Мини-пример.** x⁶ − 2x² — чётная; x³ − x — нечётная; x⁴ + x³ — ни то ни другое.

### Шаг 6. Значение в отрицательной точке (главный тип В9)

**Суть.** В задании формулу дают только для x > 0 (или x ≥ 0). Для отрицательного числа формулу напрямую применять **нельзя**: сначала переходим к положительному числу, считаем там, потом возвращаем знак.

**Наглядно.** Схема на доске в три клетки: «f(−4)» → «−f(4)» → «считаю f(4) по формуле» → «меняю знак».

**Правило.**
> Нечётная: f(−a) = −f(a). Чётная: f(−a) = f(a). Сначала заменить каждое f(отрицательное) на f(положительное) со знаком, затем считать по формуле. f(0) у нечётной функции — всегда 0.

**Мини-пример.** f нечётная, при x > 0 f(x) = x² − 5x. f(−2) = −f(2) = −(4 − 10) = −(−6) = 6.

### Шаг 7. Корни нечётной функции

**Суть.** Если f(a) = 0, то у нечётной функции f(−a) = −0 = 0. Значит, каждый положительный корень даёт «зеркальный» отрицательный корень, а корень 0 — один, пары у него нет.

**Наглядно.** Отметить на оси Ox корни при x ≥ 0 (например, 0, 2, 5) и «отразить» их через ноль: появляются −2 и −5. Ноль отражается сам в себя.

**Правило.**
> Число корней нечётной функции на всей прямой = 2 · (число положительных корней) + 1 (за x = 0, у нечётной функции, определённой в нуле, он есть всегда).

**Мини-пример.** При x ≥ 0 f(x) = x(x − 2)(x − 5): корни 0, 2, 5. Положительных — 2, всего 2·2 + 1 = 5 корней: −5, −2, 0, 2, 5.

### Шаг 8. Периодическая функция

**Суть.** Функция периодическая, если её график — «забор» из одинаковых кусков: кусок длиной T повторяется снова и снова вправо и влево. Сдвинулись по x на T (или на 2T, 3T, −T) — значение то же самое.

**Наглядно.** Нарисовать на доске ломаную «пилу»: на отрезке [0; 4] она поднимается из (0; 0) в (2; 2) и опускается в (4; 0), и этот же «зубец» копируется на [4; 8], [8; 12], [−4; 0]. Подписать: T = 4 — длина одного зубца.

**Правило.**
> f периодическая с периодом T ≠ 0, если f(x + T) = f(x) для любого x из области определения (и x + T тоже в ней). Тогда f(x + kT) = f(x) для любого целого k. Алгоритм: чтобы найти f(большое число), «снимаем» целое число периодов, пока не попадём в точку, где значение известно. Проверка: разность «искомая точка − известная точка» делится на T нацело.

**Мини-пример.** Период 4, f(1) = 3. f(13): 13 − 1 = 12 = 3·4, значит f(13) = f(1) = 3. f(−7): −7 − 1 = −8 = −2·4, значит f(−7) = 3.

### Шаг 9. Периодичность вместе с нечётностью

**Суть.** Если функция и нечётная, и периодическая, то сначала периодом подгоняем аргумент к ближайшему известному числу (часто это −a), а потом нечётностью меняем знак.

**Наглядно.** Числовая прямая с отметками через каждые T: от искомой точки идём «шагами по T» к нулю, пока не окажемся рядом с известной точкой.

**Правило.**
> f нечётная, период T, известно f(a). Тогда f(−a + kT) = f(−a) = −f(a).

**Мини-пример.** f нечётная, период 4, f(1) = 3. f(7): 7 − 8 = −1, f(7) = f(−1) = −f(1) = −3.

### Чего сейчас не объясняем

- Свойства чётности суммы и произведения функций («нечётная · нечётная = чётная») — в В9 не нужны, только перегружают.
- Наименьший положительный период и доказательство, что число T именно период, — на ЦТ период почти всегда дан в условии.
- Чётность и период тригонометрических функций — в карточках M13 и M14, там это проговаривается на своих формулах.
- Чётность функций с модулем, дробями и корнями — после того, как алгоритм уверенно работает на многочленах; алгоритм тот же.

## Опорный конспект

| Понятие | Правило | Пример |
|---|---|---|
| f(−x) | подставить (−x) в скобках | x³ − 2x → −x³ + 2x |
| Знак степени | (−x)^чётн = x^чётн; (−x)^нечётн = −x^нечётн | (−x)⁴ = x⁴; (−x)³ = −x³ |
| Чётная | f(−x) = f(x); симметрия относительно Oy | x⁴ − 3x² |
| Нечётная | f(−x) = −f(x); симметрия относительно O; f(0) = 0 | x³ + 5x |
| Ни то ни другое | правило ломается хотя бы на одном числе | x² + x: f(1) = 2, f(−1) = 0 |
| Область определения | должна быть симметрична относительно 0 | x² на [−3; 5] — ни то ни другое |
| Многочлен | только чётные степени — чётная; только нечётные без числа — нечётная | x³ + 1 — ни то ни другое |
| Значение (В9) | f(−a) = −f(a) (нечётная), f(−a) = f(a) (чётная) | f(−2) = −f(2) |
| Корни нечётной | 2 · (положительные корни) + 1 | корни 0, 2, 5 → 5 корней |
| Период T | f(x + kT) = f(x), k — целое | T = 4: f(13) = f(1) |

**Образец оформления задачи В9.**
1) f(−4) = −f(4) (функция нечётная).
2) f(4) = 4² − 6·4 + 5 = −3, значит f(−4) = 3.
3) Аналогично f(−3) = −f(3) = −(9 − 18 + 5) = 4.
4) f(−4) + 2·f(−3) = 3 + 8 = 11. Ответ: 11.

## Разобранные примеры

### Пример 1 (уровень 1). Определите, чётная, нечётная или ни то ни другое: а) f(x) = x⁴ − 3x²; б) g(x) = x³ + 5x; в) h(x) = x² + x

а) f(−x) = (−x)⁴ − 3(−x)² = x⁴ − 3x² = f(x). **Чётная.**
б) g(−x) = (−x)³ + 5(−x) = −x³ − 5x = −(x³ + 5x) = −g(x). **Нечётная.**
в) h(−x) = x² − x — не равно ни h(x), ни −h(x). Проверка числом: h(1) = 2, h(−1) = 0; 0 ≠ 2 и 0 ≠ −2. **Ни то ни другое.**

### Пример 2 (уровень 1). Функция f чётная, f(3) = 7. Функция g нечётная, g(2) = 5 и определена на всей прямой. Найдите f(−3), g(−2), g(0)

f(−3) = f(3) = 7. g(−2) = −g(2) = −5. g(0) = 0 (у нечётной функции, определённой в нуле). **Ответ: 7; −5; 0.**

### Пример 3 (уровень 2). Функция f периодическая с периодом 4, f(1) = 3. Найдите f(13) и f(−7)

1) 13 − 1 = 12 = 3·4 — целое число периодов, значит f(13) = f(1) = 3.
2) −7 − 1 = −8 = (−2)·4 — тоже целое число периодов, значит f(−7) = f(1) = 3.
**Ответ: 3; 3.**

### Пример 4 (уровень 3, формат В9). Нечётная функция y = f(x) определена на всей числовой прямой. При x > 0 f(x) = x² − 6x + 5. Найдите значение выражения f(−4) + 2·f(−3)

1) Формула дана только для x > 0, поэтому переходим к положительным числам: f(−4) = −f(4), f(−3) = −f(3).
2) f(4) = 16 − 24 + 5 = −3, значит f(−4) = 3.
3) f(3) = 9 − 18 + 5 = −4, значит f(−3) = 4.
4) f(−4) + 2·f(−3) = 3 + 2·4 = 11.
**Ответ: 11.**

Ловушка: подставить −4 прямо в формулу: 16 + 24 + 5 = 45. Формула для x > 0 к отрицательным числам не относится.

### Пример 5 (уровень 3, формат В9). Нечётная функция y = f(x) определена на всей числовой прямой. Для всякого неотрицательного x её значение совпадает со значением g(x) = x(x − 2)(x − 5). Сколько корней имеет уравнение f(x) = 0?

1) При x ≥ 0 корни g(x) = 0: x = 0, x = 2, x = 5 (каждый множитель приравниваем к нулю).
2) Нечётность: f(−2) = −f(2) = 0, f(−5) = −f(5) = 0. Появились корни −2 и −5.
3) Корень 0 своей пары не имеет: −0 = 0.
4) Всего: −5, −2, 0, 2, 5 — пять корней (2·2 + 1 = 5).
**Ответ: 5.**

Ловушка: ответить 6, посчитав корень 0 дважды, или 3, забыв отрицательные корни.

### Пример 6 (уровень 2, формат части А). Укажите номер нечётной функции

1) y = x³ + x²  2) y = x⁴ − x  3) y = x³ − 4x  4) y = x² + 3  5) y = x³ + 1

**Решение.** Быстрый признак для многочлена: нужны только нечётные степени и нет свободного члена. Подходит только 3): x³ и x — нечётные степени, числа нет. Проверка: f(−x) = −x³ + 4x = −(x³ − 4x). **Ответ: 3.**

**Разбор неверных вариантов.**
- 1) x³ + x² — смесь степеней 3 и 2: f(1) = 2, f(−1) = 0 — ни то ни другое;
- 2) x⁴ − x — смесь степеней 4 и 1: f(1) = 0, f(−1) = 2 — ни то ни другое;
- 4) x² + 3 — только чётная степень и число: это **чётная** функция — ловушка для того, кто путает слова «чётная» и «нечётная»;
- 5) x³ + 1 — нечётная степень плюс число: f(1) = 2, f(−1) = 0 — ни то ни другое; ловушка для того, кто смотрит только на старшую степень.

Ученику: в части А проверь выбранный вариант двумя числами 1 и −1 — это 20 секунд и страховка от ловушки.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Подставляет отрицательное число в формулу «для x > 0» | f(−4) = 16 + 24 + 5 = 45 | обвести в условии «при x > 0»; первая строка решения всегда «f(−4) = −f(4)» |
| Теряет минус при подстановке −x | (−x)³ записывает как x³ | подставлять только в скобках; проверить числом x = 2 |
| Путает правила чётной и нечётной | для нечётной пишет f(−3) = f(3) | запомнить: «НЕчётная — меНяет знак» |
| Забывает поменять знак у отрицательного результата | f(2) = −6, а f(−2) записывает как −6 | писать отдельной строкой: f(−2) = −(−6) = 6 |
| Считает x³ + 1 нечётной по старшей степени | смотрит только на x³ | обводить все степени, свободный член — чётная степень; проверить f(1) и f(−1) |
| Неверно считает корни нечётной функции | корень 0 считает дважды или теряет отрицательные корни | рисовать корни на оси и отражать через 0; формула 2·n + 1 |
| В периоде делит неверно | для f(13) при T = 4 и f(1) = 3 ищет 13 : 4 | считать разность 13 − 1 = 12, проверить, делится ли она на T |
| Не проверяет область определения | x² на [−3; 5] называет чётной | первый шаг алгоритма: «есть ли −x для каждого x?» |

## Домашняя работа по теме

Тема идёт на уроке 25 вместе с M14, на M32 отведено около 25–30 минут урока (шаги 1–3 и 6–8 обязательно, шаги 4, 5, 9 — по времени, иначе дома по конспекту). На самостоятельную работу — 3 часа за неделю.
