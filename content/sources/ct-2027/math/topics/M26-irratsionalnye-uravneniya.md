# M26. Иррациональные уравнения

## Зачем эта тема

**Тема уровня C: изучается, только если план идёт с опережением.** В поурочном плане её нет; если к урокам 27–29 все темы уровней A и B усвоены, M26 даётся дома (≈ 3 часа) как продолжение M20.

Позиция В15 ЦТ — иррациональное уравнение с заменой, ответ — целое число, 2 балла. Решают около 21 % участников. Замену t = √x ученик уже знает из M20; здесь добавляется второй инструмент — возведение в квадрат с обязательной проверкой. Для ученика: *«Два правила: под корнем не меньше нуля, и после возведения в квадрат каждый корень проверить подстановкой. Это бонусные 2 балла, которых нет у четырёх человек из пяти».*

## Результат: после темы ученик умеет

- [ ] выписывать ОДЗ корня: подкоренное выражение ≥ 0 (√(6 − 2x) существует при x ≤ 3);
- [ ] решать √A = число: при числе < 0 корней нет, иначе возвести в квадрат (√(x − 4) = 3 → x = 13);
- [ ] решать √A = √B: A = B и проверка A ≥ 0 (√(2x − 1) = √(x + 2) → x = 3);
- [ ] решать √A = B: условие B ≥ 0, возведение в квадрат, проверка (√(x + 7) = x + 1 → x = 2, корень −3 посторонний);
- [ ] уединять корень перед возведением в квадрат (x = 1 + √(x + 11) → x = 5);
- [ ] делать замену t = √(выражение), t ≥ 0, в формате В15 (x² − 3x + √(x² − 3x) = 6 → x = 4; −1).

## Входная проверка (5 минут)

| № | Вопрос | Ответ | Что проверяет |
|---|---|---|---|
| 1 | Вычислите √49 и (√7)² | 7; 7 | определение корня (M07) |
| 2 | Существует ли √(−4)? | нет | подкоренное ≥ 0 (M07) |
| 3 | Раскройте (x − 3)² | x² − 6x + 9 | квадрат разности (M10) |
| 4 | Решите x² − 7x + 6 = 0 | 1; 6 | квадратное уравнение (M19) |

Всё верно — шаги 1–2 читаем бегло, сразу шаг 3. Ошибки в №1–2 — сначала M07 (шаги 1–3); в №3–4 — повторить M10 и M19, иначе после возведения в квадрат уравнение не решится.

## Теория: сценарий объяснения

### Шаг 1. Что такое иррациональное уравнение и ОДЗ корня

**Суть.** «Иррациональное — значит x сидит под корнем. √a — это неотрицательное число, квадрат которого равен a. Поэтому под корнем не может быть минус, и сам корень не бывает отрицательным».

**Правило.** (На доске в столбик: √9 = 3, √0 = 0, √(−9) — зачеркнуть.)
> ОДЗ: каждое подкоренное выражение ≥ 0. √A = отрицательное число — корней нет сразу.

**Мини-пример.** √(3x + 1) = −2: корень не бывает отрицательным. Ответ: корней нет.

### Шаг 2. √A = число и √A = √B

**Суть.** «Чтобы убрать корень, возводим обе части в квадрат: (√A)² = A».

**Правило.**
> √A = c, c ≥ 0 ⇔ A = c². √A = √B ⇔ A = B и A ≥ 0 (тогда и B ≥ 0).

**Мини-пример.** √(2x − 1) = √(x + 2) → 2x − 1 = x + 2 → x = 3. Проверка: 2 · 3 − 1 = 5 ≥ 0. Ответ: 3.

### Шаг 3. √A = B и посторонние корни

**Суть.** «Квадрат не различает знаки: 3² = (−3)² = 9. Поэтому после возведения в квадрат может появиться лишний корень — тот, при котором правая часть отрицательная. Его называют посторонним». На доске: «√9 = 3 — верно; √9 = −3 — неверно, но в квадрате оба дают 9 = 9».

**Правило (алгоритм).**
> 1. Уединить корень: √A = B.
> 2. Условие B ≥ 0 (корень не бывает отрицательным).
> 3. Возвести в квадрат: A = B².
> 4. Решить (обычно квадратное уравнение, M19).
> 5. **Проверка:** подставить каждый корень в исходное уравнение, посторонние вычеркнуть.

**Мини-пример.** √(x + 7) = x + 1. Условие x ≥ −1. x + 7 = x² + 2x + 1, x² + x − 6 = 0, x = 2 или x = −3. x = −3 < −1 — посторонний (√4 = 2, а справа −2). Ответ: 2.

### Шаг 4. Замена t = √(выражение) — формат В15

**Суть.** «Если под корнем стоит то же выражение, что и рядом с корнем, обозначаем корень буквой t. Тогда выражение = t² − число, и получается квадратное уравнение».

**Правило.**
> t = √(…), **t ≥ 0**. Решить уравнение в t, отрицательные t отбросить, вернуться к x: (…) = t².

**Мини-пример.** x² − 3x + √(x² − 3x) = 6. t = √(x² − 3x) ≥ 0: t² + t − 6 = 0, t = 2 (t = −3 отбрасываем). x² − 3x = 4 → x = 4 или x = −1. Ответ: −1; 4.

### Чего сейчас не объясняем

- Уравнения с двумя корнями (√A + √B = c, двойное возведение в квадрат) — долго и ошибкоопасно, для В15 не нужно.
- Иррациональные неравенства, корни n-й степени в уравнениях, равносильные переходы без проверки — не берём: проверка подстановкой надёжнее при слабой базе.

## Опорный конспект

| Тип | Что делаем | Пример → ответ |
|---|---|---|
| √A = отрицательное | корней нет | √(3x + 1) = −2 → нет корней |
| √A = c, c ≥ 0 | A = c² | √(x − 4) = 3 → 13 |
| √A = √B | A = B, проверить A ≥ 0 | √(2x − 1) = √(x + 2) → 3 |
| √A = B | B ≥ 0, A = B², проверка | √(x + 7) = x + 1 → 2 |
| x и √(…) с тем же выражением | t = √(…), t ≥ 0 | x² − 3x + √(x² − 3x) = 6 → −1; 4 |

**Образец оформления** — пример 2: первая строка «Условие: …», последняя — «Проверка: …» и «Ответ: …».

| Вопрос | Ответ |

| ОДЗ уравнения с √A? | A ≥ 0 |
| Может ли √A быть отрицательным? | нет, √A ≥ 0 |
| Что проверить в √A = B до возведения в квадрат? | B ≥ 0 |

| Какая замена в x² − 3x + √(x² − 3x) = 6? | t = √(x² − 3x), t ≥ 0 |

## Разобранные примеры

### Пример 1 (уровень 1). Решите уравнение √(2x + 3) = 3

ОДЗ: 2x + 3 ≥ 0. Правая часть 3 ≥ 0, возводим в квадрат: 2x + 3 = 9, x = 3. Проверка: √9 = 3. **Ответ: 3.**

### Пример 2 (уровень 2). Решите уравнение √(x + 3) = x − 3

Условие: x − 3 ≥ 0, то есть x ≥ 3. Возводим в квадрат: x + 3 = x² − 6x + 9, x² − 7x + 6 = 0, по Виету x = 1 или x = 6.
x = 1 не подходит под x ≥ 3: √4 = 2, а 1 − 3 = −2. x = 6: √9 = 3 = 6 − 3. **Ответ: 6.**

### Пример 3 (уровень 3, формат В15 — ответ целым числом)

Решите уравнение x² − 4x + √(x² − 4x + 11) = 9. В ответ запишите сумму квадратов корней.

Пусть t = √(x² − 4x + 11), t ≥ 0. Тогда x² − 4x = t² − 11, уравнение: t² − 11 + t = 9, t² + t − 20 = 0, t = 4 или t = −5 (отбрасываем, t ≥ 0).
Обратная замена: x² − 4x + 11 = 16, x² − 4x − 5 = 0, x = 5 или x = −1.
Проверка: x = 5: 25 − 20 + √16 = 5 + 4 = 9; x = −1: 1 + 4 + √16 = 9. Сумма квадратов: 25 + 1 = 26. **Ответ: 26.** (Неверный ответ 16 — это t², а не сумма квадратов x.)

### Пример 4 (уровень 2, формат ЦТ часть А — 5 вариантов ответа)

Сумма корней уравнения √(5 − x) = x + 1 равна:

1) −3 2) 1 3) −4 4) 5 5) уравнение не имеет корней

**Решение.** Условие: x + 1 ≥ 0, x ≥ −1. Возводим в квадрат: 5 − x = x² + 2x + 1, x² + 3x − 4 = 0, x = 1 или x = −4.
x = −4 < −1 — посторонний (√9 = 3, а справа −3). x = 1: √4 = 2 = 1 + 1. Единственный корень 1. **Ответ: вариант 2 (1).**

**Разбор неверных вариантов.**
- 1) −3 — сумма по Виету без проверки: 1 + (−4). Главная ловушка темы.
- 3) −4 — оставили посторонний корень, потеряли настоящий.
- 4) 5 — «решили» 5 − x = 0, забыв правую часть.
- 5) — выбросили оба корня; проверка x = 1 показывает, что он подходит.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Не проверил корни после возведения в квадрат | Пример 2: ответ «1; 6» | Последняя строка решения — «Проверка:» с подстановкой каждого корня |
| Возвёл в квадрат, не уединив корень | x = 1 + √(x + 11) → x² = 1 + x + 11 | Сначала √(…) один в левой части, всё остальное — вправо |
| Квадрат двучлена как сумма квадратов | (x + 1)² = x² + 1 | Всегда (a + b)² = a² + 2ab + b², средний член проговаривать |
| Не отбросил t < 0 | t = −5 → «x² − 4x + 11 = 25» | Рядом с заменой писать «t ≥ 0» и подчёркивать |
| Забыл ОДЗ в произведении | (x + 1)√(x − 2) = 0 → «−1; 2» | При x = −1 под корнем −3 — корень не существует |
| Ответ в t, а не в x | Пример 3: ответ 16 | Последняя строка обязана содержать x |

## Домашняя работа по теме

Только при опережении плана, ≈ 3 часа на неделю, 4 дня по 45 минут. Порог усвоения: ≥ 80 % верных в блоке A.

- **A. Новое (~40 %, 14–16 задач):** день 1 — типы 1–3 (по 2); день 2 — типы 4–6 (по 2); день 3 — типы 7–8 (по 2–3); день 4 — типы 9–10 (по 2). Каждое решение с условием (ОДЗ или B ≥ 0) первой строкой и проверкой последней.
- **B. Повторение (~25 %, 5–6 задач):** M20 (замена t = √x, биквадратные), M19 (Виет), M07 (свойства корня).
- **C. Формат ЦТ (~20 %, 3–4 задания):** 2 задания части А с посторонним корнем (как пример 4), 1–2 задания В15 (как пример 3).
- **D–E. Карточки и теория (~15 %):** 6 карточек в колоду; переписать по памяти алгоритм шага 3.
- **Самопроверка:** ответы к блоку A прилагаются; ошибки — в журнал, отдельно «не проверил корень». Задачи — РЕШУ ЦТ (reshuct.by), «Уравнения и неравенства».

## Связи

- **Опирается на:** M07 (определение и свойства корня, √a ≥ 0), M19 (квадратное уравнение после возведения в квадрат или замены, теорема Виета). Полезна M20 (замена t = √x).
- **Нужна для:** позиции В15; в графе тем на M26 больше ничего не опирается.
