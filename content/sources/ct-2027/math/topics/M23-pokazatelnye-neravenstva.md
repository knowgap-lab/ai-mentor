# M23. Показательные неравенства

## Зачем эта тема

**Тема изучается, только если план идёт с опережением.** Это уровень C: в поурочном плане для неё нет урока, она целиком уходит в домашку (≈3 часа) и берётся, лишь когда темы уровней A и B уже усвоены и остаётся запас времени.

Тема даёт задание **В18** ЦТ («показательное неравенство, метод интервалов»), его решает ≈10,7 % выпускников. Это 2 первичных балла «всё или ничего», ответ — целое число: количество целых решений, наибольшее или наименьшее целое решение. Для 60–70 баллов В18 не нужно, но если В6 (M22) и метод интервалов (M21) уже идут уверенно, простые варианты В18 — реальный шанс на лишние 2 балла.

Новых идей почти нет: приведение к одному основанию и замена t = aˣ — из M22, метод интервалов и отбор целых — из M21. Добавляется одно правило: **при основании меньше 1 знак неравенства переворачивается**. Для ученика: *«Это то же показательное уравнение, только вместо „=“ стоит „>“. Одна новая мысль: посмотреть на основание. Больше единицы — знак оставляем, меньше единицы — переворачиваем»*.

## Результат: после темы ученик умеет

- [ ] решать простейшее неравенство с основанием a > 1, сохраняя знак (2^x > 8 → x > 3);
- [ ] решать неравенство с основанием 0 < a < 1, переворачивая знак ((1/3)^x ≥ 9 → x ≤ −2);
- [ ] приводить дробное основание к целому через отрицательный показатель (0,5^(x−1) < 4 → 2^(1−x) < 2² → x > −1);
- [ ] выносить общий множитель-степень (3^(x+1) + 3^x ≤ 108 → 4·3^x ≤ 108 → x ≤ 3);
- [ ] решать неравенство заменой t = aˣ с условием t > 0 (4^x − 9·2^x + 8 ≤ 0 → 1 ≤ t ≤ 8 → 0 ≤ x ≤ 3);
- [ ] решать неравенство с квадратным показателем методом интервалов из M21 и считать целые решения (2^(x²−3x) ≤ 1/4 → 1 ≤ x ≤ 2 → 2 целых).

## Входная проверка (5 минут)

| № | Вопрос | Ответ | Что проверяет |
|---|---|---|---|
| 1 | Решите 2^x = 16 | x = 4 | простейшее показательное уравнение (M22) |
| 2 | Решите (1/3)^x = 9 | x = −2 | основание-дробь, отрицательный показатель (M22) |
| 3 | Решите −2x > 6 | x < −3 | переворот знака при делении на отрицательное (M17) — та же идея, что в шаге 2 |
| 4 | Решите x² − 3x + 2 ≤ 0 | 1 ≤ x ≤ 2 | квадратное неравенство, метод интервалов (M21) |
| 5 | Сколько целых чисел в промежутке (−2; 3]? | 5 (−1, 0, 1, 2, 3) | счёт целых с учётом скобок (M21) |

Всё верно — теорию шагов 1–2 даём за 5 минут и сразу переходим к замене и квадратному показателю. Ошибка в №1–2 — сначала вернуться к M22, без него тема не пойдёт. Ошибка в №4–5 — повторить метод интервалов из M21; если и это не помогает, тему уровня C откладываем.

## Теория: сценарий объяснения

### Шаг 1. Основание больше 1: знак сохраняется

**Суть.** y = 2^x растёт: чем больше показатель, тем больше значение (2¹ = 2, 2² = 4, 2³ = 8, 2⁴ = 16). Поэтому «2^x больше, чем 2³» значит ровно «x больше, чем 3». **Наглядно.** Столбик степеней двойки: вверх — показатель растёт, и число растёт. Нарисовать возрастающую кривую y = 2^x и горизонталь y = 8: кривая выше горизонтали правее точки x = 3.

> При a > 1: a^(f(x)) > a^(g(x)) ⟺ f(x) > g(x). Знак **тот же** (для <, ≥, ≤ — так же).

**Мини-пример.** 2^x > 8 → 2^x > 2³ → x > 3.

### Шаг 2. Основание от 0 до 1: знак переворачивается

**Суть.** y = (1/2)^x убывает: (1/2)¹ = 1/2, (1/2)² = 1/4, (1/2)³ = 1/8 — показатель больше, число меньше. Значит, большему значению степени соответствует **меньший** показатель, и знак меняется на противоположный. **Наглядно.** Рядом со столбиком двойки — столбик (1/2)^x: числа идут вниз. Сравнить с тем, как при делении на −2 переворачивается знак (входная проверка, №3): «стрелки» показателя и значения направлены в разные стороны.

> При 0 < a < 1: a^(f(x)) > a^(g(x)) ⟺ f(x) **<** g(x). Знак **переворачивается**.
> Второй способ (надёжнее для этого ученика): переписать основание через целое, (1/3)^x = 3^(−x), и решать уже с основанием 3 > 1, не переворачивая ничего.

**Мини-пример.** (1/3)^x ≥ 9. Способ 1: 9 = (1/3)^(−2), основание < 1 → x ≤ −2. Способ 2: 3^(−x) ≥ 3² → −x ≥ 2 → x ≤ −2 (переворот при делении на −1). Ответы совпали. **Ловушка (сказать вслух).** Переворачиваем знак из-за **основания**, а не из-за минуса в показателе или в правой части. Перед переходом к показателям всегда спросить: «основание больше единицы или меньше?»

### Шаг 3. Приведение к одному основанию и вынесение множителя

**Суть.** Всё как в M22 (шаги 3–4): 4 = 2², 0,5 = 2⁻¹, 3^(x+1) = 3·3^x. Отличие одно — в конце неравенство, а не равенство.

> 0,5^(x−1) < 4 → 2^(−(x−1)) < 2² → 1 − x < 2 → x > −1.
> 3^(x+1) + 3^x ≤ 108 → 3^x(3 + 1) ≤ 108 → 3^x ≤ 27 = 3³ → x ≤ 3 (делим на положительное 4 — знак не меняется).

### Шаг 4. Замена t = aˣ

**Суть.** 4^x − 9·2^x + 8 ≤ 0 — квадратное неравенство относительно t = 2^x. Решаем его методом интервалов (M21), помним, что t > 0, и возвращаемся к x по шагу 1.

> t² − 9t + 8 ≤ 0 → (t − 1)(t − 8) ≤ 0 → 1 ≤ t ≤ 8 → 2⁰ ≤ 2^x ≤ 2³ → 0 ≤ x ≤ 3.
> Если интервал для t заходит в отрицательные (например, −5 ≤ t ≤ 9), левую границу заменяем на t > 0: остаётся 0 < t ≤ 9 → 3^x ≤ 9 → x ≤ 2 (условие 3^x > 0 выполнено всегда).

### Шаг 5. Квадратный показатель и метод интервалов (формат В18)

**Суть.** Если в показателе x², после приведения к одному основанию получаем квадратное неравенство для показателей — его решаем методом интервалов из M21 и считаем целые точки.

> 2^(x² − 3x) ≤ 1/4 = 2⁻² → x² − 3x ≤ −2 → x² − 3x + 2 ≤ 0 → (x − 1)(x − 2) ≤ 0 → 1 ≤ x ≤ 2 → целые 1, 2 → **2 целых решения**.
> Произведение со степенью: (x − 4)(3^x − 9) ≤ 0. Знак 3^x − 9 совпадает со знаком x − 2 (основание 3 > 1), поэтому решаем (x − 4)(x − 2) ≤ 0 → 2 ≤ x ≤ 4 → 3 целых. При основании < 1 знак множителя противоположный: 0,5^x − 4 ≥ 0 ⟺ x ≤ −2.

### Чего сейчас не объясняем

- Неравенства с основанием-переменной (x^(…) > …) и с параметром — вне ЦТ для этого ученика.
- Неравенства вида 2^x > 5 с ответом через логарифм (x > log₂5) — в В18 ответ целый, такие границы почти не встречаются; при необходимости — после M25.

## Опорный конспект

| Ситуация | Правило | Пример |
|---|---|---|
| a > 1 | знак сохраняется | 2^x > 2³ → x > 3 |
| 0 < a < 1 | знак переворачивается | (1/2)^x > (1/2)³ → x < 3 |
| Дробное основание | (1/a)^x = a^(−x), дальше как при a > 1 | (1/3)^x ≥ 9 → 3^(−x) ≥ 3² → x ≤ −2 |
| Сумма степеней | вынести aˣ, разделить на положительный коэффициент | 3^(x+1) + 3^x = 4·3^x |
| Замена | t = aˣ, t > 0; решить для t, вернуться к x | 1 ≤ 2^x ≤ 8 → 0 ≤ x ≤ 3 |
| Квадратный показатель | метод интервалов для показателей (M21) | x² − 3x + 2 ≤ 0 → [1; 2] |

**Алгоритм.** 1) Привести к одному основанию. 2) Посмотреть на основание: > 1 — знак тот же, < 1 — перевернуть. 3) Решить неравенство для показателей (линейное или методом интервалов). 4) Записать промежуток, отметить скобки. 5) Ответить на вопрос задачи: посчитать целые или взять наибольшее целое.

**Образец оформления.** 4^x − 9·2^x + 8 ≤ 0: t = 2^x > 0; t² − 9t + 8 ≤ 0; корни 1 и 8; 1 ≤ t ≤ 8; 2⁰ ≤ 2^x ≤ 2³; основание 2 > 1 → 0 ≤ x ≤ 3; целые 0, 1, 2, 3. **Количество целых решений: 4.**

## Разобранные примеры

### Пример 1 (уровень 1). Решите 2^(x−1) > 8

8 = 2³ → 2^(x−1) > 2³. Основание 2 > 1, знак сохраняем: x − 1 > 3 → x > 4. **Ответ: (4; +∞).**

### Пример 2 (уровень 2). Найдите наибольшее целое решение неравенства (1/3)^(2x−1) ≥ 27

1) (1/3)^(2x−1) = 3^(−(2x−1)) = 3^(1−2x); 27 = 3³.
2) 3^(1−2x) ≥ 3³, основание 3 > 1: 1 − 2x ≥ 3 → −2x ≥ 2 → x ≤ −1 (делим на −2 — знак переворачиваем).
3) Наибольшее целое в (−∞; −1] — это −1. **Ответ: −1.**

### Пример 3 (уровень 3, формат В18). Найдите количество целых решений неравенства 4^x − 9·2^x + 8 ≤ 0

1) t = 2^x, t > 0: t² − 9t + 8 ≤ 0. По Виета корни 1 и 8, ветви вверх → 1 ≤ t ≤ 8 (все такие t положительны).
2) 2⁰ ≤ 2^x ≤ 2³, основание 2 > 1 → 0 ≤ x ≤ 3.
3) Целые: 0, 1, 2, 3. **Ответ: 4.**

### Пример 4 (формат части А). Количество целых решений неравенства (1/2)^(x² − 2x) > 1/8 равно:

1) 2  2) 3  3) 4  4) 5  5) бесконечно много

**Решение.** 1/8 = (1/2)³. Основание 1/2 < 1 → знак переворачиваем: x² − 2x < 3 → x² − 2x − 3 < 0 → (x − 3)(x + 1) < 0 → −1 < x < 3. Целые: 0, 1, 2. **Верный вариант — 2).**

**Разбор неверных вариантов:**
- 1) 2 — посчитали только натуральные 1 и 2, потеряли 0;
- 3) 4 — включили конец −1, хотя неравенство строгое;
- 4) 5 — включили оба конца −1 и 3;
- 5) бесконечно много — не перевернули знак: x² − 2x > 3 даёт два бесконечных луча.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Не переворачивают знак при основании < 1 | (1/2)^x > 1/8 «→» x > 3 | перед переходом к показателям вслух назвать основание; проверка: x = 4 → 1/16 < 1/8, значит x > 3 неверно |
| Переворачивают знак из-за минуса, а не из-за основания | 2^(−x) > 4 «→» −x < 2 | основание 2 > 1 — знак тот же: −x > 2 → x < −2; переворот только при делении на −1 |
| Сравнивают показатели при разных основаниях | 4^x > 8 «→» x > 8 или x > 3 | сначала одно основание: 2^(2x) > 2³ → x > 1,5 |
| Забывают t > 0 после замены | −5 ≤ t ≤ 9 «→» ищут x для t = −5 | 3^x всегда положительно: левую границу заменить на t > 0 |
| Неверно считают целые на промежутке | (−1; 3) «→» 5 целых | выписать все целые подряд и отдельно проверить каждый конец по скобке |

Даётся, только если план идёт с опережением, вместо части блока C обычной недели (общий бюджет 5–7 ч на математику не превышается). Всего ≈3 часа, по дням:

- **День 2 (≈1 ч, блок A).** 8–10 задач типов 5–8: вынесение множителя, квадратный показатель, замена. После каждой — подстановка одного целого изнутри и одного снаружи ответа.
- **День 3 (≈1 ч, блоки C + B).** 4–5 задач типов 9–10 в формате В18 (ответ — одно целое число) и 4–6 задач повторения вперемешку: M22 (показательные уравнения, В6), M21 (метод интервалов), M24 (логарифмические уравнения).

**Самопроверка.** Ответы отдельным файлом; ученик сверяет и заносит ошибки в журнал. Разбор — в блоке «Разбор ДЗ» ближайшего урока, не больше 5 минут: тема уровня C не должна отнимать время у тем A и B. **Источники задач:** учебник «Алгебра, 11 класс» (РБ), глава о показательных неравенствах; РЕШУ ЦТ, раздел «Показательные неравенства»; демонстрационные варианты РИКЗ, позиция В18.
