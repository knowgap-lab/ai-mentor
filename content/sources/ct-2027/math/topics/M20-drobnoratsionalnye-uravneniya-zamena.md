# M20. Дробно-рациональные уравнения и замена переменной

## Зачем эта тема

Позиция В15 ЦТ — уравнение с заменой переменной (в последних вариантах иррациональное). Его решают около 21 % участников, ответ — целое число, задание из части В. Сама замена переменной — главный инструмент этой темы: увидеть повторяющийся кусок, обозначить его буквой t, решить квадратное уравнение и вернуться к x.

Кроме того, без этой темы не пойдут: метод интервалов для дробей (M21), показательные и логарифмические уравнения с заменой t = 2ˣ, t = log₂x (M22, M24), текстовые задачи, где неизвестное стоит в знаменателе (M28), иррациональные уравнения (M26).

Для ученика: *«Здесь всего два правила: знаменатель не ноль и вернуться от t к x. Кто их не забывает, тот берёт задание, которое не решают четыре человека из пяти».*

## Результат: после темы ученик умеет

- [ ] выписывать ОДЗ дробного уравнения: все знаменатели ≠ 0 (для (x + 1)/(x² − 9) — x ≠ 3, x ≠ −3);
- [ ] решать уравнение «дробь равна нулю»: числитель = 0, знаменатель ≠ 0 ((x² − 4)/(x − 2) = 0 → x = −2);
- [ ] решать пропорцию с x в знаменателе перекрёстным умножением (3/(x − 1) = 6/(x + 1) → x = 3);
- [ ] приводить к общему знаменателю, домножать на него и отбрасывать посторонние корни (x/(x − 1) − 2/(x + 1) = 4/(x² − 1) → корень −1 посторонний, ответ 2);
- [ ] решать биквадратное уравнение заменой t = x², t ≥ 0 (x⁴ − 3x² − 4 = 0 → t = 4, t = −1 отбрасываем → x = ±2);
- [ ] делать замену повторяющегося выражения и обратную замену ((x² − x)² − 8(x² − x) + 12 = 0 → x = −2, −1, 2, 3);
- [ ] делать замену t = x + 1/x и t = x/(x − 1) (x/(x − 1) + (x − 1)/x = 5/2 → x = 2, x = −1);
- [ ] делать замену t = √x, t ≥ 0 — мостик к В15 (x + √x − 6 = 0 → t = 2, t = −3 отбрасываем → x = 4).

## Входная проверка (5 минут)

| № | Вопрос | Ответ | Что проверяет |
|---|---|---|---|
| 1 | Решите x² − 5x + 6 = 0 | 2; 3 | квадратное уравнение (M19) |
| 2 | При каком x не имеет смысла дробь 3/(x − 2)? | x = 2 | смысл знаменателя |
| 3 | Сократите (x² − 9)/(x − 3) | x + 3 (при x ≠ 3) | разложение и сокращение (M11) |
| 4 | Общий знаменатель дробей 1/x и 1/(x − 1) | x(x − 1) | общий знаменатель (M11) |
| 5 | Решите x² = 16 и x⁴ = 16 | ±4; ±2 | извлечение корня, «два знака» |

Всё верно — шаги 1–3 проходим за 5 минут, сразу к шагам 4–6. Ошибки в №1 — сначала повторить M19 (дискриминант, теорема Виета); ошибки в №3–4 — повторить M11, иначе общий знаменатель не получится.

## Теория: сценарий объяснения

### Шаг 1. Что такое дробно-рациональное уравнение и ОДЗ

**Суть.** «Дробно-рациональное — значит x сидит в знаменателе. На ноль делить нельзя, поэтому прежде чем решать, выписываем, каким x быть нельзя. Это и есть ОДЗ — область допустимых значений».

**Наглядно.** Нарисовать на доске числовую прямую и выколоть точки, где знаменатель обращается в ноль, — пустые кружочки. «Корень, попавший в кружок, — не корень».

**Правило.**
> ОДЗ: каждый знаменатель ≠ 0. Найти: приравнять знаменатель к нулю, решить, написать «x ≠ …».
> ОДЗ пишем **первой строкой** решения, до любых преобразований.

**Мини-пример.** (x + 3)/(x − 1) = 2. ОДЗ: x ≠ 1. Домножаем на (x − 1): x + 3 = 2x − 2, x = 5. 5 ≠ 1 — подходит. Ответ: 5.

### Шаг 2. Дробь равна нулю

**Суть.** «Дробь равна нулю, когда делить нечего: в числителе ноль. Знаменатель при этом не должен быть нулём».

**Наглядно.** 0/5 = 0, 0/(−3) = 0, а 0/0 — «не число». Написать три записи в столбик и зачеркнуть третью.

**Правило.**
> A/B = 0 ⇔ A = 0 и B ≠ 0.

**Мини-пример.** (x² − 4)/(x − 2) = 0. Числитель: x = 2 или x = −2. Знаменатель: x ≠ 2. Ответ: −2.

### Шаг 3. Пропорция с x в знаменателе

**Суть.** «Две дроби равны — умножаем крест-накрест, как в пропорции 2/3 = 4/6: 2 · 6 = 3 · 4».

**Наглядно.** Нарисовать крест между дробями стрелками.

**Правило.**
> a/b = c/d, b ≠ 0, d ≠ 0 ⇔ a · d = b · c.

**Мини-пример.** 3/(x − 1) = 6/(x + 1). ОДЗ: x ≠ 1, x ≠ −1. 3(x + 1) = 6(x − 1), 3x + 3 = 6x − 6, x = 3. Ответ: 3.

### Шаг 4. Общий знаменатель и посторонние корни

**Суть.** «Если дробей несколько, приводим их к общему знаменателю и умножаем обе части на него — дроби исчезают, остаётся обычное уравнение. Но умножение на выражение с x может подарить лишний корень — тот, где знаменатель был нулём. Такой корень называют посторонним и вычёркивают».

**Наглядно.** Таблица на доске: корень → подставляю в знаменатели → «≠ 0, оставляю» или «= 0, вычёркиваю».

**Правило (алгоритм).**
> 1. Разложить знаменатели на множители (x² − 4 = (x − 2)(x + 2)).
> 2. Выписать ОДЗ.
> 3. Найти общий знаменатель, умножить на него **каждое** слагаемое обеих частей.
> 4. Решить получившееся линейное или квадратное уравнение.
> 5. Сверить корни с ОДЗ, посторонние вычеркнуть.
> 6. Записать ответ (если всё вычеркнули — «корней нет»).

**Мини-пример.** 1/(x − 2) + 1/(x + 2) = 4/(x² − 4). ОДЗ: x ≠ ±2. Умножаем на (x − 2)(x + 2): (x + 2) + (x − 2) = 4, 2x = 4, x = 2. Но x = 2 вне ОДЗ — посторонний. Ответ: корней нет.

### Шаг 5. Замена переменной: биквадратное уравнение

**Суть.** «Если в уравнении одна и та же штука стоит несколько раз, называем её одной буквой. x⁴ = (x²)², поэтому x⁴ − 5x² + 4 = 0 — это квадратное уравнение относительно x²».

**Наглядно.** Обвести x² в уравнении кружком, рядом написать t. Под ним две стрелки: «решаем для t» → «возвращаемся к x».

**Правило.**
> ax⁴ + bx² + c = 0: замена t = x², **t ≥ 0**. Решаем at² + bt + c = 0.
> t < 0 — отбрасываем; t = 0 → x = 0; t > 0 → x = ±√t (два корня).

**Мини-пример.** x⁴ − 5x² + 4 = 0. t² − 5t + 4 = 0, t = 1 или t = 4 (Виет). x² = 1 → x = ±1; x² = 4 → x = ±2. Ответ: −2; −1; 1; 2.

### Шаг 6. Замена t = x + 1/x и взаимно обратные дроби

**Суть.** «Ищем выражение, которое повторяется, — даже если оно дробное. x + 1/x встретилось дважды — это t. Дроби x/(x − 1) и (x − 1)/x перевёрнуты друг к другу — это t и 1/t».

**Наглядно.** Над уравнением подписать: «t = x + 1/x», ниже уравнение в t, ниже два маленьких уравнения для x.

**Правило.**
> 1. Выбрать t, записать «Пусть t = …».
> 2. Решить уравнение в t (обычно квадратное).
> 3. **Обратная замена**: для каждого t решить уравнение относительно x.
> 4. Проверить ОДЗ исходного уравнения (x ≠ 0, знаменатели ≠ 0).

**Мини-пример.** 2(x + 1/x)² − 9(x + 1/x) + 10 = 0. t = x + 1/x: 2t² − 9t + 10 = 0, D = 81 − 80 = 1, t = 2 или t = 5/2.
x + 1/x = 2 → x² − 2x + 1 = 0 → x = 1. x + 1/x = 5/2 → 2x² − 5x + 2 = 0 → x = 2 или x = 1/2. Ответ: 1/2; 1; 2.

Полезно знать: x + 1/x = 1 корней не имеет (x² − x + 1 = 0, D = −3 < 0) — при обратной замене такое t просто не даёт корней.

### Шаг 7. Замена t = √x — дорога к В15

**Суть.** «x = (√x)², значит x − 5√x + 6 = 0 — квадратное уравнение для √x. Корень квадратный не бывает отрицательным, поэтому t ≥ 0».

**Наглядно.** Тот же кружок, что в шаге 5, только вокруг √x.

**Правило.**
> ОДЗ: x ≥ 0. t = √x, t ≥ 0, x = t². Отрицательные t отбрасываем, из t ≥ 0 находим x = t².

**Мини-пример.** x + √x − 6 = 0. t² + t − 6 = 0, t = 2 или t = −3 (отбрасываем). √x = 2, x = 4. Ответ: 4.

### Чего сейчас не объясняем

- Неравенства с дробями и метод интервалов — M21: там нельзя просто умножать на знаменатель.
- Иррациональные уравнения общего вида (√(x + 3) = x − 3, возведение в квадрат) — M26; здесь только замена t = √x.
- Показательные и логарифмические уравнения с заменой t = 2ˣ, t = log₂x — M22, M24: алгоритм тот же, ограничения на t другие.
- Уравнения с параметром, уравнения третьей степени и выше без замены — не берём.

## Опорный конспект

| Тип уравнения | Что делаем | Пример → ответ |
|---|---|---|
| A/B = 0 | A = 0 и B ≠ 0 | (x² − 4)/(x − 2) = 0 → −2 |
| a/b = c/d | ad = bc, b ≠ 0, d ≠ 0 | 3/(x − 1) = 6/(x + 1) → 3 |
| Сумма дробей | ОДЗ → общий знаменатель → решить → сверить с ОДЗ | 1/(x − 2) + 1/(x + 2) = 4/(x² − 4) → нет корней |
| ax⁴ + bx² + c = 0 | t = x², t ≥ 0 | x⁴ − 5x² + 4 = 0 → ±1; ±2 |
| Повторяющееся выражение | t = это выражение → обратная замена | (x² − x)² − 8(x² − x) + 12 = 0 → −2; −1; 2; 3 |
| x + 1/x встречается дважды | t = x + 1/x | 2t² − 9t + 10 = 0 → 1/2; 1; 2 |
| x/(x − 1) и (x − 1)/x | t + 1/t = … | → 2; −1 |
| x и √x | t = √x, t ≥ 0 | x + √x − 6 = 0 → 4 |

**Алгоритм «дробное уравнение» (переписать себе):** 1) разложить знаменатели; 2) ОДЗ; 3) умножить каждое слагаемое на общий знаменатель; 4) решить; 5) сверить с ОДЗ; 6) ответ.

**Алгоритм «замена»:** 1) найти повторяющийся кусок; 2) «Пусть t = …», условие на t (t ≥ 0 для x² и √x); 3) решить в t; 4) отбросить неподходящие t; 5) обратная замена; 6) ОДЗ исходного уравнения; 7) ответ — в x, не в t.

**Образец оформления.**

```
x/(x − 1) − 2/(x + 1) = 4/(x² − 1)
ОДЗ: x ≠ 1, x ≠ −1.
| · (x − 1)(x + 1)
x(x + 1) − 2(x − 1) = 4
x² + x − 2x + 2 − 4 = 0
x² − x − 2 = 0  →  x = 2, x = −1
x = −1 ∉ ОДЗ — посторонний.
Ответ: 2.
```

## Разобранные примеры

### Пример 1 (уровень 1). Решите уравнение (2x − 1)/(x + 3) = 1

ОДЗ: x ≠ −3. Умножаем обе части на (x + 3): 2x − 1 = x + 3, x = 4. Проверка: 4 ≠ −3, подходит. Подстановка: (8 − 1)/(4 + 3) = 7/7 = 1. **Ответ: 4.**

### Пример 2 (уровень 2). Решите уравнение (x² − x − 6)/(x − 3) = 0

Дробь равна нулю ⇔ числитель = 0 и знаменатель ≠ 0.
Числитель: x² − x − 6 = 0, по Виету x₁ + x₂ = 1, x₁ · x₂ = −6 → x = 3 или x = −2.
Знаменатель: x ≠ 3, поэтому x = 3 вычёркиваем. **Ответ: −2.**

Ученику: «Сократить и написать x + 2 = 0 тоже можно, но только если ты помнишь, что x ≠ 3. Безопаснее всегда выписывать ОДЗ».

### Пример 3 (уровень 2). Решите уравнение x/(x − 1) − 2/(x + 1) = 4/(x² − 1)

1) x² − 1 = (x − 1)(x + 1) — это и есть общий знаменатель.
2) ОДЗ: x ≠ 1, x ≠ −1.
3) Умножаем каждое слагаемое: x(x + 1) − 2(x − 1) = 4.
4) x² + x − 2x + 2 − 4 = 0, x² − x − 2 = 0, x = 2 или x = −1.
5) x = −1 не входит в ОДЗ — посторонний. **Ответ: 2.**

Обратить внимание на знак: −2(x − 1) = −2x + 2, а не −2x − 2.

### Пример 4 (уровень 2). Решите биквадратное уравнение x⁴ − 3x² − 4 = 0

Пусть t = x², t ≥ 0. Тогда t² − 3t − 4 = 0, по Виету t = 4 или t = −1.
t = −1 < 0 — отбрасываем (квадрат не бывает отрицательным).
x² = 4 → x = 2 или x = −2. **Ответ: −2; 2.**

Проверка: 16 − 12 − 4 = 0 для обоих корней (чётные степени, знак не важен).

### Пример 5 (уровень 3, формат части В — ответ целым числом)

Решите уравнение 2(x + 1/x)² − 9(x + 1/x) + 10 = 0. В ответ запишите сумму всех корней, умноженную на 2.

ОДЗ: x ≠ 0. Пусть t = x + 1/x. Тогда 2t² − 9t + 10 = 0, D = 81 − 80 = 1, t = (9 ± 1)/4: t = 5/2 или t = 2.
Обратная замена:
- x + 1/x = 2 → умножаем на x: x² − 2x + 1 = 0 → (x − 1)² = 0 → x = 1;
- x + 1/x = 5/2 → умножаем на 2x: 2x² − 5x + 2 = 0, D = 25 − 16 = 9, x = (5 ± 3)/4 → x = 2 или x = 1/2.

Все три корня ≠ 0. Сумма: 1 + 2 + 1/2 = 7/2, умножить на 2 → 7. **Ответ: 7.**

Типичный неверный ответ: 9 — записали 2 · (2 + 5/2), то есть сумму t, а не x.

### Пример 6 (уровень 3, формат ЦТ часть А — 5 вариантов ответа)

Сумма корней уравнения x/(x − 2) − 8/(x² − 4) = 1/(x + 2) равна:

1) −1 2) −3 3) 2 4) 1 5) уравнение не имеет корней

**Решение.** x² − 4 = (x − 2)(x + 2). ОДЗ: x ≠ 2, x ≠ −2.
Умножаем каждое слагаемое на (x − 2)(x + 2): x(x + 2) − 8 = x − 2.
x² + 2x − 8 − x + 2 = 0, x² + x − 6 = 0, x = 2 или x = −3.
x = 2 вне ОДЗ — посторонний. Остаётся x = −3, сумма корней равна −3. **Ответ: вариант 2 (−3).**

**Разбор неверных вариантов.**
- 1) −1 — сумма по Виету для x² + x − 6 = 0 без проверки ОДЗ: 2 + (−3). Самая частая ловушка темы.
- 4) 1 — та же ошибка плюс неверный знак в теореме Виета (x₁ + x₂ = −b, а не b).
- 3) 2 — оставили посторонний корень и потеряли настоящий.
- 5) «нет корней» — выбросили оба корня, решив, что −3 тоже обнуляет знаменатель; проверка: (−3)² − 4 = 5 ≠ 0.

Ученику: в варианты ЦТ специально кладут ответ «без проверки ОДЗ». Если корень из квадратного уравнения совпадает с числом из ОДЗ — его нельзя записывать.

| Не выписал ОДЗ и оставил посторонний корень | Пример 3: ответ «2; −1» | ОДЗ — первая строка решения; в конце подставить каждый корень в знаменатели |
| Домножил не все слагаемые | x + 6/x = 5 → x + 6 = 5x | Стрелками от общего знаменателя к **каждому** слагаемому, в том числе к целым числам |
| Потерял знак перед дробью | x(x + 1) − 2(x − 1) → x² + x − 2x − 2 | Сначала скобка со знаком: −2(x − 1) = −2x + 2 |
| Сократил дробь и забыл ограничение | (x² − x − 6)/(x − 3) = 0 → x + 2 = 0, а потом и x = 3 «тоже» | Записать x ≠ 3 до сокращения |
| Не отбросил отрицательное t при t = x² или t = √x | x² = −1 → «x = ±1» | Рядом с заменой сразу писать «t ≥ 0» и подчёркивать |
| Взял один знак при x² = t | x² = 4 → x = 2 | Проговаривать «квадрат — два корня, плюс и минус» |
| Забыл обратную замену | Ответ «t = 2; 5/2» вместо x | Последняя строка обязана содержать x; в формате В ответ про корни x |
| Посчитал совпавший корень дважды | Тип 15: сумма −3 + 1 + (−1) + (−1) = −4 | Выписать корни списком без повторов перед подсчётом |

## Домашняя работа по теме

Всего ≈ 4 часа на неделю после урока 26, по дням (понедельник — пятница по 45–50 минут). Порог усвоения: ≥ 80 % верных в блоке A и выходной тест урока 3/3.

- **A. Новое (~40 %, 20–24 задачи, по возрастанию):** пн — типы 1–4 (по 2 задачи); вт — типы 5–8 (по 1 задаче); ср — типы 9–13 (по 1 задаче); чт — типы 14–17 (по 1 задаче); пт — типы 18–19 (по 1 задаче), всего 23. Каждое решение — с ОДЗ первой строкой и проверкой корней в конце.
- **B. Повторение (~25 %, 6–8 задач вперемешку):** темы из поля review урока 26 (M36, M37, M34, M14) и опоры M19 (квадратные уравнения, Виет), M11 (разложение знаменателей).
- **C. Формат ЦТ (~20 %, 4–6 заданий):** 2 задания части А с ловушкой «посторонний корень» (как пример 6), 2–3 задания части В с заменой (как пример 5, типы 14–15), плюс 1 задание по пройденным темам.
- **D. Карточки (~10 %):** добавить 12 карточек из «Опорного конспекта» в колоду, 10–15 минут в день.
- **E. Теория (~5 %):** перечитать опорный конспект и переписать по памяти оба алгоритма — «дробное уравнение» и «замена».
- **Самопроверка:** ответы к блоку A прилагаются; каждую ошибку — в журнал ошибок (задача → что сделал → в чём ошибка → верная идея), отдельно отмечать «забыл ОДЗ» и «забыл обратную замену».
- **Источники задач:** учебник «Алгебра, 8 класс» (РБ) — дробно-рациональные уравнения; «Алгебра, 9 класс» (РБ) — биквадратные уравнения и замена переменной; РЕШУ ЦТ (math-ct.sdamgia.ru), раздел «Уравнения и неравенства» (рациональные уравнения, уравнения с заменой).
