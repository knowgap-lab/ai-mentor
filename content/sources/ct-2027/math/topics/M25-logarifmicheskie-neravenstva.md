# M25. Логарифмические неравенства

## Зачем эта тема

Логарифмическое неравенство с заменой — это задание **В14** части В: 2 балла, в ЦЭ-2025 его решили 34 % выпускников. Приоритет темы — B: это резерв роста от 60 к 70 баллам. Задание выглядит страшно, но собрано из двух уже знакомых кусков: логарифмы и замена t = log_a x из M24 плюс метод интервалов из M21. Новых идей ровно две: **ОДЗ остаётся навсегда** (в неравенстве её нельзя «проверить в конце» подстановкой) и **основание меньше 1 переворачивает знак**.

Для ученика: *«Треть выпускников решает это задание. Если научишься всегда писать ОДЗ и смотреть на основание, ты попадёшь в эту треть — это 2 балла, которых у большинства нет»*.

## Результат: после темы ученик умеет

- [ ] выписывать ОДЗ неравенства до решения и решать её как систему (log_3(x + 4) + log_3(5 − x): −4 < x < 5);
- [ ] решать простейшее неравенство с основанием больше 1, сохраняя знак (log_2(x − 1) < 3 → 1 < x < 9);
- [ ] решать простейшее неравенство с основанием от 0 до 1, меняя знак на противоположный (log_{1/3}(x + 2) ≥ −2 → −2 < x ≤ 7);
- [ ] сравнивать два логарифма с одинаковым основанием и переходить к неравенству для аргументов (log_{0,2}(x − 1) > log_{0,2}(7 − x) → x − 1 < 7 − x);
- [ ] сворачивать сумму логарифмов и решать получившееся квадратное неравенство вместе с ОДЗ (log_3(x − 2) + log_3(x − 4) ≤ 1 → 4 < x ≤ 5);
- [ ] решать неравенство с заменой t = log_a x методом интервалов и возвращаться от t к x ((log_2 x)² − 3log_2 x − 4 ≤ 0 → 1/2 ≤ x ≤ 16);
- [ ] давать ответ в формате В14: число целых решений, наибольшее или наименьшее целое, сумму целых решений.

## Входная проверка (5 минут)

| № | Вопрос | Ответ | Что проверяет |
|---|---|---|---|
| 1 | При каких x имеет смысл log_2(x − 3)? | x > 3 | ОДЗ логарифма (M12, M24) |
| 2 | Запишите 3 как логарифм по основанию 2 | 3 = log_2 8 | число → логарифм (M24, шаг 5) |
| 3 | log_{1/2} 4 = ? | −2 | логарифм с основанием меньше 1 (M12) |
| 4 | Решите (x − 1)(x − 5) < 0. Сколько целых решений? | 1 < x < 5; три (2, 3, 4) | метод интервалов (M21) |
| 5 | Что больше: log_{1/2} 2 или log_{1/2} 4? | log_{1/2} 2 = −1 больше, чем −2 | интуиция «убывающего» логарифма |

Всё верно, включая №5, — шаги 1–3 даём за 3 минуты и сразу переходим к замене (шаг 5). Ошибки в №1–2 — сначала повторить ОДЗ и свёртку из M24. Ошибка в №4 — 5 минут метода интервалов (M21, шаги 3 и 5) перед шагом 5. Ошибка в №5 — это нормально, ради неё и есть шаг 3.

## Теория: сценарий объяснения

### Шаг 1. Чем неравенство отличается от уравнения

**Суть.** В уравнении мы находили несколько чисел и каждое проверяли по ОДЗ подстановкой. В неравенстве ответ — промежуток, в нём бесконечно много чисел, подставить их все нельзя. Поэтому ОДЗ не «проверяется в конце», а **решается вместе с неравенством как система**: ответ = пересечение решения неравенства и ОДЗ.

**Наглядно.** Рисуем две числовые прямые одну под другой: на верхней — штриховка ОДЗ, на нижней — штриховка решения «без логарифмов». Ответ — там, где штриховки перекрываются (как в M17 для систем линейных неравенств).

**Правило.**
> Алгоритм: 1) ОДЗ (каждое выражение под log > 0); 2) привести к виду log_a f(x) ∨ log_a g(x) или log_a f(x) ∨ b; 3) посмотреть на основание и снять логарифмы (шаг 2 или 3); 4) решить; 5) пересечь с ОДЗ; 6) ответить на вопрос задачи (целые решения).

**Мини-пример.** log_2(x − 1) < 3. ОДЗ: x > 1. Без логарифмов: x − 1 < 8, x < 9. Пересечение: 1 < x < 9.

### Шаг 2. Основание больше 1: знак сохраняется

**Суть.** При основании больше 1 логарифм «растёт»: чем больше число, тем больше его логарифм (log_2 2 = 1, log_2 4 = 2, log_2 8 = 3). Значит, сравнивать логарифмы — то же самое, что сравнивать числа под ними. Знак неравенства не меняется.

**Наглядно.** Нарисовать график y = log_2 x: кривая идёт вверх слева направо, «в горку». Чем правее x, тем выше точка.

**Правило.**
> a > 1: log_a f(x) > log_a g(x) ⟺ f(x) > g(x) (и ОДЗ: f(x) > 0, g(x) > 0).
> Число справа сначала превращаем в логарифм: b = log_a(a^b).

**Мини-пример.** log_5(2x − 1) ≤ 1 = log_5 5 → 2x − 1 ≤ 5 → x ≤ 3; ОДЗ: x > 1/2. Ответ: 1/2 < x ≤ 3, целых решений три (1, 2, 3).

### Шаг 3. Основание от 0 до 1: знак меняется

**Суть.** При основании меньше 1 всё наоборот: log_{1/2} 2 = −1, log_{1/2} 4 = −2, log_{1/2} 8 = −3 — число растёт, а логарифм уменьшается. Поэтому большему логарифму соответствует **меньшее** число, и при снятии логарифмов знак переворачивается. Это ровно та же история, что умножение неравенства на отрицательное число в M17: что-то «переворачивает» порядок — переворачиваем и знак.

**Наглядно.** График y = log_{1/2} x идёт вниз, «с горки». Положить рядом два графика: log_2 x вверх, log_{1/2} x вниз — они зеркальны относительно оси Ox.

**Правило.**
> 0 < a < 1: log_a f(x) > log_a g(x) ⟺ f(x) < g(x) (и ОДЗ: f(x) > 0, g(x) > 0).
> Основания 0,5; 0,2; 1/3; 0,1 — сигнал «переверни знак». Обвести основание кружком, прежде чем снимать логарифм.

**Мини-пример.** log_{1/3}(x + 2) ≥ −2 = log_{1/3} 9 → x + 2 ≤ 9 (знак перевернули!) → x ≤ 7; ОДЗ: x > −2. Ответ: −2 < x ≤ 7.

**Ловушка (сказать вслух).** Отрицательное число справа (−2) знак не переворачивает. Переворачивает только основание меньше 1. Знак числа справа ни на что не влияет.

### Шаг 4. Свёртка и квадратное неравенство

**Суть.** Если слева сумма логарифмов, сворачиваем её в один логарифм произведения (M12, M24), снимаем логарифмы и получаем квадратное неравенство — его решаем по M21. ОДЗ здесь особенно важна: после свёртки выражение x(x − 2) положительно и там, где оба множителя отрицательны, а исходные логарифмы там не существуют.

**Алгоритм.**
1. ОДЗ для **каждого** исходного логарифма отдельно (не для свёрнутого!).
2. Свернуть, число справа записать как логарифм.
3. Снять логарифмы с учётом основания.
4. Решить квадратное неравенство (корни → парабола или интервалы).
5. Пересечь с ОДЗ на одной прямой.

**Мини-пример.** log_6 x + log_6(x − 1) ≤ 1. ОДЗ: x > 1. Свёртка: x(x − 1) ≤ 6 → x² − x − 6 ≤ 0 → (x − 3)(x + 2) ≤ 0 → −2 ≤ x ≤ 3. С ОДЗ: 1 < x ≤ 3.

### Шаг 5. Замена t = log_a x и метод интервалов

**Суть.** Это и есть задание В14. Если log_a x стоит в квадрате и в первой степени, обозначаем t = log_a x. Получаем квадратное неравенство относительно t, решаем его методом интервалов (M21), а потом **каждую** границу для t переводим в границу для x.

**Алгоритм.**
1. ОДЗ: x > 0 (или то, что стоит под логарифмом, > 0).
2. t = log_a x; переписать неравенство через t.
3. Корни квадратного трёхчлена, интервалы, знаки → промежуток для t (например, −1 ≤ t ≤ 4).
4. Возврат: −1 ≤ log_a x ≤ 4. При a > 1: a^(−1) ≤ x ≤ a^4. При 0 < a < 1 знаки обоих концов переворачиваются: a^4 ≤ x ≤ a^(−1).
5. Пересечь с ОДЗ, ответить на вопрос (целые решения).

**Мини-пример.** (log_3 x)² − 3log_3 x + 2 < 0. t² − 3t + 2 < 0 → (t − 1)(t − 2) < 0 → 1 < t < 2 → 3 < x < 9. Целых решений пять: 4, 5, 6, 7, 8.

**Ловушка (сказать вслух).** Ответ на t — это не ответ. Если t ≤ −1 или t ≥ 3, то при основании 2 это 0 < x ≤ 1/2 или x ≥ 8 — левый кусок начинается с нуля (ОДЗ!), а не с минус бесконечности.

### Шаг 6. Как считать целые решения

**Суть.** Ответ В14 — одно целое число. Чаще всего спрашивают «сколько целых решений», «наибольшее целое», «сумма целых решений».

**Правило.**
> Число целых на отрезке [m; n] равно n − m + 1. Строгие концы (круглая скобка) не считаем. Дробные концы округляем внутрь: [1/2; 16] → целые от 1 до 16, это 16 чисел.
> Сумма целых от m до n: (m + n) · (n − m + 1) / 2 — формула суммы арифметической прогрессии (M34).

**Мини-пример.** [1/4; 8] → целые 1, …, 8: восемь штук, сумма (1 + 8) · 8 / 2 = 36.

### Чего сейчас не объясняем

- Неравенства с переменной в основании (log_x 5 > 1) — нужен разбор двух случаев, в ЦТ на нашем уровне не встречается.
- Метод рационализации (замена log_a f − log_a g на (a − 1)(f − g)) — удобен, но для слабого ученика это ещё одно правило, которое легко применить неверно.
- Показательные неравенства (M23) — тот же принцип про основание, тема уровня C.

## Опорный конспект

| Ситуация | Что делаем | Пример |
|---|---|---|
| Любое неравенство | сначала ОДЗ: всё под log > 0 | log_3(x + 4) + log_3(5 − x): −4 < x < 5 |
| Число справа | b = log_a(a^b) | 3 = log_2 8; −2 = log_{1/3} 9 |
| a > 1 | знак сохраняем | log_2(x − 1) < 3 → x − 1 < 8 |
| 0 < a < 1 | знак переворачиваем | log_{1/3}(x + 2) ≥ −2 → x + 2 ≤ 9 |
| Сумма логарифмов | свернуть, квадратное неравенство, пересечь с ОДЗ | log_6 x + log_6(x − 1) ≤ 1 → 1 < x ≤ 3 |
| log² и log | t = log_a x, метод интервалов, возврат к x | 1 < t < 2 → 3 < x < 9 |
| Целые на [m; n] | n − m + 1 | [1; 16] → 16 |

**Образец оформления (В14).**
1. ОДЗ: x > 0.
2. Замена: t = log_2 x; t² − 3t − 4 ≤ 0.
3. Корни: t = −1, t = 4; парабола ветвями вверх → −1 ≤ t ≤ 4.
4. Возврат: −1 ≤ log_2 x ≤ 4; основание 2 > 1, знак сохраняем → 1/2 ≤ x ≤ 16.
5. С ОДЗ: 1/2 ≤ x ≤ 16. Целые: 1, …, 16. **Ответ: 16.**

## Разобранные примеры

### Пример 1 (уровень 1). Сколько целых решений у неравенства log_2(x − 1) < 3?

ОДЗ: x − 1 > 0 → x > 1. Число справа: 3 = log_2 8. Основание 2 > 1 — знак сохраняем: x − 1 < 8 → x < 9. Пересечение с ОДЗ: 1 < x < 9. Концы строгие, целые: 2, 3, …, 8. **Ответ: 7.**

### Пример 2 (уровень 1). Сколько целых решений у неравенства log_{1/3}(x + 2) ≥ −2?

ОДЗ: x + 2 > 0 → x > −2. Число справа: −2 = log_{1/3}((1/3)^(−2)) = log_{1/3} 9. Основание 1/3 < 1 — знак переворачиваем: x + 2 ≤ 9 → x ≤ 7. Пересечение: −2 < x ≤ 7. Целые: −1, 0, 1, …, 7 — это 7 − (−1) + 1 = 9 чисел. **Ответ: 9.**

Типичная ошибка: не перевернуть знак → x ≥ 7, «бесконечно много решений». Ответ «бесконечно много» в В14 — сигнал перепроверить основание.

### Пример 3 (уровень 2). Найдите наибольшее целое решение неравенства log_3(x − 2) + log_3(x − 4) ≤ 1

1) ОДЗ: x − 2 > 0 и x − 4 > 0 → x > 4.
2) Свёртка: log_3[(x − 2)(x − 4)] ≤ log_3 3.
3) Основание 3 > 1: (x − 2)(x − 4) ≤ 3 → x² − 6x + 8 ≤ 3 → x² − 6x + 5 ≤ 0 → (x − 1)(x − 5) ≤ 0 → 1 ≤ x ≤ 5.
4) С ОДЗ: 4 < x ≤ 5. Единственное целое — 5. **Ответ: 5.**

Без ОДЗ получился бы отрезок [1; 5], и ученик ответил бы «5» правильно случайно — но в вопросе «число целых решений» он написал бы 5 вместо 1. ОДЗ — по каждому исходному логарифму, а не по свёрнутому (x − 2)(x − 4) > 0, иначе в ответ попал бы кусок 1 ≤ x < 2.

### Пример 4 (уровень 3, замена). Сколько целых решений у неравенства (log_2 x)² − 3log_2 x − 4 ≤ 0?

1) ОДЗ: x > 0.
2) t = log_2 x: t² − 3t − 4 ≤ 0. Корни по Виету: t = 4 и t = −1 (сумма 3, произведение −4).
3) Метод интервалов: на прямой t точки −1 и 4, знаки «+ − +» → −1 ≤ t ≤ 4.
4) Возврат: −1 ≤ log_2 x ≤ 4 → 2^(−1) ≤ x ≤ 2^4 → 1/2 ≤ x ≤ 16 (основание 2 > 1, знаки сохранены).
5) С ОДЗ x > 0 ничего не меняется. Целые: 1, 2, …, 16. **Ответ: 16.**

### Пример 5 (уровень 3, формат В14). Найдите сумму целых решений неравенства (log_{0,5} x)² + log_{0,5} x − 6 ≤ 0

1) ОДЗ: x > 0.
2) t = log_{0,5} x: t² + t − 6 ≤ 0 → (t + 3)(t − 2) ≤ 0 → −3 ≤ t ≤ 2.
3) Возврат: −3 ≤ log_{0,5} x ≤ 2. Основание 0,5 < 1 — оба знака переворачиваются: x ≤ 0,5^(−3) = 8 и x ≥ 0,5² = 1/4. Итого 1/4 ≤ x ≤ 8.
4) Целые: 1, 2, …, 8. Сумма: (1 + 8) · 8 / 2 = 36. **Ответ: 36.**

Проверка точкой: x = 1 → t = 0 → 0 + 0 − 6 = −6 ≤ 0, верно; x = 16 → t = −4 → 16 − 4 − 6 = 6 > 0, не входит — сходится с ответом.

### Пример 6 (уровень 2, формат части А)

Множество решений неравенства log_{0,2}(x − 1) > log_{0,2}(7 − x) — это:

1) (1; 4)  2) (4; 7)  3) (−∞; 4)  4) (4; +∞)  5) (1; 7)

**Решение.** 1) ОДЗ: x − 1 > 0 и 7 − x > 0 → 1 < x < 7. 2) Основание 0,2 < 1 — знак меняем: x − 1 < 7 − x → 2x < 8 → x < 4. 3) Пересечение с ОДЗ: 1 < x < 4. **Ответ: 1) (1; 4).**

**Разбор неверных вариантов.**
- 2) (4; 7) — не перевернули знак (x − 1 > 7 − x → x > 4), но ОДЗ учли;
- 3) (−∞; 4) — знак перевернули, но забыли ОДЗ;
- 4) (4; +∞) — обе ошибки сразу;
- 5) (1; 7) — выписали только ОДЗ и на этом остановились.

Ученику: каждый вариант — это конкретная ошибка. Если твой ответ совпал с одним из них, проверь две вещи: основание и ОДЗ. Проверка точкой: x = 2 → log_{0,2} 1 = 0 и log_{0,2} 5 = −1; 0 > −1 — верно, значит 2 входит в ответ, и варианты 2) и 4) отпадают сразу.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Не меняет знак при основании меньше 1 | log_{1/3}(x + 2) ≥ −2 → x + 2 ≥ 9 | Обвести основание кружком до снятия логарифма; проверка точкой из ответа |
| Меняет знак из-за отрицательного числа справа | log_2(x − 1) < −1 → x − 1 > 1/2 | Правило: знак решает только основание; число справа ни при чём |
| Забывает ОДЗ, ответ уходит в минус бесконечность | log_{0,2}(x − 1) > log_{0,2}(7 − x) → x < 4 | ОДЗ — первая строка решения, ответ — пересечение на рисунке с двумя прямыми |
| Пишет ОДЗ по свёрнутому выражению | log_3(x − 2) + log_3(x − 4): берёт (x − 2)(x − 4) > 0 | ОДЗ строится по исходной записи, по каждому логарифму отдельно |
| Записывает ответ для t вместо x | −1 ≤ t ≤ 4, пишет «целых решений 6» | Отдельная строка «возврат к x:»; t — промежуточная буква |
| При возврате путает степень и умножение | −1 ≤ log_2 x → x ≥ −2 | log_2 x = −1 значит x = 2^(−1) = 1/2 (M12, шаг 1) |
| При 0 < a < 1 переворачивает только один конец двойного неравенства | −3 ≤ log_{0,5} x ≤ 2 → 8 ≤ x ≤ 1/4 (пустое множество) | Разбить на два неравенства и перевернуть каждое; меньшее число всегда пишем слева |
| Ошибается в счёте целых | [1/2; 16] → «15» или «17» | Формула n − m + 1 по крайним целым; для малых ответов выписать числа подряд |
