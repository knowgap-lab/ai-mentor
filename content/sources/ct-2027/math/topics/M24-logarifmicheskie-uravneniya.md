# M24. Логарифмические уравнения

## Зачем эта тема

Логарифмические уравнения — это задание **В11** части В: 2 балла, решает 59,5 % выпускников — задание среднего уровня, доступное при аккуратной работе, а не только сильным ученикам. Приоритет темы — A, то есть это обязательные баллы в копилку к цели 60–70.

Тема целиком строится на свойствах логарифма из M12 (без них не свернуть уравнение в простое) и на квадратных уравнениях из M19 (без них не решить уравнение после замены переменной). Взамен она открывает путь к M25 (логарифмические неравенства — тот же набор приёмов плюс метод интервалов) и к M33 (графики логарифмической функции).

Для ученика: *«Ты уже умеешь превращать несколько логарифмов в один (M12). Логарифмическое уравнение — это та же работа плюс одно новое правило: раз логарифмы равны, значит равны и числа под ними. И есть одна привычка, которую нужно поставить железно: в конце — всегда проверка по ОДЗ, иначе 2 балла превращаются в 0 из-за одного лишнего корня»*.

## Результат: после темы ученик умеет

- [ ] находить ОДЗ логарифмического уравнения до того, как начал его решать (каждое выражение под логарифмом строго больше нуля);
- [ ] решать простейшее уравнение log_a f(x) = b, переходя к f(x) = a^b (log_2(x + 3) = 4 → x = 13);
- [ ] решать уравнение вида log_a f(x) = log_a g(x), переходя к f(x) = g(x) с проверкой по ОДЗ (log_7(x + 2) = log_7(3x − 4) → x = 3);
- [ ] сворачивать сумму или разность логарифмов в один логарифм перед решением (log_3 x + log_3(x − 2) = 1 → x(x − 2) = 3);
- [ ] заносить числовой коэффициент перед логарифмом внутрь как степень, когда это нужно для свёртки (2 log_2 x − log_2(x + 3) = log_2 4 → x²/(x + 3) = 4);
- [ ] решать уравнение с заменой t = log_a x, сводя его к квадратному уравнению (M19), и возвращаться от t к x ((log_2 x)² − log_2 x − 2 = 0 → x = 4 или x = 1/2);
- [ ] проверять каждый найденный корень по ОДЗ и отбрасывать посторонние, объясняя вслух, почему корень не подходит;
- [ ] решать задание в формате ЦТ В11 и получать ответ целым числом.

## Входная проверка (5 минут)

| № | Вопрос | Ответ | Что проверяет |
|---|---|---|---|
| 1 | При каких x определён log_5(x − 3)? | x > 3 | ОДЗ логарифма (M12) |
| 2 | log_2 32 = ? | 5 | вычисление логарифма по определению (M12) |
| 3 | log_3 x + log_3 y = ? (одним логарифмом) | log_3(xy) | свойство произведения (M12) |
| 4 | Решите x² − 2x − 8 = 0 | x = 4 или x = −2 | квадратное уравнение, теорема Виета (M19) |
| 5 | Если log_2 a = log_2 b, что можно сказать про a и b? | a = b | идея простейшего логарифмического уравнения |

Все верно, особенно №5 (ключевая идея уже понятна без формального названия) — теорию (шаги 1–3) даём за 3–4 минуты и быстрее переходим к сложным видам (шаги 4–7). Ошибки в №1–3 — сначала 5 минут повторить M12 (ОДЗ и свойства логарифма), иначе сегодняшняя тема не держится. Ошибка в №4 — повторить теорему Виета (M19) перед шагом 6.

## Теория: сценарий объяснения

### Шаг 1. Что такое логарифмическое уравнение

**Суть.** Логарифмическое уравнение — это уравнение, где неизвестное x стоит под знаком логарифма (внутри него или в основании). Мы будем решать только те, где x — под логарифмом, а основание — обычное число. Задача всегда одна: убрать знаки логарифма и получить обычное уравнение относительно x, которое мы уже умеем решать (линейное или квадратное).

**Наглядно.** Логарифм — это «замок» на x. Чтобы достать x, нужно подобрать правильный «ключ» — одно из правил из M12. Разные уравнения требуют разных ключей, но вид замка (где стоит log) сразу подсказывает, какой ключ нужен.

**Правило.**
> Общая стратегия: 1) найти ОДЗ; 2) свернуть всё уравнение к одному логарифму слева и одному числу (или одному логарифму) справа; 3) «снять» логарифмы по правилу из шага 3 или 4; 4) решить обычное уравнение; 5) проверить корни по ОДЗ.

**Мини-пример.** log_2(x + 3) = 4 — простейший случай, x стоит один раз под одним логарифмом.

### Шаг 2. Область допустимых значений (ОДЗ) — находим первой

**Суть.** Логарифм существует только у положительного числа (M12, шаг 2). Поэтому первое действие в любом логарифмическом уравнении — не решение, а список условий: каждое выражение, стоящее под знаком log, должно быть больше нуля. Это не формальность «для галочки»: именно ОДЗ потом отсеивает посторонние корни, которые появляются при свёртке логарифмов и снятии знака логарифма (новое уравнение определено на большем множестве x, чем исходное).

**Наглядно.** ОДЗ — это забор вокруг поля, на котором ищем решение. Можно получить несколько чисел-кандидатов, но в ответ идут только те, что внутри забора.

**Правило.**
> Для уравнения с логарифмами вида log_a(…) записать систему: каждое подлогарифменное выражение > 0 (основание a тоже должно быть > 0 и ≠ 1; у нас оно число, это выполнено сразу). Решить эту систему — получить промежуток (или пересечение промежутков) допустимых x.

**Мини-пример.** Для log_3 x + log_3(x − 2) = 1 ОДЗ: x > 0 и x − 2 > 0, то есть x > 2.

### Шаг 3. Простейшее уравнение log_a f(x) = b

**Суть.** Это прямое применение определения логарифма (M12, шаг 1): log_a f(x) = b означает «a в степени b даёт f(x)». Значит f(x) = a^b. Особенность этого вида: отдельно проверять ОДЗ почти не нужно — a^b всегда больше нуля (раз a > 0), поэтому если корень f(x) = a^b существует, он автоматически попадает в ОДЗ. Проверка по ОДЗ всё равно делается — но как контроль арифметики, а не как отбор корней.

**Правило.**
> log_a f(x) = b ⟺ f(x) = a^b (при a > 0, a ≠ 1).

**Мини-пример.** log_2(x + 3) = 4 → x + 3 = 2⁴ = 16 → x = 13. Проверка ОДЗ: x + 3 = 16 > 0 — верно.

### Шаг 4. Уравнение log_a f(x) = log_a g(x)

**Суть.** Если логарифмы по одному основанию равны, то и числа под ними равны — это обратная сторона того, что у каждого положительного числа ровно один логарифм по данному основанию (функция log_a монотонна). Поэтому можно «снять» логарифмы с обеих сторон сразу, получив обычное уравнение f(x) = g(x). Но именно здесь чаще всего рождаются посторонние корни: уравнение f(x) = g(x) может иметь решения, не входящие в ОДЗ исходного уравнения, — поэтому проверка по ОДЗ после решения обязательна, не «если будет время».

**Правило.**
> log_a f(x) = log_a g(x) ⟺ f(x) = g(x), при условии f(x) > 0 (или, что то же самое при f = g, g(x) > 0) — то есть при ОДЗ.

**Мини-пример.** log_7(x + 2) = log_7(3x − 4) → x + 2 = 3x − 4 → 6 = 2x → x = 3. ОДЗ: x + 2 > 0 и 3x − 4 > 0 → x > 4/3. x = 3 входит в ОДЗ — подходит.

**Ловушка (сказать вслух).** log_a f(x) = c (число справа, не логарифм) — это шаг 3, а не шаг 4. Снимать логарифмы по шагу 4 можно только когда с каждой стороны стоит ровно один логарифм (без коэффициентов) и основания совпадают.

### Шаг 5. Сначала — свёртка в один логарифм

**Суть.** Реальные уравнения ЦТ редко сразу выглядят как шаг 3 или шаг 4 — обычно слева или справа стоит сумма или разность нескольких логарифмов. Прежде чем «снимать» логарифмы, нужно собрать их в один, используя свойства из M12 (шаги 6–7): произведение, частное, вынесение коэффициента. После свёртки уравнение становится простейшим (шаг 3 или 4).

**Алгоритм.**
1. Если перед логарифмом стоит числовой множитель — занести его внутрь как степень: p · log_a x = log_a(x^p).
2. Все логарифмы с одинаковым основанием в одной части уравнения собрать в один через произведение (+) или частное (−).
3. Если число слева/справа без логарифма — представить его как логарифм того же основания: c = log_a(a^c).
4. Получить вид log_a F(x) = log_a G(x) и применить шаг 4 (или log_a F(x) = b и применить шаг 3).

**Мини-пример.** log_3 x + log_3(x − 2) = 1 → log_3[x(x − 2)] = 1 → x(x − 2) = 3¹ = 3 → x² − 2x − 3 = 0 → (x − 3)(x + 1) = 0 → x = 3 или x = −1. ОДЗ (шаг 2): x > 2. Корень x = −1 не входит в ОДЗ — отбрасываем. **Ответ: x = 3.**

**Ловушка (сказать вслух).** log_a x + log_a y ≠ log_a(x + y) — это та же ошибка, что и в M12. Здесь она особенно опасна: если сложить аргументы вместо умножения, получится совсем другое уравнение и совсем другой (неверный) корень.

### Шаг 6. Замена переменной t = log_a x

**Суть.** Если во всё уравнение логарифм одного и того же выражения (например, log_2 x) входит несколько раз — как множитель, в квадрате и т. д., — а свернуть всё в один логарифм через свойства нельзя (шаг 5 здесь не работает), вводим новую переменную t = log_a x. Уравнение относительно t становится обычным квадратным — тем самым, которое уже умеем решать по M19 (через дискриминант или теорему Виета).

**Алгоритм.**
1. Обозначить t = log_a x (или t = log_a f(x), если под логарифмом не просто x).
2. Переписать всё уравнение через t — получится квадратное уравнение at² + bt + c = 0.
3. Решить его (M19): найти t₁ и t₂.
4. Вернуться к x: из t₁ = log_a x найти x = a^(t₁); то же для t₂.
5. Проверить оба значения x по ОДЗ исходного уравнения.

**Мини-пример.** (log_2 x)² − log_2 x − 2 = 0. Пусть t = log_2 x: t² − t − 2 = 0 → (t − 2)(t + 1) = 0 → t = 2 или t = −1 (проверка Виета: t₁ + t₂ = 1, t₁·t₂ = −2 — совпадает с −b/a = 1 и c/a = −2). Возврат к x: log_2 x = 2 → x = 4; log_2 x = −1 → x = 1/2. ОДЗ: x > 0 — оба подходят. **Ответ: x = 4 или x = 1/2.**

**Ловушка (сказать вслух).** Самая частая ошибка здесь — не ошибка в логарифмах, а забытый последний шаг: ученик решает квадратное уравнение, находит t₁ и t₂, и записывает их в ответ как x. Это не ответ — t — промежуточная переменная, назад нужно вернуться к x через a^t.

### Шаг 7. Проверка корней по ОДЗ — обязательный последний шаг

**Суть.** Какой бы метод ни использовался (шаг 3, 4, 5 или 6), последнее действие — подставить каждый найденный корень в список условий ОДЗ (шаг 2) и оставить только те, что ему удовлетворяют. Это не «на всякий случай» — в уравнениях ЦТ формата В11 часто специально заложен посторонний корень, который отсеивается именно на этом шаге.

**Правило.**
> Корень подходит, если он удовлетворяет ОДЗ, найденной в шаге 2 — для каждого подлогарифменного выражения отдельно. Подставлять в исходное уравнение целиком необязательно (это долго и может потребовать логарифмов без калькулятора) — достаточно подставить в условия ОДЗ, это быстрее и не требует вычисления самого логарифма.

**Мини-пример.** В шаге 5 ОДЗ была x > 2; корни x = 3 и x = −1; x = −1 не входит в x > 2 — отбрасываем, остаётся x = 3.

### Чего сейчас не объясняем

- Логарифмические неравенства и метод интервалов для них — отдельная тема M25, целиком опирается на сегодняшние приёмы свёртки и замены.
- Уравнения с переменным основанием логарифма (вида log_x a = b, где x — и основание) — встречаются в ЦТ редко, относятся к уровню C; при необходимости разбираются отдельно.
- Системы уравнений, где одно или оба уравнения логарифмические, — после того как обе части курса (уравнения и системы) пройдены по отдельности.
- Логарифмические уравнения вместе с иррациональными или уравнения с модулем под знаком логарифма — продвинутый уровень, не входит в обязательный минимум.
- Доказательство того, почему log_a монотонна (а значит из равенства логарифмов следует равенство аргументов) — это темы M33 (график и свойства логарифмической функции), сейчас пользуемся фактом без доказательства.

## Опорный конспект

| Вид уравнения | Метод | ОДЗ | Пример |
|---|---|---|---|
| log_a f(x) = b | f(x) = a^b | проверяется автоматически (a^b > 0), но контролируем | log_2(x+3)=4 → x=13 |
| log_a f(x) = log_a g(x) | f(x) = g(x) | f(x) > 0 (и/или g(x) > 0) — обязательно проверить | log_7(x+2)=log_7(3x−4) → x=3 |
| log_a f(x) + log_a g(x) = c | log_a(f·g) = c → f·g = a^c | f(x) > 0, g(x) > 0 | log_3 x+log_3(x−2)=1 → x=3 |
| log_a f(x) − log_a g(x) = c | log_a(f/g) = c → f/g = a^c | f(x) > 0, g(x) > 0 | log_5(x+6)−log_5(x−2)=1 → x=4 |
| k·log_a f(x) + … = … | занести k внутрь: k·log_a f = log_a(f^k), затем свернуть | f(x) > 0 (и остальные выражения под логарифмом) | 2log_2 x−log_2(x+3)=log_2 4 → x=6 |
| (log_a x)² + p·log_a x + q = 0 | замена t = log_a x → квадратное уравнение (M19) → вернуться к x через x = a^t | x > 0 (условие на сам x, t может быть любым) | (log_2 x)²−log_2 x−2=0 → x=4 или 1/2 |

**Образец оформления решения.** log_3 x + log_3(x − 2) = 1. 1) ОДЗ: x > 0, x − 2 > 0 → x > 2. 2) Свёртка: log_3[x(x − 2)] = 1. 3) Снимаем логарифм: x(x − 2) = 3¹ = 3 → x² − 2x − 3 = 0. 4) Решаем: (x − 3)(x + 1) = 0 → x = 3 или x = −1. 5) Проверка по ОДЗ (x > 2): x = 3 подходит, x = −1 — нет. **Ответ: x = 3.**

## Разобранные примеры

### Пример 1 (уровень 1). Решите уравнение log_2(x + 3) = 4

ОДЗ: x + 3 > 0 → x > −3. По определению логарифма: x + 3 = 2⁴ = 16 → x = 13. Проверка ОДЗ: 13 > −3 — верно. **Ответ: x = 13.**

### Пример 2 (уровень 1). Решите уравнение log_7(x + 2) = log_7(3x − 4)

ОДЗ: x + 2 > 0 → x > −2; 3x − 4 > 0 → x > 4/3. Снимаем логарифмы: x + 2 = 3x − 4 → 6 = 2x → x = 3. Проверка ОДЗ: 3 > 4/3 — верно. **Ответ: x = 3.**

### Пример 3 (уровень 2, с отбором корня). Решите уравнение log_3 x + log_3(x − 2) = 1

ОДЗ: x > 0 и x − 2 > 0 → x > 2. Свёртка: log_3[x(x − 2)] = 1 → x(x − 2) = 3 → x² − 2x − 3 = 0 → (x − 3)(x + 1) = 0 → x = 3 или x = −1. По ОДЗ (x > 2) подходит только x = 3; x = −1 — посторонний корень. **Ответ: x = 3.**

### Пример 4 (уровень 2, разность логарифмов). Решите уравнение log_5(x + 6) − log_5(x − 2) = 1

ОДЗ: x + 6 > 0 → x > −6; x − 2 > 0 → x > 2. Свёртка: log_5[(x + 6)/(x − 2)] = 1 → (x + 6)/(x − 2) = 5 → x + 6 = 5x − 10 → 16 = 4x → x = 4. Проверка ОДЗ: 4 > 2 — верно. **Ответ: x = 4.**

### Пример 5 (уровень 3, замена переменной). Решите уравнение (log₂ x)² − log₂ x − 2 = 0

ОДЗ: x > 0. Замена t = log₂ x: t² − t − 2 = 0 → (t − 2)(t + 1) = 0 → t = 2 или t = −1 (по теореме Виета: сумма 1, произведение −2 — совпадает). Возврат к x: log₂ x = 2 → x = 4; log₂ x = −1 → x = 1/2. Оба значения положительны — оба входят в ОДЗ. **Ответ: x = 4 или x = 1/2.**

### Пример 6 (уровень 3, формат части А — 5 вариантов)

Корень уравнения log₂(x + 1) + log₂(x − 1) = log₂(x + 5) равен:

1) 3  2) −2  3) 2  4) −3  5) верны оба числа: 3 и −2

**Решение.** 1) ОДЗ: x + 1 > 0 → x > −1; x − 1 > 0 → x > 1; x + 5 > 0 → x > −5. Пересечение всех трёх условий: x > 1. 2) Свёртка слева: log₂[(x + 1)(x − 1)] = log₂(x + 5). 3) Снимаем логарифмы: (x + 1)(x − 1) = x + 5 → x² − 1 = x + 5 → x² − x − 6 = 0 → (x − 3)(x + 2) = 0 → x = 3 или x = −2. 4) Проверка по ОДЗ (x > 1): x = 3 подходит; x = −2 не подходит (−2 < 1, и к тому же x − 1 = −3 < 0 — под этим логарифмом было бы отрицательное число). **Ответ: 1) 3.**

**Разбор неверных вариантов.**
- 2) −2 — взяли ровно тот корень, который отбрасывается по ОДЗ, то есть решили квадратное уравнение правильно, но забыли (или не сделали) последнюю проверку;
- 5) «верны оба» — классическая ловушка для тех, кто помнит, что квадратное уравнение даёт два корня, но не проверяет ни один из них по ОДЗ исходного уравнения — в логарифмическом уравнении не любое решение квадратного уравнения становится ответом;
- 3) 2 — результат ошибки знака при переносе x: x² − 1 = x + 5 → x² + x − 6 = 0 (вместо x² − x − 6 = 0) → (x + 3)(x − 2) = 0 → x = 2 или x = −3; корень 2 проходит ОДЗ, поэтому ошибку не видно без проверки подстановкой;
- 4) −3 — второй корень того же неверного уравнения x² + x − 6 = 0; к тому же он не входит в ОДЗ (−3 < 1).

Ученику: при логарифмическом уравнении в части В опасность не в вычислениях, а в последнем шаге. Если нашёл два корня квадратного уравнения — это сигнал остановиться и свериться с ОДЗ, а не повод сразу писать оба числа в бланк.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Не находит ОДЗ вообще, не отбрасывает посторонний корень | решает x(x−2)=3, пишет в ответ x=3 и x=−1 | Правило «ОДЗ — первое действие, проверка по ОДЗ — последнее»: писать её строкой до решения и сверяться после |
| Складывает аргументы вместо умножения при свёртке | log_a x + log_a y «=» log_a(x + y) | Проверка на простых числах (как в M12): log_2 4 + log_2 8 = 5, а log_2(4+8) = log_2 12 ≠ 5 |
| Забывает вернуться от t к x после замены переменной | находит t = 2 и t = −1, пишет в ответ x = 2 и x = −1 | Проговорить: t — не ответ, последний шаг — x = a^t; писать явную строку «возврат к x:» |
| Ошибается в квадратном уравнении после замены | неверно раскладывает t² − t − 2 = 0 | Проверка по теореме Виета (M19): сумма и произведение корней должны совпасть с −b/a и c/a |
| Неверно заносит коэффициент перед логарифмом | 2·log_a x «=» log_a(2x) вместо log_a(x²) | Проговорить правило M12 шаг 7 вслух: показатель выходит множителем, а при обратном действии становится степенью аргумента |
| Путает направление в простейшем уравнении | log_a f(x) = b «=» f(x) = a·b вместо f(x) = a^b | Напоминание: логарифм — показатель степени (M12 шаг 1), а не множитель; проверка подстановкой готового корня в исходное уравнение |
| При делении аргументов (разность логарифмов) переворачивает дробь | log_a(x/y) «=» c → y/x = a^c вместо x/y = a^c | Проговорить порядок: какой логарифм писали первым (уменьшаемое), тот и в числителе |
| Подставляет корень в упрощённое уравнение вместо проверки по ОДЗ исходного | проверяет x=−1 в x²−2x−3=0, видит «подходит», не глядя на ОДЗ x>2 | Проверка по ОДЗ — это отдельный шаг со своим списком условий, а не повторная подстановка в то же упрощённое уравнение |
