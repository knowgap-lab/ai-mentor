# M34. Арифметическая и геометрическая прогрессии

## Зачем эта тема

Арифметическая прогрессия — это напрямую задание **В7** ЦТ, решаемость на ЦЭ-2025 ≈42 % — то есть больше половины выпускников это задание не решают, хотя правило там одно и короткое. Это чистые 2 первичных балла, которые не зависят от геометрии или тригонометрии, а только от двух формул и аккуратной работы с линейным уравнением (опора М16).

Геометрическая прогрессия в части В ЦЭ последних лет отдельным номером не встречается, но входит в программу и без неё не понять идею показательного роста (проценты по вкладу, рост бактерий, деление листа бумаги пополам) — а эти образы потом пригодятся в текстовых задачах (М28) и при обсуждении показательной функции (М33). Кроме того, у арифметической и геометрической прогрессий одна и та же логика построения: «первый член + правило перехода к следующему», и после этой темы обе формулы n-го члена будут выглядеть предсказуемо, а не как два разных факта для зубрёжки.

Для ученика: *«Задание В7 решает меньше половины — это задание, которое можно забрать себе почти всегда, потому что оно не про сообразительность, а про две формулы, которые мы сейчас выучим так, чтобы ты мог написать их не задумываясь»*.

## Результат: после темы ученик умеет

- [ ] объяснить, что такое арифметическая прогрессия, найти разность d по двум соседним членам и дописать следующие члены (2, 5, 8, 11, … — d = 3, следующий член 14);
- [ ] находить любой член арифметической прогрессии по формуле aₙ = a₁ + (n − 1)d без выписывания всех членов подряд (a₁ = 3, d = 5 → a₁₀ = 48);
- [ ] находить номер члена n по его значению, решая линейное уравнение относительно n (a₁ = 4, d = 3, aₙ = 100 → n = 33);
- [ ] находить сумму первых n членов арифметической прогрессии двумя способами — через a₁ и d, и через a₁ и aₙ (a₁ = 2, d = 3, n = 20 → S₂₀ = 610; a₁ = 5, aₙ = 95, n = 10 → S₁₀ = 500);
- [ ] объяснить, что такое геометрическая прогрессия, найти знаменатель q по двум соседним членам и дописать следующие члены (3, 6, 12, … — q = 2, следующий член 24);
- [ ] находить любой член геометрической прогрессии по формуле bₙ = b₁ · qⁿ⁻¹ (b₁ = 2, q = 3 → b₆ = 486) и сумму первых n членов по формуле Sₙ = b₁(qⁿ − 1) / (q − 1) (b₁ = 1, q = 2, n = 10 → S₁₀ = 1023);
- [ ] по виду числового ряда определить, какая это прогрессия — арифметическая, геометрическая или ни то ни другое (4, 7, 10, 13 — арифметическая; 2, 6, 18, 54 — геометрическая);
- [ ] решать текстовую задачу формата В7 (места в рядах зала, прибавка зарплаты и т. п.), переводя условие в a₁, d и n, с ответом целым числом.

## Входная проверка (5 минут)

| № | Вопрос | Ответ | Что проверяет |
|---|---|---|---|
| 1 | Решите уравнение 3x + 7 = 22 | x = 5 | линейное уравнение (опора М16, понадобится находить n и d) |
| 2 | Вычислите 2⁵ | 32 | степень с натуральным показателем (опора М06, понадобится в формуле геометрической прогрессии) |
| 3 | Какое число идёт следующим в ряду 3, 7, 11, 15, …? | 19 | интуитивное понимание «прибавляем одно и то же» — это и есть арифметическая прогрессия |
| 4 | Во сколько раз каждое следующее число больше предыдущего в ряду 2, 6, 18, 54? | в 3 раза | интуитивное понимание «умножаем на одно и то же» — это и есть геометрическая прогрессия |
| 5 | Найдите среднее арифметическое чисел 5 и 11 | 8 | среднее двух чисел — понадобится для характеристического свойства прогрессии |

Всё верно — определения (шаги 1, 4) проговариваем за 1–2 минуты как уже знакомую идею и быстро переходим к формулам (шаги 2–3, 5–6). Ошибка в №1 — сначала 3–5 минут повторяем перенос слагаемых (М16), иначе не получится находить n и d из уравнений. Ошибка в №2 — повторяем свойства степени (М06) перед формулой суммы геометрической прогрессии.

## Теория: сценарий объяснения

### Шаг 1. Что такое числовая последовательность

**Суть.** «Последовательность — это просто пронумерованный список чисел: первое число, второе, третье и так далее». Каждое число в списке называют членом последовательности и обозначают буквой с номером снизу: a₁ — первый член, a₂ — второй, aₙ — член с номером n (где n может быть любым).

**Наглядно.** Нарисовать таблицу из двух строк: в верхней — номера 1, 2, 3, 4, 5…, в нижней — числа под ними. Показать, что у каждого номера есть ровно одно число, но связь между номером и числом может быть разной — в этой теме разберём две самые важные связи.

**Мини-пример.** Последовательность 2, 5, 8, 11, 14 — это a₁ = 2, a₂ = 5, a₃ = 8, a₄ = 11, a₅ = 14.

### Шаг 2. Арифметическая прогрессия: определение и разность d

**Суть.** Арифметическая прогрессия — это последовательность, где от одного члена к следующему **прибавляют одно и то же число**. Это число называют разностью прогрессии и обозначают буквой d (от слова difference — разность). Если d положительное — прогрессия растёт, если отрицательное — убывает, если d = 0 — все члены одинаковые.

**Наглядно.** Нарисовать лестницу с одинаковыми по высоте ступеньками: высота каждой ступеньки — это d. Числа 2, 5, 8, 11 — это высота на старте и высоты после 1-й, 2-й, 3-й ступеньки, если начали с 2.

**Правило.**
> Последовательность a₁, a₂, a₃, … называется арифметической прогрессией, если для любого n выполняется aₙ₊₁ = aₙ + d, где d — постоянное число (разность прогрессии). Разность находят так: d = aₙ₊₁ − aₙ (любые два соседних члена).

**Мини-пример.** 2, 5, 8, 11, 14 — арифметическая прогрессия, d = 5 − 2 = 3. Следующий член: 14 + 3 = 17.

**Ловушка (сказать вслух).** Чтобы найти d, из **следующего** члена вычитают **предыдущий**, а не наоборот: d = a₂ − a₁, а не a₁ − a₂. Перепутанный порядок даёт разность с противоположным знаком.

### Шаг 3. Формула n-го члена арифметической прогрессии

**Суть.** Чтобы найти, например, сотый член, не нужно 99 раз подряд прибавлять d — от a₁ до aₙ прибавили d ровно (n − 1) раз (на первом шаге прибавили один раз, чтобы получить a₂, а не aₙ). Отсюда формула для любого члена сразу, без выписывания всех предыдущих.

**Наглядно.** Выписать цепочку: a₁ → (+d) → a₂ → (+d) → a₃ → (+d) → a₄. От a₁ до a₄ сделано 3 шага по +d, то есть (4 − 1) = 3 шага. Обвести количество стрелок и количество «минус один» рядом с номером.

**Правило.**
> aₙ = a₁ + (n − 1)d.

**Мини-пример.** a₁ = 3, d = 5. Найдём a₁₀: a₁₀ = 3 + (10 − 1)·5 = 3 + 45 = 48.

**Ловушка (сказать вслух).** В формуле стоит (n − 1), а не n — это самая частая потеря балла в теме. Проверка на маленьком номере: a₁ = a₁ + (1 − 1)d = a₁ + 0 = a₁ — верно, значит скобка (n − 1) на месте.

### Шаг 4. Нахождение номера члена и разности из условия

**Суть.** Иногда известен не номер, а значение члена, и нужно найти, каким по счёту он стоит, или известны два члена без явного d — тогда формула n-го члена превращается в обычное линейное уравнение (опора М16), только неизвестное — это n или d.

**Алгоритм (найти n по известному aₙ).**
1. Подставить a₁, d и известное значение aₙ в формулу aₙ = a₁ + (n − 1)d.
2. Решить получившееся линейное уравнение относительно n.
3. Проверить: номер n должен получиться натуральным числом.

**Мини-пример 1.** a₁ = 4, d = 3, aₙ = 100. 100 = 4 + (n − 1)·3 → 96 = (n − 1)·3 → n − 1 = 32 → **n = 33.**

**Алгоритм (найти d и a₁ по двум членам aₚ и aₖ).**
1. Составить два уравнения: aₚ = a₁ + (p − 1)d и aₖ = a₁ + (k − 1)d.
2. Вычесть одно уравнение из другого — a₁ сократится, останется уравнение только с d.
3. Найти d, затем подставить в любое из уравнений и найти a₁.

**Мини-пример 2.** a₅ = 14, a₁₀ = 34. Вычитаем: a₁₀ − a₅ = (10 − 5)d → 34 − 14 = 5d → d = 4. Тогда a₁ = a₅ − 4d = 14 − 16 = **−2.**

### Шаг 5. Сумма первых n членов арифметической прогрессии

**Суть.** Сумму первых n членов можно найти не складывая их по одному, а сразу: это старый приём Гаусса — сложить прогрессию саму с собой, но «в обратном порядке», тогда каждая пара (первый + последний, второй + предпоследний, …) даёт одно и то же число.

**Наглядно.** Записать сумму 1 + 2 + 3 + … + 10 в строке, под ней ту же сумму в обратном порядке 10 + 9 + 8 + … + 1, и сложить по столбикам: каждая пара даёт 11, пар десять, итого 2S = 110, S = 55. Показать, что то же самое работает для любой арифметической прогрессии: пара «первый + последний» всегда равна паре «второй + предпоследний».

**Правило.**
> Sₙ = (a₁ + aₙ)/2 · n — если известны первый и последний член.
> Sₙ = (2a₁ + (n − 1)d)/2 · n — если aₙ неизвестен, но известны a₁ и d (сюда просто подставили aₙ = a₁ + (n − 1)d в первую формулу).

**Мини-пример.** a₁ = 2, d = 3, n = 20. Сначала a₂₀ = 2 + 19·3 = 59. Затем S₂₀ = (2 + 59)/2 · 20 = 610.

**Ловушка (сказать вслух).** В обеих формулах суммы n стоит **снаружи**, умножает всю дробь, а не только последнее слагаемое — это чаще всего забывают при подстановке в калькулятор в голове. Проверка на маленьком n: сумма первых 2 членов должна совпасть с a₁ + a₂, посчитанными напрямую.

### Шаг 6. Геометрическая прогрессия: определение и знаменатель q

**Суть.** Геометрическая прогрессия — это последовательность, где от одного члена к следующему **умножают на одно и то же число**. Это число называют знаменателем прогрессии и обозначают буквой q (от quotient — частное). Важное условие: ни один член геометрической прогрессии не равен нулю, иначе умножение «убивает» всю последовательность.

**Наглядно.** Клетка делится пополам, каждая половинка снова делится пополам и так далее: доли 1/2, 1/4, 1/8, 1/16 — геометрическая прогрессия с q = 1/2. Или наоборот: лист бумаги складывают, и число слоёв 1, 2, 4, 8, 16 — геометрическая прогрессия с q = 2.

**Правило.**
> Последовательность b₁, b₂, b₃, … (все члены не равны нулю) называется геометрической прогрессией, если для любого n выполняется bₙ₊₁ = bₙ · q, где q — постоянное число (знаменатель прогрессии), q ≠ 0. Знаменатель находят так: q = bₙ₊₁ / bₙ (любые два соседних члена).

**Мини-пример.** 3, 6, 12, 24 — геометрическая прогрессия, q = 6 : 3 = 2. Следующий член: 24 · 2 = 48.

**Ловушка (сказать вслух).** Чтобы найти q, **следующий** член делят на **предыдущий**, а не наоборот — так же, как с разностью d, только делением вместо вычитания. И если q отрицательное, знаки членов будут чередоваться — это не ошибка, а свойство такой прогрессии (не входит в типовые задачи ЦТ, но полезно узнавать на слух).

### Шаг 7. Формула n-го члена геометрической прогрессии

**Суть.** Так же, как с арифметической прогрессией: от b₁ до bₙ умножили на q ровно (n − 1) раз, поэтому bₙ = b₁ · q, умноженное на себя (n − 1) раз, то есть q в степени (n − 1) (опора М06 — степень с натуральным показателем).

**Наглядно.** Цепочка b₁ → (·q) → b₂ → (·q) → b₃ → (·q) → b₄ = b₁·q·q·q = b₁·q³. Три стрелки «умножить на q» — это q в третьей степени, и 3 = 4 − 1.

**Правило.**
> bₙ = b₁ · qⁿ⁻¹.

**Мини-пример.** b₁ = 2, q = 3. Найдём b₆: b₆ = 2 · 3⁵ = 2 · 243 = 486.

**Ловушка (сказать вслух).** Показатель степени — это (n − 1), в точности как у арифметической прогрессии в формуле для aₙ. Проверка: b₁ = b₁ · q⁰ = b₁ · 1 = b₁ — верно, значит показатель на месте.

### Шаг 8. Сумма первых n членов геометрической прогрессии

**Суть.** Приём Гаусса здесь не работает (суммы «в обратном порядке» не совпадают по парам), зато работает другой приём: вычесть из суммы S эту же сумму, умноженную на q — тогда почти все члены взаимно уничтожатся.

**Наглядно.** Записать S = b₁ + b₁q + b₁q² + … + b₁qⁿ⁻¹, под ней qS = b₁q + b₁q² + … + b₁qⁿ, и вычесть строку из строки: все средние слагаемые сократятся, останется S − qS = b₁ − b₁qⁿ, то есть S(1 − q) = b₁(1 − qⁿ).

**Правило.**
> Sₙ = b₁(qⁿ − 1) / (q − 1), при q ≠ 1.
> При q = 1 все члены равны b₁, и сумма считается проще: Sₙ = b₁ · n (формула с делением на (q − 1) здесь не работает — нельзя делить на 0).

**Мини-пример.** b₁ = 1, q = 2, n = 10. S₁₀ = 1·(2¹⁰ − 1) / (2 − 1) = (1024 − 1) / 1 = 1023.

**Ловушка (сказать вслух).** В формуле суммы стоит qⁿ (показатель равен количеству членов n), а не qⁿ⁻¹ (это было в формуле члена bₙ) — две похожие формулы с разным показателем, их легко перепутать. Проверка на маленьком n = 1: S₁ = b₁(q¹ − 1)/(q − 1) = b₁ — совпадает с тем, что сумма одного члена равна самому члену.

### Шаг 9. Характеристическое свойство: средний член прогрессии

**Суть.** Если взять три соседних члена прогрессии, то между ними есть правило, которое удобно использовать, когда просят проверить или подобрать неизвестное число так, чтобы три числа составили прогрессию.

**Правило.**
> Арифметическая прогрессия: средний член равен среднему арифметическому крайних — aₙ = (aₙ₋₁ + aₙ₊₁)/2. Верно и обратное: если для трёх чисел выполняется это равенство, они образуют арифметическую прогрессию.
> Геометрическая прогрессия (члены одного знака): средний член по модулю равен среднему геометрическому крайних — bₙ² = bₙ₋₁ · bₙ₊₁.

**Мини-пример (АП).** Числа 2x − 5, x + 1, 3x − 2 образуют арифметическую прогрессию. Тогда 2(x + 1) = (2x − 5) + (3x − 2) → 2x + 2 = 5x − 7 → 3x = 9 → **x = 3.** Проверка: получаются числа 1, 4, 7 — действительно арифметическая прогрессия с d = 3.

**Мини-пример (ГП).** Числа 2, x, 18 образуют геометрическую прогрессию из положительных чисел. Тогда x² = 2 · 18 = 36 → **x = 6** (отрицательный корень −6 отбрасываем, так как числа положительные).

### Чего сейчас не объясняем

- Сумма **бесконечной** убывающей геометрической прогрессии — на ЦТ последних лет не встречалась; изучаем, если останется время. Формула: S = b₁/(1 − q), |q| < 1. Пример: 8, 4, 2, … → S = 8/(1 − 1/2) = 16.
- Прогрессии с отрицательным и дробным q, где знаки членов чередуются или само поведение прогрессии «скачет», — сама формула работает так же, но в части В такие прогрессии не встречаются, подробно не тренируем.
- Связь геометрической прогрессии с показательной функцией (bₙ = b₁ · qⁿ⁻¹ — это «показательная функция на натуральных числах») — будет естественным наблюдением в теме М33, здесь не акцентируем.
- Доказательство формул через метод математической индукции — для этого курса достаточно наглядного вывода (приём Гаусса и приём «вычесть из S величину qS»), формальное доказательство не нужно.

## Опорный конспект

| Понятие | Арифметическая прогрессия | Геометрическая прогрессия |
|---|---|---|
| Правило перехода | aₙ₊₁ = aₙ + d | bₙ₊₁ = bₙ · q |
| Как найти d / q | d = aₙ₊₁ − aₙ | q = bₙ₊₁ / bₙ |
| Формула n-го члена | aₙ = a₁ + (n − 1)d | bₙ = b₁ · qⁿ⁻¹ |
| Формула суммы | Sₙ = (a₁ + aₙ)/2 · n = (2a₁ + (n−1)d)/2 · n | Sₙ = b₁(qⁿ − 1)/(q − 1), q ≠ 1; Sₙ = b₁·n, если q = 1 |
| Характеристическое свойство | aₙ = (aₙ₋₁ + aₙ₊₁)/2 | bₙ² = bₙ₋₁ · bₙ₊₁ |
| Пример | 2, 5, 8, 11, … (d = 3) | 3, 6, 12, 24, … (q = 2) |

**Образец оформления.** Дана арифметическая прогрессия с a₁ = 5, d = 4. Найти a₁₂ и S₁₂.
1) Формула члена: a₁₂ = a₁ + (12 − 1)d = 5 + 11·4 = 5 + 44 = 49.
2) Формула суммы: S₁₂ = (a₁ + a₁₂)/2 · n = (5 + 49)/2 · 12 = 27 · 12 = 324.
**Ответ: a₁₂ = 49, S₁₂ = 324.**

| Что такое арифметическая прогрессия? | последовательность, где к каждому члену прибавляют одно и то же число d |
| Как найти разность d? | d = aₙ₊₁ − aₙ (следующий минус предыдущий) |
| Формула n-го члена арифметической прогрессии? | aₙ = a₁ + (n − 1)d |
| Формула суммы первых n членов арифметической прогрессии (через a₁ и aₙ)? | Sₙ = (a₁ + aₙ)/2 · n |
| Что такое геометрическая прогрессия? | последовательность, где каждый член умножают на одно и то же число q, члены не равны 0 |
| Как найти знаменатель q? | q = bₙ₊₁ / bₙ (следующий делить на предыдущий) |
| Формула n-го члена геометрической прогрессии? | bₙ = b₁ · qⁿ⁻¹ |
| Формула суммы первых n членов геометрической прогрессии (q ≠ 1)? | Sₙ = b₁(qⁿ − 1)/(q − 1) |
| Чему равна сумма, если q = 1? | Sₙ = b₁ · n |
| Характеристическое свойство арифметической прогрессии? | средний член равен среднему арифметическому соседних: aₙ = (aₙ₋₁ + aₙ₊₁)/2 |
| Характеристическое свойство геометрической прогрессии? | квадрат среднего члена равен произведению соседних: bₙ² = bₙ₋₁·bₙ₊₁ |
| В формуле n-го члена стоит n или (n − 1)? | (n − 1) — множитель при d в арифметической и показатель степени q в геометрической прогрессии |

## Разобранные примеры

### Пример 1 (уровень 1). Дана арифметическая прогрессия 7, 11, 15, 19, … Найдите разность d и пятнадцатый член

Разность: d = 11 − 7 = 4. Формула члена: a₁₅ = a₁ + (15 − 1)d = 7 + 14·4 = 7 + 56 = 63. **Ответ: d = 4, a₁₅ = 63.**

### Пример 2 (уровень 1). Дана геометрическая прогрессия 3, 6, 12, 24, … Найдите знаменатель q и пятый член

Знаменатель: q = 6 : 3 = 2. Формула члена: b₅ = b₁ · q⁴ = 3 · 2⁴ = 3 · 16 = 48. **Ответ: q = 2, b₅ = 48.**

### Пример 3 (уровень 2). В арифметической прогрессии a₅ = 14, a₁₀ = 34. Найдите a₁ и сумму первых восьми членов

Вычитаем: a₁₀ − a₅ = 5d → 34 − 14 = 5d → d = 4. Тогда a₁ = a₅ − 4d = 14 − 16 = −2.
Сумма: a₈ = a₁ + 7d = −2 + 28 = 26. S₈ = (a₁ + a₈)/2 · 8 = (−2 + 26)/2 · 8 = 12 · 8 = 96. **Ответ: a₁ = −2, S₈ = 96.**

### Пример 4 (уровень 2). Числа 2, x, 18 — три последовательных члена геометрической прогрессии из положительных чисел. Найдите x

По характеристическому свойству: x² = 2 · 18 = 36 → x = 6 (берём положительный корень, так как прогрессия из положительных чисел). **Ответ: x = 6.**

### Пример 5 (уровень 3, формат части В — ответ целым числом). В кинозале первый ряд содержит 18 мест, а каждый следующий ряд — на 2 места больше предыдущего. Всего в зале 24 ряда. Сколько всего мест в зале?

Это арифметическая прогрессия: a₁ = 18 (места в 1-м ряду), d = 2 (на столько увеличивается от ряда к ряду), n = 24 (число рядов). Нужно найти сумму всех мест S₂₄.
1) Количество мест в последнем ряду: a₂₄ = a₁ + (24 − 1)d = 18 + 23·2 = 18 + 46 = 64.
2) Сумма: S₂₄ = (a₁ + a₂₄)/2 · n = (18 + 64)/2 · 24 = 41 · 24 = 984.
**Ответ: 984.**

### Пример 6 (уровень 3, формат ЦТ часть А — 5 вариантов ответа)

Третий член арифметической прогрессии равен 11, а восьмой — 31. Чему равен первый член этой прогрессии?

1) −1  2) 3  3) 19  4) 4  5) 21

**Решение.** Составляем систему: a₃ = a₁ + 2d = 11; a₈ = a₁ + 7d = 31. Вычитаем первое из второго: 5d = 20 → d = 4. Тогда a₁ = a₃ − 2d = 11 − 8 = 3. **Верный вариант — 2).**

**Разбор неверных вариантов** (каждый соответствует конкретной типичной ошибке):
- 1) −1 — ошибка «на единицу»: вместо a₁ = a₃ − 2d посчитали a₁ = a₃ − 3d (перепутали номер члена с количеством шагов), получили 11 − 12 = −1;
- 3) 19 — перепутан порядок вычитания при поиске d: посчитали d = (a₃ − a₈)/(8 − 3) = (11 − 31)/5 = −4 вместо (31 − 11)/5 = 4, и тогда a₁ = 11 − 2·(−4) = 19;
- 4) 4 — нашли верно d = 4, но ответили значением самой разности d, а не тем, что спросили (первый член a₁);
- 5) 21 — применили среднее арифметическое членов a₃ и a₈ вместо формулы прогрессии: (11 + 31)/2 = 21 — это не имеет отношения к a₁, потому что a₃ и a₈ не являются соседними членами с a₁.

Ученику: в части А каждый неверный вариант построен на реальной типичной ошибке, поэтому совпадение с одним из чисел ничего не доказывает — решать нужно по алгоритму (составить систему из формулы n-го члена, вычесть одно уравнение из другого) и в конце проверить оба условия задачи на найденных a₁ и d.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| В формуле члена путает (n − 1) с n | aₙ = a₁ + n·d вместо a₁ + (n−1)·d | Проверка на маленьком номере: a₁ по формуле с n = 1 должен дать a₁ + 0 = a₁, а не a₁ + d |
| Путает формулу разности: вычитает в неверном порядке | d = a₁ − a₂ вместо a₂ − a₁ (знак меняется) | Проговаривать «следующий минус предыдущий»; проверка — если прогрессия растёт, d должно получиться положительным |
| Применяет формулу арифметической прогрессии к геометрической (или наоборот) | Для 2, 6, 18, 54 считает «разность» 6−2=4 и использует её как d | Сначала спросить себя: «прибавляют или умножают?» — проверить на двух парах соседних членов, одинаковая разность или одинаковое отношение |
| В формуле суммы ГП путает qⁿ и qⁿ⁻¹ | Sₙ = b₁(qⁿ⁻¹ − 1)/(q − 1) вместо qⁿ | Проверка на n = 1: формула должна дать S₁ = b₁ |
| Забывает умножить всю дробь на n в формуле суммы АП | Sₙ = (a₁ + aₙ)/2 вместо (a₁+aₙ)/2 · n | Проверка на малом n = 2: сумма должна совпасть с a₁ + a₂, посчитанными напрямую |
| В текстовой задаче путает «на величину больше» (АП, d) и «во столько раз больше» (ГП, q) | «каждый год зарплата увеличивается на 10 %» считает как d = 10 вместо q = 1,1 | Перечитать условие: «на …» и «увеличилась на …%» → прогрессия арифметическая только если прибавляется одно и то же число, а не процент от текущего |
| Использует характеристическое свойство геометрической прогрессии как среднее арифметическое | bₙ = (bₙ₋₁ + bₙ₊₁)/2 вместо bₙ² = bₙ₋₁·bₙ₊₁ | Проверить на числах 2, 6, 18: среднее арифметическое 2 и 18 равно 10, а не 6 — значит для ГП нужен не обычный, а геометрический «средний» |
| Не проверяет знак/натуральность найденного номера n | Получив n = −2 или n = 2,5, записывает как ответ | Жёсткое правило: номер члена n — всегда натуральное число (1, 2, 3, …); дробный или отрицательный n — сигнал арифметической ошибки |
