# M29. Функция: понятие, график, область определения, свойства по графику

## Зачем эта тема

Сама тема «функция» напрямую в части А и В почти не встречается отдельной позицией, но без неё не читаются три конкретных задания: А4 (график квадратичной функции — мы сдвигаем параболу по тому же правилу, которое выучим здесь), А10 (свойства и сдвиги графика логарифмической функции — тот же сдвиг, другая исходная кривая) и В9 (чётная/нечётная функция, значение выражения — умение смотреть на график и видеть симметрию). Эта карточка — тот самый «переходник»: мы один раз разбираемся, что значит «сдвинуть график» и «прочитать свойство по графику», а дальше в темах M31 (квадратичная функция), M33 (показательная и логарифмическая) и M32 (чётность) только подставляем конкретную формулу в уже знакомую схему.

Кроме того, без понятия «область определения» не читаются никакие более сложные задачи с корнями, дробями и логарифмами — а их в части В большинство.

Для ученика: *«Функция — это не формула, а правило "каждому x — свой y". Научимся один раз читать график: где он идёт вверх, где вниз, где пересекает ось, — и дальше это пригодится в параболе, в логарифме и ещё в десяти темах курса»*.

## Результат: после темы ученик умеет

- [ ] объяснить, что такое функция (каждому x из области определения соответствует ровно одно значение y) и проверить по рисунку, является ли линия графиком функции (вертикальная прямая пересекает график не больше одного раза);
- [ ] находить область определения функции, заданной формулой: при делении (x ≠ корень знаменателя), при корне чётной степени (подкоренное ≥ 0), при логарифме (аргумент > 0), и их комбинации (f(x) = √(x + 5)/(x − 2): x ∈ [−5; 2) ∪ (2; +∞));
- [ ] по графику находить значение функции в точке, нули функции и промежутки, где функция положительна или отрицательна;
- [ ] по графику указывать промежутки возрастания и убывания функции и её область значений;
- [ ] по графику узнавать симметрию: график симметричен относительно оси Oy — функция чётная, относительно начала координат — нечётная (без вычислений, на глаз, как подготовка к M32);
- [ ] строить новый график сдвигом известного: y = f(x) + n — сдвиг по вертикали на n, y = f(x − m) — сдвиг по горизонтали на m, и находить координаты точки сдвинутого графика по точке исходного;
- [ ] решать задание части А на область определения функции с пятью вариантами ответа, отсекая типичные ловушки.

## Входная проверка (5 минут)

| № | Вопрос | Ответ | Что проверяет |
|---|---|---|---|
| 1 | Известно, что f(2) = 5. Что это значит? | при x = 2 значение функции равно 5; точка (2; 5) лежит на графике | смысл записи f(x) |
| 2 | Найдите область определения f(x) = 1/(x − 3) | x ≠ 3 | запрет деления на 0 |
| 3 | Являются ли точки (1; 2) и (1; 5) точками одного графика функции? | нет: одному x = 1 соответствуют два разных y, это не функция | смысл определения функции |
| 4 | График проходит через (−2; 1) и (0; 3): y растёт с 1 до 3. Это участок возрастания или убывания? | возрастания | направление изменения y при движении x влево → вправо |
| 5 | График функции f проходит через точку (0; 3). Чему равно f(0)? | 3 | чтение значения по графику |

Все пять верно — теорию (шаги 1–3) проговариваем кратко и сразу переходим к чтению графика и сдвигам (шаги 4–8). Ошибка в №1 или №3 — начинаем с полного объяснения понятия функции и обязательно рисуем вертикальную прямую на нескольких картинках.

## Теория: сценарий объяснения

### Шаг 1. Что такое функция

**Суть.** Функция — это правило, по которому каждому числу x из некоторого множества (область определения) ставится в соответствие ровно одно число y. x называют аргументом (независимой переменной), y — значением функции (зависимой переменной). Короткая запись: y = f(x), читается «игрек равен эф от икс», а f(2) означает «значение функции при x = 2».

**Наглядно.** «Станок»: кладём число x на входной лоток, внутри станка — формула-инструкция, что с ним сделать, на выходе получаем ровно одно число y. Если положить x = 2 два раза, станок каждый раз выдаст одно и то же число — иначе это не функция, а что-то другое.

**Правило.**
> y = f(x). x — аргумент, y — значение функции. Каждому x из области определения соответствует ровно одно y. Множество всех допустимых x называют областью определения и обозначают D(f), множество всех получающихся y — областью значений, E(f).

**Мини-пример.** f(x) = 2x + 1. f(3) = 2·3 + 1 = 7. Точка (3; 7) лежит на графике функции f.

### Шаг 2. Как задают функцию и что такое график

**Суть.** Функцию можно задать формулой (y = 2x + 1), таблицей значений, словесным правилом («y — цена билета в зависимости от возраста») или картинкой — графиком. График функции — это множество всех точек плоскости с координатами (x; f(x)), то есть «портрет» того, как y меняется при изменении x.

**Наглядно.** Отметить на координатной плоскости несколько точек графика y = 2x + 1: (−1; −1), (0; 1), (1; 3), (2; 5) — и соединить их линией. Получили прямую — это и есть график.

**Правило.**
> Не каждая линия на плоскости — график функции. Если провести вертикальную прямую x = a, она должна пересекать график не более чем в одной точке (иначе одному x соответствуют два y, а это запрещено определением функции). Эту проверку называют «проверкой вертикальной прямой».

**Мини-пример.** Окружность x² + y² = 9 — не график функции: прямая x = 0 пересекает её в двух точках, (0; 3) и (0; −3).

### Шаг 3. Область определения функции, заданной формулой

**Суть.** Область определения — это все x, для которых формулу можно вычислить, не нарушая правил арифметики. Запретов всего три, и они уже знакомы: нельзя делить на 0, нельзя извлекать корень чётной степени из отрицательного числа, нельзя брать логарифм от числа ≤ 0.

**Наглядно.** Таблица на доске: «что в формуле» → «что запрещаем» → «что пишем».

**Правило.**
> 1) Если в выражении есть дробь A/B, то знаменатель B ≠ 0.
> 2) Если есть корень чётной степени √(A) или ⁴√A, то подкоренное выражение A ≥ 0.
> 3) Если есть логарифм log A, то аргумент A > 0.
> Если в формуле несколько запретов одновременно, область определения — это **пересечение** (общая часть) всех условий, а не любое одно из них.

**Мини-пример.** f(x) = 1/(x − 5): x ≠ 5, D(f) = (−∞; 5) ∪ (5; +∞).

### Шаг 4. Область определения: комбинации условий

**Суть.** Когда в одной формуле встречаются и корень, и знаменатель (или логарифм), условия выписывают отдельно, а потом пересекают на одной координатной прямой — как пересечение промежутков в теме M04.

**Наглядно.** Для f(x) = √(x + 5)/(x − 2) на одной прямой отметить штриховкой x ≥ −5 (от корня) и отдельной штриховкой x ≠ 2 (от знаменателя); общая часть — ответ.

**Правило.**
> Алгоритм: 1) выписать каждое условие отдельно; 2) отметить каждое на числовой прямой; 3) найти общую часть (пересечение); 4) записать ответ в виде объединения промежутков.

**Мини-пример.** f(x) = √(x + 5)/(x − 2): x + 5 ≥ 0 → x ≥ −5; x − 2 ≠ 0 → x ≠ 2. Пересечение: x ∈ [−5; 2) ∪ (2; +∞).

### Шаг 5. Чтение графика: значения, нули, знак

**Суть.** Если нужно узнать f(a) по графику — находим на оси x точку a, поднимаемся (или опускаемся) до графика и читаем координату y. Нуль функции — это x, при котором график пересекает ось Ox (f(x) = 0). Там, где график выше оси Ox, функция положительна; где ниже — отрицательна.

**Наглядно.** Нарисовать на доске ломаную линию через точки (−4; −3), (−3; 0), (0; 3), (3; 0), (4; −2), соединённые отрезками. Эту ломаную используем во всех следующих примерах темы — обозначим её y = f(x).

**Правило.**
> f(a) — это координата y точки графика с координатой x = a. Нули функции — абсциссы точек пересечения графика с осью Ox. f(x) > 0 там, где график строго выше оси Ox; f(x) < 0 — где строго ниже.

**Мини-пример.** На нашей ломаной f(0) = 3 (график проходит через (0; 3)); нули функции: x = −3 и x = 3 (график пересекает ось Ox в этих точках).

### Шаг 6. Чтение графика: возрастание, убывание, область значений

**Суть.** Смотрим на график слева направо (в направлении возрастания x). Если линия идёт вверх — функция на этом промежутке возрастает (большему x соответствует большее y); если вниз — убывает. Область значений — это все y, которые «достаёт» график, то есть промежуток от самого нижнего до самого верхнего уровня линии.

**Наглядно.** На той же ломаной провести рукой слева направо: от (−4; −3) до (0; 3) рука идёт вверх (возрастание), от (0; 3) до (4; −2) — вниз (убывание). Горизонтальными линиями отметить самый нижний (y = −3) и самый верхний (y = 3) уровень графика.

**Правило.**
> Записывают промежутки монотонности по x: функция возрастает на [−4; 0], убывает на [0; 4]. Точку x = 0, где возрастание меняется на убывание, называют точкой максимума (здесь — без строгого определения через производную, только по картинке). Область значений E(f) — для сплошного графика без разрывов, как наша ломаная, — отрезок от минимального до максимального значения y, которое принимает график.

**Мини-пример.** На нашей ломаной: возрастает на [−4; 0], убывает на [0; 4], E(f) = [−3; 3] (самый низкий уровень −3 при x = −4, самый высокий 3 при x = 0).

### Шаг 7. Чётность и нечётность по графику (на глаз)

**Суть.** Иногда график обладает симметрией, которую видно без вычислений. Если его можно «сложить пополам» по оси Oy и обе половины совпадут — функция чётная. Если график переходит в себя при повороте на 180° вокруг начала координат (точка (a; b) и точка (−a; −b) обе на графике) — функция нечётная.

**Наглядно.** Парабола y = x² — зеркальна относительно оси Oy (чётная). Кубическая парабола y = x³ (или простая прямая y = x через начало координат) — переходит в себя при повороте на 180° (нечётная). Наша ломаная из шага 5 — пример функции без какой-либо из этих симметрий: f(−4) = −3, а f(4) = −2. Для симметрии относительно Oy нужно f(−4) = f(4), для симметрии относительно начала координат — f(−4) = −f(4) = 2; не выполняется ни то, ни другое, значит график не симметричен ни относительно Oy, ни относительно начала координат.

**Правило.**
> Чётная функция: график симметричен относительно оси Oy. Нечётная функция: график симметричен относительно начала координат. Большинство функций — ни чётные, ни нечётные. Строгое определение через f(−x) и алгебраическую проверку — в теме M32; здесь достаточно уметь увидеть симметрию на картинке.

**Мини-пример.** Если на графике есть точки (2; 5) и (−2; −5) — эта пара согласуется с нечётной симметрией (точка и её «противоположная» точка на месте). Но одной пары мало: функция нечётная, только если так «в пару» входит каждая точка графика.

### Шаг 8. Сдвиги графика

**Суть.** Если к готовому графику y = f(x) что-то добавить снаружи (к y) или внутри (к x), график не меняет форму, а просто передвигается — целиком, как через копирку. Это самое важное правило темы: оно без изменений работает для параболы (M31) и для логарифма (M33).

**Наглядно.** Взять прозрачный лист с нарисованной на нём кривой y = f(x) и просто подвинуть его вверх, вниз, влево или вправо — кривая та же самая, просто в другом месте координатной плоскости.

**Правило.**
> y = f(x) + n — сдвиг графика на n единиц **вверх**, если n > 0, и на |n| единиц вниз, если n < 0 (действие с y — сдвиг по вертикали, направление совпадает со знаком n).
> y = f(x − m) — сдвиг графика на m единиц **вправо**, если m > 0, и на |m| единиц влево, если m < 0 (действие с x — сдвиг по горизонтали, направление **противоположно** знаку внутри скобки: минус внутри — вправо, плюс внутри — влево).
> y = f(x − m) + n — совмещённый сдвиг: сначала (или одновременно) по горизонтали на m, по вертикали на n. Если точка (a; b) принадлежала графику y = f(x), то точка (a + m; b + n) принадлежит графику y = f(x − m) + n.

**Мини-пример.** График f проходит через точку (3; 7) (то есть f(3) = 7). Тогда график y = f(x − 2) + 1 проходит через точку (3 + 2; 7 + 1) = (5; 8).

### Чего сейчас не объясняем

- Строгое алгебраическое определение чётности и нечётности через равенство f(−x) = f(x) или f(−x) = −f(x) и вычисление значений по этому равенству (нужно для В9) — тема M32, целиком отдельный урок.
- Растяжение и отражение графика (y = k·f(x), y = f(k·x), y = −f(x)) — там, где они нужны конкретно, разбираются в M31 (парабола) и M33 (показательная и логарифмическая функции); здесь — только параллельный перенос.
- Экстремумы как точные значения через производную — тема M35 (производная), там же строгое определение возрастания/убывания через знак производной. Сейчас — только «на глаз» по графику.
- Периодичность функций — понадобится в M13/M32 для тригонометрии, здесь не затрагиваем.
- Свойства конкретных функций (линейной, квадратичной, показательной, логарифмической) — это отдельные темы M30, M31, M33; здесь даём только общий язык и общее правило сдвига.

## Опорный конспект

| Понятие | Правило | Пример |
|---|---|---|
| Функция | каждому x — ровно одно y; y = f(x) | f(x) = 2x + 1, f(3) = 7 |
| Проверка «это функция?» | вертикальная прямая пересекает график не более 1 раза | окружность — не функция |
| ОДЗ: дробь | знаменатель ≠ 0 | f(x) = 1/(x − 5): x ≠ 5 |
| ОДЗ: корень чётной степени | подкоренное ≥ 0 | f(x) = √(x − 3): x ≥ 3 |
| ОДЗ: логарифм | аргумент > 0 | f(x) = lg(x − 7): x > 7 |
| ОДЗ: несколько условий | пересечение всех условий | √(x+5)/(x−2): [−5; 2) ∪ (2; +∞) |
| Нули функции | x, при которых f(x) = 0 | график пересекает Ox |
| Знак функции | f(x) > 0 — график выше Ox; f(x) < 0 — ниже | — |
| Возрастание / убывание | слева направо: линия вверх — возрастает, вниз — убывает | — |
| Область значений E(f) | от минимального до максимального y на графике | — |
| Чётность (на глаз) | симметрия относительно Oy | y = x² |
| Нечётность (на глаз) | симметрия относительно начала координат | y = x³ |
| Сдвиг по вертикали | y = f(x) + n: вверх при n > 0, вниз при n < 0 | y = f(x) + 3 — вверх на 3 |
| Сдвиг по горизонтали | y = f(x − m): вправо при m > 0, влево при m < 0 | y = f(x − 4) — вправо на 4 |
| Точка сдвинутого графика | (a; b) → (a + m; b + n) | (3;7) → (5;8) при сдвиге (x−2)+1 |

**Образец оформления задачи на ОДЗ.** Выписываем каждое условие под своим номером, решаем отдельно, в конце — одна строка «Ответ: пересечение = …». Не пропускаем ни одно условие, даже если оно кажется «очевидным».

| Что делает +n в записи y = f(x) + n? | сдвигает график вверх на n (вниз, если n < 0) |
| Что делает y = f(x − m)? | сдвигает график вправо на m (влево, если m < 0) |
| Точка (a;b) на графике f. Где она окажется у графика f(x−m)+n? | в точке (a + m; b + n) |

## Разобранные примеры

### Пример 1 (уровень 1). Найдите область определения функции f(x) = 1/(x + 7)

Знаменатель не равен нулю: x + 7 ≠ 0, значит x ≠ −7. **Ответ: D(f) = (−∞; −7) ∪ (−7; +∞).**

### Пример 2 (уровень 1). Найдите область определения функции f(x) = √(5 − x)

Подкоренное выражение неотрицательно: 5 − x ≥ 0, значит x ≤ 5. **Ответ: D(f) = (−∞; 5].**

### Пример 3 (уровень 2). Найдите область определения функции f(x) = √(x − 2)/(x − 6)

1) Корень: x − 2 ≥ 0 → x ≥ 2. 2) Знаменатель: x − 6 ≠ 0 → x ≠ 6. 3) Пересечение: x ≥ 2 и x ≠ 6. **Ответ: D(f) = [2; 6) ∪ (6; +∞).**

### Пример 4 (уровень 2). Найдите область определения функции f(x) = lg(8 − x)/(x + 1)

1) Логарифм: 8 − x > 0 → x < 8. 2) Знаменатель: x + 1 ≠ 0 → x ≠ −1. 3) Пересечение: x < 8 и x ≠ −1. **Ответ: D(f) = (−∞; −1) ∪ (−1; 8).**

### Пример 5 (уровень 2). По графику функции f (ломаная через точки (−4;−3), (−3;0), (0;3), (3;0), (4;−2)) найдите: f(−2); нули функции; промежуток убывания; область значений

1) f(−2): x = −2 лежит на отрезке от (−3;0) до (0;3), на треть пути от −3 к 0; считаем по наклону: отрезок идёт из (−3;0) в (0;3), наклон = (3−0)/(0−(−3)) = 1; при x = −2 (на 1 правее −3): y = 0 + 1·1 = 1. **f(−2) = 1.**
2) Нули — где график пересекает Ox: это точки (−3;0) и (3;0). **Нули: x = −3 и x = 3.**
3) Убывание — где график идёт вниз слева направо: от (0;3) до (4;−2). **Убывает на [0; 4].**
4) Область значений — от самого низкого (y = −3 при x = −4) до самого высокого (y = 3 при x = 0) уровня графика. **E(f) = [−3; 3].**

### Пример 6 (уровень 3). График функции f проходит через точку (3; 7). Через какую точку проходит график функции g(x) = f(x − 2) + 1?

Сдвиг y = f(x − m) + n сдвигает каждую точку (a; b) исходного графика в точку (a + m; b + n). Здесь m = 2, n = 1, точка (3; 7): новая точка — (3 + 2; 7 + 1) = (5; 8). **Ответ: (5; 8).**

### Пример 7 (уровень 3, формат части А). Найдите область определения функции f(x) = √(6 − 2x)/(x + 1)

1) Корень: 6 − 2x ≥ 0 → −2x ≥ −6 → x ≤ 3 (при делении на отрицательное число знак неравенства меняется). 2) Знаменатель: x + 1 ≠ 0 → x ≠ −1. 3) Пересечение: x ≤ 3 и x ≠ −1.

1) (−∞; −1) ∪ (−1; 3]  2) (−∞; 3]  3) [−1; 3]  4) (−∞; −1) ∪ (−1; 3)  5) x ≤ 3, x ≠ 1

**Ответ: 1) (−∞; −1) ∪ (−1; 3].**

**Разбор неверных вариантов.** Варианты построены на типичных потерях одного из двух условий:
- 2) (−∞; 3] — учли только корень, забыли исключить x = −1 (знаменатель);
- 3) [−1; 3] — ошибочно решили, что область должна начинаться с −1, как будто это ограничение снизу от корня (спутали условие знаменателя «x ≠ −1» с условием «x ≥ −1»);
- 4) (−∞; −1) ∪ (−1; 3) — верно исключили x = −1, но неверно исключили и x = 3: забыли, что при равенстве 6 − 2x = 0 корень всё равно определён (√0 = 0 — это не запрет, граница включается);
- 5) x ≤ 3, x ≠ 1 — арифметическая невнимательность: перепутали корень знаменателя (−1) с числом 1.

Ученику: при ОДЗ всегда два отдельных действия — найти условие и отдельно проверить, включается или не включается граница. Поставить в формулу граничное значение и проверить устно: при x = 3 подкоренное выражение равно 0, а 0 — разрешённое число под корнем, значит x = 3 входит в ответ.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Путает f(x) с произведением | думает, что f(3) значит «f умножить на 3» | проговаривать: «f(3) — это значение функции при x = 3», f — не число, его нельзя умножать |
| Забывает исключить x из ОДЗ при делении | пишет D(f) = ℝ для f(x) = 1/(x − 5) | всегда отдельно спрашивать себя: «есть ли в формуле деление? на что?» |
| Ставит строгое неравенство под корнем | требует x > 3 вместо x ≥ 3 для √(x − 3) | проверить граничное значение устно: √0 = 0 существует, значит граница входит |
| Теряет одно из двух условий ОДЗ | для √(x+5)/(x−2) пишет только x ≥ −5, забывает x ≠ 2 | выписывать условия отдельно пронумерованными пунктами, пересекать в конце |
| Путает направление сдвига по x | думает, что y = f(x − 4) сдвигает график влево | проверить на точке: если f(0) = 5, то у f(x−4) это значение будет при x = 4, то есть точка «уехала» вправо |
| Читает возрастание/убывание не слева направо | смотрит на график справа налево и путает рост с падением | всегда вести пальцем по графику строго в направлении увеличения x |
| Путает область определения с областью значений | для D(f) называет множество y вместо x | спросить: «D — это что мы подставляем (x), E — что получаем (y)» |
| Называет функцией любую линию на рисунке | окружность или «восьмёрка» — считает графиком функции | применить проверку вертикальной прямой на конкретном рисунке |
