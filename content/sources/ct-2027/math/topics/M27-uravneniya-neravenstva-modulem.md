# M27. Уравнения и неравенства с модулем

## Зачем эта тема

**Тема изучается, только если план идёт с опережением.** Это уровень C: в карте теста за ней не закреплена ни одна позиция, урока в плане нет, на неё отведены только 3 часа самостоятельной работы. Если ученик отстаёт хотя бы на урок, тему пропускаем без потерь для цели 60–70.

Зачем она всё-таки может понадобиться: модуль иногда появляется внутри уравнений и неравенств раздела «Уравнения и неравенства», а простые случаи |x| = a, |x| < a, |x| > a решаются по одному правилу за минуту. Тема опирается на M04 (модуль как расстояние) и на запись промежутков из M17 и M21.

Для ученика: *«Модуль — это расстояние до точки на прямой. Нарисовал прямую — и уравнение решилось само».*

## Результат: после темы ученик умеет

- [ ] решить |x| = a при a > 0, a = 0 и a < 0 (|x| = 6 → ±6; |x| = 0 → 0; |x| = −3 → корней нет);
- [ ] решить уравнение с линейным выражением внутри (|x + 2| = 7 → 5; −9);
- [ ] решить |x| < a и |x| > a и записать ответ промежутком (|x| < 4 → (−4; 4));
- [ ] решить неравенство с линейным выражением внутри через двойное неравенство (|2x + 1| ≤ 7 → [−4; 3]);
- [ ] ответить на вопрос формата В: сумма корней, количество целых решений (|2x + 3| ≤ 5 → 6 целых решений).

## Входная проверка (5 минут)

| № | Вопрос | Ответ | Что проверяет |
|---|---|---|---|
| 1 | Найдите \|−7\| и \|3 − 8\| | 7; 5 | смысл модуля (M04) |
| 2 | Расстояние между точками −2 и 3 на прямой | 5 | модуль как расстояние |
| 3 | Решите 2x + 1 = −7 | −4 | линейное уравнение (M16) |
| 4 | Решите −1 ≤ 2x + 1 ≤ 5 | [−1; 2] | двойное неравенство (M17) |

Всё верно — шаги 1–2 читаем бегло и сразу решаем банк. Ошибки в №1–2 — сначала повторить шаг про модуль в M04.

## Теория: сценарий объяснения

### Шаг 1. Модуль — расстояние до нуля

**Суть.** |x| — сколько шагов от точки x до нуля. Расстояние не бывает отрицательным: |x| ≥ 0 всегда.

**Наглядно.** Нарисовать прямую, отметить 0, отступить на 6 клеток вправо и влево: точки 6 и −6. Обе на расстоянии 6.

> **Правило.** |x| = x, если x ≥ 0; |x| = −x, если x < 0. Например, |−5| = −(−5) = 5.

### Шаг 2. Уравнение |x| = a

**Суть.** «Какие точки стоят на расстоянии a от нуля?» Их две (справа и слева), одна (сам ноль) или ни одной (расстояние не может быть отрицательным).

> **Правило.** a > 0: x = a или x = −a. a = 0: x = 0. a < 0: корней нет.

**Мини-пример.** |x| = 6 → x = 6 или x = −6. |x| = −3 → корней нет (сразу, без вычислений).

### Шаг 3. Линейное выражение внутри: |kx + b| = a

**Суть.** Внутри модуля стоит «целый блок». Блок должен быть равен a или −a — получаем два обычных линейных уравнения. Наглядно: |x − 3| — расстояние от x до точки 3; при |x − 3| = 5 от точки 3 отступаем 5 вправо (8) и 5 влево (−2).

> **Правило.** |kx + b| = a, a > 0 ⇔ kx + b = a или kx + b = −a.

**Мини-пример.** |x + 2| = 7: x + 2 = 7 → x = 5; x + 2 = −7 → x = −9. Проверка: |5 + 2| = 7, |−9 + 2| = 7.

### Шаг 4. Неравенства |x| < a и |x| > a

**Суть.** |x| < 4 — «точки ближе 4 к нулю»: это отрезок между −4 и 4. |x| > 4 — «точки дальше 4 от нуля»: два луча наружу. На доске: прямая, точки −4 и 4; для «<» штрихуем середину, для «>» — два края.

> **Правило.** |x| < a ⇔ −a < x < a (одна полоса, «И»).
> |x| > a ⇔ x < −a или x > a (два луча, «ИЛИ»).
> Для ≤ и ≥ точки ±a закрашены. При a ≤ 0: |x| < a решений нет. |x| > a при a < 0 — любое x; |x| > 0 — любое x ≠ 0.

**Мини-пример.** |x| ≤ 3 → [−3; 3]. |x| > 2 → (−∞; −2) ∪ (2; +∞).

### Шаг 5. Неравенство с линейным выражением внутри

> **Правило.** |kx + b| < a ⇔ −a < kx + b < a — решаем двойное неравенство (из всех трёх частей вычитаем b, затем делим на k).
> |kx + b| > a ⇔ kx + b < −a или kx + b > a — два отдельных линейных неравенства, ответ — объединение.

**Мини-пример.** |x − 1| ≥ 3: x − 1 ≤ −3 → x ≤ −2 или x − 1 ≥ 3 → x ≥ 4. Ответ (−∞; −2] ∪ [4; +∞). При k < 0 удобнее сначала переписать |5 − x| = |x − 5| — модули противоположных чисел равны, и знак неравенства не придётся переворачивать.

### Чего сейчас не объясняем

- Уравнения с двумя модулями и с x вне модуля (|x − 1| = 2x + 3) — нужна проверка корней или метод интервалов, это выше нашей цели.
- Модуль квадратного выражения и графики y = |f(x)| — после M21 и M31, только при большом опережении.

## Опорный конспект

| Вид | Что делаем | Пример |
|---|---|---|
| \|x\| = a, a > 0 | x = a или x = −a | \|x\| = 6 → ±6 |
| \|x\| = a, a < 0 | корней нет | \|x\| = −3 → ∅ |
| \|kx + b\| = a | kx + b = a или kx + b = −a | \|x + 2\| = 7 → 5; −9 |
| \|kx + b\| < a | −a < kx + b < a | \|2x + 1\| ≤ 7 → [−4; 3] |
| \|kx + b\| > a | kx + b < −a или kx + b > a | \|x − 1\| ≥ 3 → x ≤ −2 или x ≥ 4 |

**Алгоритм.** 1) Посмотреть на правую часть: если она отрицательна — сразу ответ. 2) Выбрать правило по знаку: «=» — два уравнения, «<» — двойное неравенство, «>» — два неравенства с «или». 3) Решить. 4) Нарисовать ответ на прямой. 5) Ответить на вопрос задачи (сумма корней, число целых решений). 6) Подставить одну точку для проверки.

## Разобранные примеры

### Пример 1 (уровень 1). Найдите сумму корней уравнения |x − 3| = 5

Правая часть 5 > 0 → два случая. x − 3 = 5 → x = 8; x − 3 = −5 → x = −2. Проверка: |8 − 3| = 5, |−2 − 3| = 5. Сумма 8 + (−2) = 6. **Ответ: 6.**

### Пример 2 (уровень 2, формат В). Найдите количество целых решений неравенства |2x + 1| ≤ 7

1) −7 ≤ 2x + 1 ≤ 7. 2) Вычитаем 1: −8 ≤ 2x ≤ 6. 3) Делим на 2: −4 ≤ x ≤ 3. 4) Целые: −4, −3, −2, −1, 0, 1, 2, 3 — концы входят (знак ≤). Считаем: 3 − (−4) + 1 = 8. **Ответ: 8.**

### Пример 3 (уровень 2, формат В). Сколько натуральных чисел не являются решениями неравенства |x − 4| > 3?

1) x − 4 < −3 → x < 1 или x − 4 > 3 → x > 7. 2) Решения — два луча, значит не являются решениями числа 1 ≤ x ≤ 7 (это |x − 4| ≤ 3). 3) Натуральные среди них: 1, 2, …, 7. **Ответ: 7.**

### Пример 4 (уровень 2, формат части А)

Множество решений неравенства |3x − 6| < 9 — это:

1) (−1; 5) 2) (−∞; −1) ∪ (5; +∞) 3) (−5; 1) 4) (−∞; 5) 5) (−1; 5]

**Решение.** −9 < 3x − 6 < 9 → −3 < 3x < 15 → −1 < x < 5. **Ответ: 1.**

**Разбор неверных вариантов.**
- 2) — перепутали «<» и «>»: при «<» решение одна полоса, а не два луча;
- 3) — ошибка знака при переносе: решено |3x + 6| < 9;
- 4) — решили только 3x − 6 < 9 и забыли левую границу;
- 5) — знак строгий, поэтому 5 не входит; квадратная скобка невозможна.

Быстрое отсечение подстановкой: x = −3 даёт |−15| = 15 > 9 — не решение, это убирает 3) и 4); x = 6 даёт |12| = 12 > 9 — убирает 2). Между 1) и 5) решает строгий знак.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Находит корни при отрицательной правой части | \|x\| = −3 → ±3 | первым шагом смотреть на знак справа; «расстояние −3 шага?» |
| Теряет второй корень | \|x + 2\| = 7 → только 5 | всегда писать две строки: «= a» и «= −a» |
| Для «<» пишет два луча | \|x\| < 4 → x < −4 или x > 4 | «меньше — значит ближе к нулю — середина»; проверить x = 0 |
| Для «>» пишет двойное неравенство | \|x\| > 2 → −2 > x > 2 | такое неравенство невозможно; два луча через «или» |
| Вычитает b только из средней части | −7 ≤ 2x + 1 ≤ 7 → −7 ≤ 2x ≤ 6 | «что сделали с серединой — то и с краями» |
| Неверно считает целые точки | от −4 до 3 включительно → 7 | формула «правый − левый + 1» и выписать числа |
| Забывает уединить модуль | \|x − 2\| + 3 = 8 → \|x − 2\| = 8 | сначала оставить модуль один слева |

## Домашняя работа по теме

Урока по теме нет: 3 часа самостоятельной работы, только если план идёт с опережением. Решение о старте принимает репетитор.

- **Подход 1 (~1 ч):** прочитать шаги 1–3, разобрать пример 1, затем 12 задач по типам 1–3 (уровень 1) и 6 (уровень 2). Каждую проверить подстановкой корня.
- **Подход 2 (~1 ч):** шаги 4–5, примеры 2–3, затем 12 задач по типам 4, 5, 8, 10 — в каждой нарисовать прямую.
- **Подход 3 (~1 ч):** пример 4, затем 6 заданий формата В (типы 7–10) и 3 задания формата А по образцу примера 4, перемешанные с 4 задачами по M17 и M21.
- **Карточки:** 7 карточек из конспекта добавить в колоду.
- **Самопроверка:** ответы в конце листа; ошибки — в журнал с пометкой «модуль: знак / второй корень / границы».
