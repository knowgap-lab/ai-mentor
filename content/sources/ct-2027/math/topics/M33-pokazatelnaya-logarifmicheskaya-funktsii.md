# M33. Показательная и логарифмическая функции: свойства и графики

## Зачем эта тема

Тема напрямую даёт задание А10: «свойства логарифмической функции, сдвиги графика». На ЦЭ-2025 его решили 54,1 % — задание средней сложности, но для нас оно решается по одному алгоритму: основание → возрастает или убывает; ОДЗ; асимптота; одна-две контрольные точки. Это 1 первичный балл, который почти не требует счёта.

Кроме того, свойства этих функций объясняют, *почему* работают показательные и логарифмические уравнения (M22, M24) и неравенства (M23, M25): «у функции с основанием меньше 1 знак неравенства меняется» — это и есть убывание. Сравнение чисел вида 0,3^1,2 и 0,3^0,8 встречается в А1.

Для ученика: *«Две функции, четыре факта про каждую и одна картинка. Запомнил картинку — А10 решаешь за 3 минуты».*

## Результат: после темы ученик умеет

- [ ] по основанию сказать, возрастает функция или убывает (y = 0,5^x убывает, y = log₃ x возрастает, y = log_{1/2} x убывает);
- [ ] назвать область определения и множество значений базовых функций (у a^x: D = ℝ, E = (0; +∞); у log_a x: D = (0; +∞), E = ℝ);
- [ ] найти ОДЗ логарифма со сложным аргументом (y = log₂(x − 3) → x > 3; y = lg(9 − x²) → −3 < x < 3);
- [ ] назвать асимптоту графика, в том числе после сдвига (y = 3^{x−2} + 1 → y = 1; y = log₂(x + 1) − 3 → x = −1);
- [ ] нарисовать эскиз графика по трём контрольным точкам и асимптоте (y = 2^x: (−1; 1/2), (0; 1), (1; 2));
- [ ] сравнить два числа через монотонность (0,3^1,2 < 0,3^0,8; log_{0,2} 5 > log_{0,2} 7);
- [ ] проверить, лежит ли точка на графике, и найти нуль функции (y = log₃(x + 4) − 2 → x = 5);
- [ ] решить задание формата А10: отбросить неверные утверждения о функции и выбрать верные.

## Теория: сценарий объяснения

### Шаг 1. Показательная функция: таблица и точки

**Суть.** «Показательная функция — это когда x стоит *в показателе*: y = 2^x. Основание фиксировано, а меняется степень». Сначала просто считаем значения.

**Наглядно.** На доске таблица и точки на клетчатой бумаге:

| x | −2 | −1 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|---|---|
| 2^x | 1/4 | 1/2 | 1 | 2 | 4 | 8 |
| (1/2)^x | 4 | 2 | 1 | 1/2 | 1/4 | 1/8 |

Соединяем точки плавной линией. У 2^x кривая слева «прижимается» к оси Ox, справа резко взлетает. У (1/2)^x — зеркально: слева взлетает, справа прижимается к Ox.

**Правило.**
> y = a^x, где a > 0 и a ≠ 1. Основание 1 не берём: 1^x = 1 — это просто прямая. Отрицательное основание не берём: (−2)^{1/2} не существует.

**Мини-пример.** y = 3^x: y(0) = 1, y(2) = 9, y(−1) = 1/3.

### Шаг 2. Свойства показательной функции

**Суть.** «Четыре факта, которые читаются с картинки».

**Правило.**

| Свойство | y = a^x |
|---|---|
| Область определения | D = ℝ (любой x) |
| Множество значений | E = (0; +∞) — всегда положительна, нуля нет |
| Контрольная точка | (0; 1), потому что a⁰ = 1 |
| Асимптота | **y = 0** (ось Ox): график подходит к ней сколь угодно близко, но не касается |
| Монотонность | a > 1 — возрастает; 0 < a < 1 — убывает |

**Наглядно.** Рука ведёт по графику слева направо: «у 2^x идём вверх — возрастает; у (1/2)^x идём вниз — убывает». Обе кривые проходят через (0; 1) и никогда не опускаются ниже оси Ox.

**Мини-пример.** Уравнение 5^x = −3 корней не имеет: значения 5^x всегда больше нуля.

### Шаг 3. Логарифмическая функция — «перевёрнутая» показательная

**Суть.** «Логарифм отвечает на вопрос: в какую степень возвести 2, чтобы получить x. Поэтому таблица для log₂ x — это таблица 2^x, в которой поменяли строки местами».

**Наглядно.**

| x | 1/4 | 1/2 | 1 | 2 | 4 | 8 |
|---|---|---|---|---|---|---|
| log₂ x | −2 | −1 | 0 | 1 | 2 | 3 |

Рисуем рядом с y = 2^x и проводим пунктиром y = x: графики симметричны относительно этой прямой, как отражение в зеркале. Точка (0; 1) превращается в (1; 0), точка (1; 2) — в (2; 1).

**Правило.**
> y = log_a x, где a > 0, a ≠ 1. Аргумент x > 0: логарифм нуля и отрицательного числа не существует.

**Мини-пример.** y = log₃ x: y(1) = 0, y(9) = 2, y(1/3) = −1.

### Шаг 4. Свойства логарифмической функции

**Правило.**

| Свойство | y = a^x | y = log_a x |
|---|---|---|
| Область определения | ℝ | **(0; +∞)** |
| Множество значений | (0; +∞) | **ℝ** |
| Контрольная точка | (0; 1) | **(1; 0)** |
| Вторая точка | (1; a) | (a; 1) |
| Асимптота | **y = 0** (горизонтальная) | **x = 0** (вертикальная, ось Oy) |
| a > 1 | возрастает | возрастает |
| 0 < a < 1 | убывает | убывает |

**Суть (сказать вслух).** «D и E у них меняются местами, точки (0; 1) и (1; 0) меняются местами, асимптота y = 0 становится x = 0. А монотонность одинаковая: основание больше 1 — обе растут, меньше 1 — обе падают».

**Знак логарифма.** При a > 1: log_a x < 0 при 0 < x < 1 и log_a x > 0 при x > 1. При 0 < a < 1 — наоборот. Пример: log_{0,3} 2 < 0, потому что основание меньше 1, а аргумент больше 1.

**Мини-пример.** y = log_{1/2} x убывает: log_{1/2} 2 = −1, log_{1/2} 4 = −2 — аргумент вырос, значение уменьшилось.

### Шаг 5. Сравнение чисел через монотонность

**Суть.** «Возрастающая функция сохраняет порядок, убывающая — переворачивает».

**Алгоритм.**
1. Привести оба числа к одному основанию.
2. Посмотреть на основание: больше 1 или меньше 1.
3. a > 1 — какой показатель (аргумент) больше, то число и больше. 0 < a < 1 — наоборот.

**Мини-пример.** 0,7^{−2} и 0,7³: основание 0,7 < 1, функция убывает; −2 < 3, значит 0,7^{−2} > 0,7³. Проверка: 0,7^{−2} ≈ 2, а 0,7³ ≈ 0,34.

### Шаг 6. Сдвиги графиков (опора — M31)

**Суть.** «Правила сдвига те же, что у параболы. Вместе с графиком сдвигается и асимптота, и контрольная точка».

**Правило.**
> y = a^{x − m} + n: график a^x сдвинут на m вправо и на n вверх; асимптота **y = n**; E = (n; +∞); точка (m; 1 + n).
>
> y = log_a(x − m) + n: график log_a x сдвинут на m вправо и на n вверх; асимптота **x = m**; D = (m; +∞); точка (m + 1; n).

**Наглядно.** Сначала рисуем пунктиром асимптоту, потом ставим сдвинутую контрольную точку, потом — кривую того же вида, что у базовой функции.

**Ловушка.** «x + 1 в скобке — сдвиг *влево* на 1». y = log₂(x + 1): асимптота x = −1, а не x = 1.

**Мини-пример.** y = 2^{x+1} + 3: сдвиг на 1 влево и на 3 вверх, асимптота y = 3, E = (3; +∞).

### Шаг 7. ОДЗ логарифма со сложным аргументом

**Суть.** «Всё, что стоит под знаком логарифма, — строго больше нуля. Записываем это неравенство и решаем».

**Алгоритм.**
1. Выписать каждый аргумент логарифма: аргумент > 0.
2. Решить неравенства (линейные — M17, квадратные — M21).
3. Если логарифмов несколько — взять пересечение.

**Мини-пример.** y = log₅(2x − 6): 2x − 6 > 0, x > 3, D = (3; +∞).

### Шаг 8. Как решать А10

**Алгоритм проверки утверждений.**
1. Выписать функцию и подчеркнуть основание: > 1 или < 1 → возрастает или убывает.
2. Найти D (для логарифма) или E (для показательной) с учётом сдвига.
3. Назвать асимптоту.
4. Каждую точку из вариантов проверять подстановкой.
5. Читать инструкцию: в А10 бывает несколько верных ответов — проверить все пять утверждений, а не остановиться на первом верном.

### Чего сейчас не объясняем

- Показательные и логарифмические неравенства — отдельные темы M23 и M25; здесь только идея «убывание переворачивает знак».
- Число e и натуральный логарифм ln x — в ЦТ почти не встречаются, к ним вернёмся только с производной (M35).
- Растяжения графиков (y = 2 · 3^x, y = log₂(3x)) — в А10 редки, разбираем по запросу.
- Модуль в аргументе (y = log₂|x|) — уровень C.

## Опорный конспект

| | y = a^x | y = log_a x |
|---|---|---|
| Условие на основание | a > 0, a ≠ 1 | a > 0, a ≠ 1 |
| D | ℝ | (0; +∞) |
| E | (0; +∞) | ℝ |
| Точка | (0; 1) | (1; 0) |
| Асимптота | y = 0 | x = 0 |
| a > 1 | ↗ возрастает | ↗ возрастает |
| 0 < a < 1 | ↘ убывает | ↘ убывает |
| Со сдвигом | a^{x−m} + n: асимптота y = n, E = (n; +∞) | log_a(x − m) + n: асимптота x = m, D = (m; +∞) |

**Сравнение.** Одно основание → a > 1: порядок сохраняется; 0 < a < 1: порядок переворачивается.

**ОДЗ.** Аргумент логарифма > 0, каждый аргумент отдельно, потом пересечение.

**Образец оформления А10.** «y = log_{1/2}(x − 2) + 1. Основание 1/2 < 1 → убывает. D: x − 2 > 0, x > 2. Асимптота x = 2. E = ℝ. Точка (3; 1)». После этого каждый вариант проверяется по этой записи.

## Разобранные примеры

### Пример 1 (уровень 1). Найдите наименьшее целое число из области определения функции y = log₂(x − 3)

Аргумент логарифма больше нуля: x − 3 > 0, x > 3. D = (3; +∞). Число 3 не входит (неравенство строгое), значит наименьшее целое — 4. **Ответ: 4.**

### Пример 2 (уровень 1). Сравните 0,3^{1,2} и 0,3^{0,8}

Основание одинаковое: 0,3 < 1, функция y = 0,3^x убывает. Показатели: 1,2 > 0,8. Убывающая функция переворачивает порядок: 0,3^{1,2} < 0,3^{0,8}. **Ответ: 0,3^{1,2} < 0,3^{0,8}.**

Ученику: «Большая степень — больше число» верно только при основании больше 1. Проверка прикидкой: 0,3^{1,2} ≈ 0,24, 0,3^{0,8} ≈ 0,38.

### Пример 3 (уровень 2). Постройте эскиз графика y = log₂(x + 1) − 3 и найдите нуль функции

1) Базовая функция log₂ x, основание 2 > 1 — возрастает.
2) Сдвиг: «x + 1» — на 1 влево, «−3» — на 3 вниз. Асимптота x = −1, D = (−1; +∞).
3) Контрольные точки (подставляем аргумент — степень двойки):

| x | 0 | 1 | 3 | 7 |
|---|---|---|---|---|
| x + 1 | 1 | 2 | 4 | 8 |
| y | −3 | −2 | −1 | 0 |

4) Нуль функции: log₂(x + 1) = 3, x + 1 = 8, x = 7.

**Ответ:** асимптота x = −1, график проходит через (0; −3) и пересекает Ox в точке (7; 0); нуль x = 7.

### Пример 4 (уровень 2). Найдите множество значений и асимптоту функции y = 3^{x−2} + 1

1) 3^{x−2} > 0 при любом x. Прибавляем 1: y > 1. E = (1; +∞).
2) Асимптота сдвигается вместе с графиком: y = 1.
3) Контрольная точка: при x = 2 показатель 0, y = 3⁰ + 1 = 2. При x = 3: y = 3 + 1 = 4.

**Ответ:** E = (1; +∞), асимптота y = 1.

### Пример 5 (уровень 3, формат части В — ответ целым числом)

Найдите сумму всех целых чисел из области определения функции y = lg(10 − x) + log₅(x − 3).

1) Первый аргумент: 10 − x > 0, x < 10.
2) Второй аргумент: x − 3 > 0, x > 3.
3) Пересечение: 3 < x < 10. Целые: 4, 5, 6, 7, 8, 9.
4) Сумма: 4 + 5 + 6 + 7 + 8 + 9 = 39.

**Ответ: 39.**

Проверка: концы 3 и 10 не входят — при x = 3 аргумент log₅ равен 0, при x = 10 аргумент lg равен 0.

### Пример 6 (уровень 2, формат части А)

Укажите верное утверждение о функции y = log_{1/2}(x − 2) + 1:

1) функция возрастает на всей области определения
2) область определения функции — промежуток (−∞; 2)
3) график функции проходит через точку (3; 1)
4) асимптота графика — прямая x = −2
5) множество значений функции — промежуток (1; +∞)

**Решение по алгоритму А10.** Основание 1/2 < 1 → убывает. D: x − 2 > 0, x > 2, то есть (2; +∞). Асимптота x = 2. E = ℝ (у логарифма значения любые, сдвиг вверх этого не меняет). Точка: x = 3 → log_{1/2} 1 + 1 = 0 + 1 = 1, то есть (3; 1) лежит на графике. **Ответ: 3.**

**Разбор неверных вариантов.**
- 1) «возрастает» — не посмотрел на основание: 1/2 < 1;
- 2) (−∞; 2) — решил x − 2 > 0 с ошибкой знака;
- 4) x = −2 — перепутал направление сдвига: «x − 2» — сдвиг вправо, асимптота x = 2;
- 5) (1; +∞) — перенёс свойство показательной функции на логарифмическую: у логарифма E = ℝ.

Ученику: в А10 бывает несколько верных ответов. Даже найдя вариант 3, проверь остальные четыре.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Не смотрит на основание при монотонности | «y = 0,5^x возрастает» | Первым действием подчеркнуть основание и написать «> 1» или «< 1» |
| Переносит E показательной на логарифм | «у log₂ x значения положительные» | Таблица: log₂(1/2) = −1 — значение отрицательное |
| Путает асимптоты | «у 2^x асимптота x = 0» | Нарисовать: 2^x лежит над осью Ox и прижимается к ней — асимптота горизонтальная, y = 0 |
| Сдвиг в неправильную сторону | y = log₂(x + 1): асимптота x = 1 | Приравнять аргумент к нулю: x + 1 = 0 → x = −1 |
| Нестрогое неравенство в ОДЗ | log₂(x − 3): «x ≥ 3» | Подставить x = 3: log₂ 0 — не существует |
| Забывает сдвиг E у показательной | y = 5^x − 4: «E = (0; +∞)» | E сдвигается вместе с асимптотой: 5^x > 0 → 5^x − 4 > −4 |
| Сравнивает «по показателю» при основании < 1 | 0,3^{1,2} > 0,3^{0,8} | Прикидка: 0,5² = 0,25 меньше 0,5¹ = 0,5 |
| В А10 останавливается на первом верном | отмечает только 1 из 3 верных | Правило: проверить все пять утверждений и поставить отметку у каждого |
