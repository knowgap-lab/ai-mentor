# M35. Производная: вычисление, касательная, наибольшее и наименьшее значение

## Зачем эта тема

**Тема изучается, только если план идёт с опережением.** Это уровень C: в плане уроков её нет (0 часов урока), она даётся дома, когда все темы уровней A и B уже усвоены. Напрямую тема даёт позицию В19 «наибольшее/наименьшее значение функции» — 2 первичных балла. На ЦЭ-2025 её решили только 18,5 % участников, поэтому для нашей цели 60–70 она не обязательна.

Почему всё же стоит взять, если есть время: в простом варианте (парабола на отрезке) В19 решается по алгоритму из пяти шагов, а опоры уже есть — чтение графика (M29) и квадратный трёхчлен (M19).

Для ученика: *«Это задание решает меньше пятой части выпускников. Если ты его решишь — это 2 балла, которых нет у большинства»*.

## Результат: после темы ученик умеет

- [ ] находить производную многочлена по трём правилам: (xⁿ)′ = n·xⁿ⁻¹, (c)′ = 0, производная суммы — сумма производных ((x³ − 4x)′ = 3x² − 4);
- [ ] вычислять значение производной в точке (f(x) = x² − 4x + 7, f′(1) = −2);
- [ ] объяснять, что f′(x₀) — угловой коэффициент касательной в точке x₀;
- [ ] составлять уравнение касательной y = f(x₀) + f′(x₀)(x − x₀) (к y = x² в точке x₀ = 1: y = 2x − 1);
- [ ] находить наибольшее и наименьшее значение параболы на отрезке (y = x² − 4x на [0; 5]: наибольшее 5, наименьшее −4);
- [ ] решать задание В19 и записывать ответ целым числом.

|---|---|---|---|

| 2 | Чему равен угловой коэффициент прямой y = 2x − 3? | 2 | смысл k в y = kx + b |
| 3 | Раскройте скобки: −1 + 4(x − 2) | 4x − 9 | раскрытие скобок для уравнения касательной |

Все верно — шаги 1–2 кратко, сразу к касательной и отрезку. Ошибки в №1 или №3 — сначала повторить подстановку и скобки (M09, M10), иначе тема не пойдёт.

## Теория: сценарий объяснения

### Шаг 1. Что показывает производная

**Суть.** Производная f′(x) — это «скорость роста» функции в точке: насколько быстро растёт y при малом сдвиге x. Если f′(x) > 0, функция в этом месте растёт, если f′(x) < 0 — убывает, если f′(x) = 0 — график «на секунду горизонтален» (вершина параболы).

**Наглядно.** Нарисовать параболу y = x² и в точке (1; 1) приложить линейку так, чтобы она только касалась графика. Это касательная. Её наклон (угловой коэффициент) и есть f′(1) = 2. В вершине (0; 0) линейка лежит горизонтально — f′(0) = 0.

**Правило.**
> f′(x₀) = угловой коэффициент k касательной к графику в точке x₀. f′ > 0 — функция возрастает, f′ < 0 — убывает.

**Мини-пример.** Для y = x² производная 2x; f′(3) = 6 — в точке x = 3 график круто идёт вверх.

### Шаг 2. Как вычислять производную многочлена

**Суть.** Формулу производной не выводим, пользуемся тремя правилами. Каждое слагаемое дифференцируем отдельно: показатель степени «спускается» множителем, а сама степень уменьшается на 1.

**Наглядно.** Стрелка на доске: x³ → 3·x². Число спереди переходит множителем: 5x³ → 5·3x² = 15x².

**Правило.**

| Функция | Производная |
|---|---|
| c (число) | 0 |
| x | 1 |
| kx | k |
| xⁿ | n·xⁿ⁻¹ |
| c·f(x) | c·f′(x) |
| f(x) + g(x) | f′(x) + g′(x) |

**Мини-пример.** (x³ − 4x² + 5x − 2)′ = 3x² − 8x + 5.

### Шаг 3. Уравнение касательной

**Суть.** Касательная — прямая, которая проходит через точку графика (x₀; f(x₀)) и имеет наклон f′(x₀). Подставляем два числа в готовую формулу.

**Правило.**
> y = f(x₀) + f′(x₀)(x − x₀). Порядок: 1) f(x₀); 2) f′(x); 3) f′(x₀); 4) подставить и раскрыть скобки до вида y = kx + b.

**Мини-пример.** y = x², x₀ = 1: f(1) = 1, f′(x) = 2x, f′(1) = 2, y = 1 + 2(x − 1) = 2x − 1.

### Шаг 4. Наибольшее и наименьшее значение на отрезке

**Суть.** На отрезке [a; b] функция берёт наибольшее и наименьшее значение либо на концах, либо в точке, где f′(x) = 0. Значит, достаточно сравнить несколько чисел.

**Наглядно.** Нарисовать параболу и «окошко» [a; b]. Если вершина внутри окошка — она кандидат; если снаружи — смотрим только концы.

**Правило (алгоритм В19).**
> 1) f′(x); 2) решить f′(x) = 0; 3) оставить корни, лежащие в [a; b]; 4) посчитать f в этих корнях и на концах a, b; 5) выбрать наибольшее и наименьшее из чисел.

**Мини-пример.** y = x² − 4x на [0; 5]: f′ = 2x − 4 = 0, x = 2 ∈ [0; 5]. f(0) = 0, f(2) = −4, f(5) = 5. Наибольшее 5, наименьшее −4.

### Чего сейчас не объясняем

Определение производной через предел, производные тригонометрических, показательных функций, произведения и частного, сложной функции, исследование кубических функций на экстремумы. Для В19 в простом варианте хватает многочленов и параболы; остальное — только если В19 стабильно решается.

## Опорный конспект

- **Правила:** (c)′ = 0; (x)′ = 1; (xⁿ)′ = n·xⁿ⁻¹; (c·f)′ = c·f′; (f + g)′ = f′ + g′.
- **Смысл:** f′(x₀) = k касательной; f′ > 0 — растёт, f′ < 0 — убывает.
- **Касательная:** y = f(x₀) + f′(x₀)(x − x₀).
- **Касательная параллельна прямой y = kx + b** ⇔ f′(x₀) = k.
- **Отрезок [a; b]:** f′ = 0 → корни внутри отрезка → f в корнях и на концах → выбрать.

Образец: *y = x² − 6x + 5, [0; 4]. 1) y′ = 2x − 6. 2) 2x − 6 = 0, x = 3 ∈ [0; 4]. 3) y(0) = 5, y(3) = −4, y(4) = −3. Ответ: наибольшее 5, наименьшее −4.*

| Вопрос | Ответ |

| Производная числа | 0 |
| (7x)′ = ? | 7 |
| Геометрический смысл f′(x₀) | угловой коэффициент касательной в точке x₀ |
| Уравнение касательной | y = f(x₀) + f′(x₀)(x − x₀) |
| Касательная параллельна y = 4x + 1. Условие | f′(x₀) = 4 |
| Где искать наибольшее/наименьшее на [a; b] | на концах и в точках f′ = 0 внутри отрезка |
| Вершина параболы вне отрезка — что считать | только значения на концах |

## Разобранные примеры

### Пример 1 (уровень 1). f(x) = x³ − 4x² + 5x − 2. Найдите f′(2)

f′(x) = 3x² − 8x + 5. f′(2) = 3·4 − 8·2 + 5 = 12 − 16 + 5 = 1. **Ответ: 1.**

### Пример 2 (уровень 2). Уравнение касательной к f(x) = x² − 3x + 1 в точке x₀ = 2

1) f(2) = 4 − 6 + 1 = −1. 2) f′(x) = 2x − 3. 3) f′(2) = 1. 4) y = −1 + 1·(x − 2) = x − 3. **Ответ: y = x − 3.** Проверка: точка (2; −1) лежит на прямой: 2 − 3 = −1.

### Пример 3 (уровень 3, формат В19). Найдите наибольшее значение функции f(x) = x² − 6x + 5 на отрезке [0; 4]

1) f′(x) = 2x − 6. 2) 2x − 6 = 0, x = 3; 3 ∈ [0; 4] — берём. 3) f(0) = 5, f(3) = 9 − 18 + 5 = −4, f(4) = 16 − 24 + 5 = −3. 4) Наибольшее из 5, −4, −3 — это 5. **Ответ: 5.** Ловушка: значение в вершине (−4) — наименьшее, а не наибольшее; у параболы ветвями вверх наибольшее всегда на конце.

### Пример 4 (уровень 2, формат части А). Угловой коэффициент касательной к графику f(x) = 2x² − 5x + 3 в точке x₀ = 3 равен:

1) 3; 2) 7; 3) 6; 4) 12; 5) −5.

f′(x) = 4x − 5, f′(3) = 12 − 5 = 7. **Ответ: 2) 7.** Как отсечь: 6 = f(3) — посчитали значение функции, а не производной; 12 = 4·3 — забыли −5; −5 — взяли свободный член производной; 3 — подставили x₀ вместо k.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Производная числа не ноль | (x² + 5)′ = 2x + 5 | проговаривать «число без x исчезает» |
| Степень не уменьшили | (x³)′ = 3x³ | правило «спустить и уменьшить на 1»; проверка: степень производной на 1 меньше |
| В касательную подставили f′(x), а не f′(x₀) | y = 1 + 2x(x − 1) | касательная — прямая; если в ответе x², ошибка |
| Перепутали f(x₀) и f′(x₀) | в примере 4 выбрали 6 | писать столбиком: «f(x₀) = …, f′(x₀) = …» |
| Забыли концы отрезка | в примере 3 ответили −4 на вопрос «наибольшее» | всегда f(a) и f(b); f(вершина) — только если вершина ∈ [a; b] |
| Взяли корень f′ = 0 вне отрезка | банк №8: f(4) = −6 | проверять «x₀ ∈ [a; b]?» перед подстановкой |
| Ответили точкой, а не значением | «наибольшее при x = 0» вместо 5 | В19 спрашивает значение функции, а не x |

## Домашняя работа по теме

Даётся только при опережении плана, 4 часа на 1–2 недели вместо части блока C.

- **День 1 (40 мин):** перечитать шаги 1–2, 15 производных многочленов (типы 1–3), сверка ответов.
- **День 2 (50 мин):** 8 уравнений касательной (тип 4), 4 задачи «параллельна прямой» (тип 6).
- **День 3 (50 мин):** 10 задач на отрезок (типы 7–10); в каждой выписывать f(a), f(b) и, если вершина внутри отрезка, f(вершина).
- **День 4 (40 мин):** 6 задач В19 из сборников РИКЗ / РЕШУ ЦТ вперемешку с 4 задачами по M19 и M31.
- **Карточки:** 8 карточек из таблицы выше — в колоду.

Самопроверка: ученик сверяет ответы, отмечает ошибки в журнале; для задач на отрезок проверяет, что ответ — одно из значений на концах и в вершине внутри отрезка, и целое.

## Если тема не усвоена

- Ошибки в производной (типы 1–2) — повторить степени (M06) и подстановку (M09), 20 производных одночленов.
- Касательная получается с x² или не проходит через (x₀; f(x₀)) — разделить на 4 шага, решать по шаблону-таблице; 10 задач.
- На отрезке ошибается с выбором — вернуться к параболе (M31): рисовать эскиз, отмечать вершину и отрезок.
- Если после 4 часов В19 не решается стабильно (< 60 % верных) — тему оставить; уровень C не стоит баллов по темам A и B.
