# M19. Квадратные уравнения, теорема Виета, квадратный трёхчлен

## Зачем эта тема

У этой темы нет своей отдельной позиции в тесте — ни одно задание А1–А10 или В1–В20 не называется прямо «квадратное уравнение». Но это обманчивое спокойствие: квадратное уравнение — это шаг внутри решения доброй половины заданий части В. Показательные уравнения (В6, тема М22) и логарифмические уравнения (В11, тема М24) после замены переменной почти всегда превращаются именно в квадратное. Иррациональные уравнения (В15, тема М26) и дробно-рациональные уравнения (М20) на последнем шаге снова приводят к квадратному. Квадратичная функция и её график (А4, тема М31) понимаются только через корни и дискриминант. Если решение квадратного уравнения не доведено до автоматизма, ученик будет решать не задание В6 или В11, а квадратное уравнение внутри него — и терять время и баллы там, где основная идея была уже понята.

Для ученика: *«Это уравнение само по себе не даёт баллов. Но оно сидит внутри десятка заданий частей В, которые дают баллы. Не выучишь это — не возьмёшь их»*.

## Результат: после темы ученик умеет

- [ ] назвать квадратное уравнение по виду ax² + bx + c = 0 (a ≠ 0) и определить его коэффициенты a, b, c (в 3x² − 5x + 2 = 0: a = 3, b = −5, c = 2);
- [ ] решать неполные квадратные уравнения без формулы — вынесением x или через x² = число (x² − 7x = 0 → x = 0 или x = 7; x² − 16 = 0 → x = ±4);
- [ ] вычислять дискриминант D = b² − 4ac и по его знаку сразу сказать, сколько у уравнения действительных корней, без решения до конца (D = 1 > 0 — два корня; D = 0 — один корень; D = −3 < 0 — корней нет);
- [ ] находить корни квадратного уравнения по формуле x = (−b ± √D) / (2a) (x² − 5x + 6 = 0 → x = 3 или x = 2);
- [ ] применять теорему Виета, чтобы найти сумму и произведение корней без решения уравнения (для x² − 5x + 6 = 0: x₁ + x₂ = 5, x₁x₂ = 6);
- [ ] подбирать целые корни устно по обратной теореме Виета, без дискриминанта (x² + x − 6 = 0 → ищем два числа с суммой −1 и произведением −6: это 2 и −3);
- [ ] разложить квадратный трёхчлен на множители через его корни, ax² + bx + c = a(x − x₁)(x − x₂) (2x² − 2x − 4 = 2(x − 2)(x + 1));
- [ ] находить значение выражения с корнями уравнения (например, x₁² + x₂²) через теорему Виета, без явного вычисления самих корней.

## Входная проверка (5 минут)

| № | Вопрос | Ответ | Что проверяет |
|---|---|---|---|
| 1 | Разложите на множители: x² − 9 | (x − 3)(x + 3) | формула разности квадратов (М10) |
| 2 | Вычислите √49 | 7 | арифметический квадратный корень (М07) |
| 3 | Решите уравнение: 2x − 6 = 0 | x = 3 | линейное уравнение (М16) |
| 4 | Раскройте скобки: (x − 2)(x + 5) | x² + 3x − 10 | умножение многочленов (М10) |
| 5 | Если x₁ = 2, x₂ = 3, чему равны x₁ + x₂ и x₁ · x₂? | 5 и 6 | готовность к идее теоремы Виета |

Всё верно — теорию по неполным уравнениям (шаги 1–2) проходим бегло, основное время отдаём дискриминанту, формуле корней и особенно теореме Виета (шаги 3–7), это ядро темы. Ошибка в №2 — повторяем квадратный корень (М07). Ошибки в №1 или №4 — пять минут повторяем разложение на множители (М10), без него не получится ни разложить трёхчлен, ни быстро прикинуть корни устно.

## Теория: сценарий объяснения

### Шаг 1. Квадратное уравнение и его стандартный вид

**Суть.** Квадратное уравнение — это уравнение, где переменная встречается в квадрате и это старшая степень: ax² + bx + c = 0, где a, b, c — числа (коэффициенты), и обязательно a ≠ 0 (если a = 0, x² исчезает, и уравнение становится линейным — темой М16, а не этой). b и c могут быть любыми, в том числе равными нулю.

**Наглядно.** Записать рядом три уравнения: 3x² − 5x + 2 = 0 (есть все три члена), x² − 16 = 0 (нет члена с x, то есть b = 0) и x² − 7x = 0 (нет свободного члена, c = 0) — и сразу подчеркнуть коэффициенты в каждом цветом: a красным, b синим, c зелёным.

**Правило.**
> Стандартный вид: ax² + bx + c = 0, a ≠ 0. a — коэффициент при x², b — коэффициент при x, c — свободный член (число без x). Если в уравнении есть скобки или перенос слагаемых — сначала всё переносится в одну сторону и приводится к этому виду, как в линейных уравнениях (М16).

**Мини-пример.** В уравнении 3x² − 5x + 2 = 0: a = 3, b = −5, c = 2. В уравнении 4 − x² = 3x, после переноса: −x² − 3x + 4 = 0, то есть (умножив на −1 для удобства) x² + 3x − 4 = 0: a = 1, b = 3, c = −4.

### Шаг 2. Неполные квадратные уравнения

**Суть.** Если b = 0 или c = 0 (или оба сразу), уравнение называется неполным — его решают быстрее, без общей формулы, прямыми приёмами.

**Наглядно.** Два отдельных случая на доске: «c = 0 → в уравнении есть общий множитель x → выносим его» и «b = 0 → уравнение вида x² = число → извлекаем корень (М07), не забывая про знак ±».

**Правило.**
> Если c = 0: ax² + bx = 0 → x(ax + b) = 0 → x = 0 или x = −b/a (произведение равно нулю, когда один из множителей равен нулю).
> Если b = 0: ax² + c = 0 → x² = −c/a → x = ±√(−c/a), если −c/a ≥ 0; если −c/a < 0 — корней нет (отрицательного числа квадратным корнем не извлечь, М07).
> Если b = 0 и c = 0: ax² = 0 → x = 0 (единственный корень).

**Мини-пример.** x² − 7x = 0 → x(x − 7) = 0 → x = 0 или x = 7. x² − 16 = 0 → x² = 16 → x = ±4.

**Ловушка (сказать вслух).** В уравнении x² − 7x = 0 часто сокращают обе части на x и теряют корень x = 0: x² − 7x = 0 → x − 7 = 0 → x = 7 — неверно, потерян один из двух корней. На x можно делить только тогда, когда заранее доказано, что x ≠ 0; правильный путь — всегда выносить общий множитель, а не сокращать.

### Шаг 3. Дискриминант

**Суть.** Прежде чем искать сами корни, полезно узнать, сколько их будет и есть ли они вообще — для этого считают дискриминант. Слово «дискриминант» буквально означает «различающий»: по его знаку видно, различаются ли корни, совпадают, или их нет вовсе среди действительных чисел.

**Наглядно.** Таблица на доске с тремя строками — знак D и число корней, — и напротив каждой строки по одному короткому уравнению-примеру, которое ученик проверяет сам.

**Правило.**
> D = b² − 4ac.
> D > 0 — два разных корня.
> D = 0 — один корень (говорят также «два совпадающих корня»).
> D < 0 — действительных корней нет.

**Мини-пример.** Для x² − 5x + 6 = 0: a = 1, b = −5, c = 6 → D = (−5)² − 4·1·6 = 25 − 24 = 1 > 0 — два корня.
Для x² − 6x + 9 = 0: D = 36 − 36 = 0 — один корень.
Для x² + x + 1 = 0: D = 1 − 4 = −3 < 0 — корней нет.

**Ловушка (сказать вслух).** В формуле D = b² − 4ac знак коэффициента b уходит сам при возведении в квадрат — b² всегда неотрицателен, независимо от знака самого b. Ошибка возникает не здесь, а в знаке произведения 4ac: если c отрицательно, то −4ac становится положительным слагаемым, а не вычитается. Проверка — переписать −4ac как отдельное слагаемое со своим знаком, прежде чем складывать с b².

### Шаг 4. Формула корней квадратного уравнения

**Суть.** Если D ≥ 0, корни находят по одной и той же готовой формуле — её не выводят на уроке каждый раз, а запоминают и подставляют числа.

**Наглядно.** Записать формулу один раз крупно на отдельном листе и не убирать её с глаз до конца урока: «числитель — минус b, плюс-минус корень из D; знаменатель — два a».

**Правило.**
> x = (−b ± √D) / (2a), где D = b² − 4ac ≥ 0. При D > 0 знаки ± дают два разных корня x₁ и x₂. При D = 0 формула даёт один корень x = −b / (2a) (знак ± не имеет значения, потому что √D = 0).

**Мини-пример.** x² − 5x + 6 = 0: a = 1, b = −5, D = 1 (посчитан в шаге 3). x = (5 ± 1) / 2 → x₁ = (5 + 1)/2 = 3, x₂ = (5 − 1)/2 = 2. **Корни: 3 и 2.**

**Ловушка (сказать вслух).** В числителе стоит «минус b», то есть знак коэффициента b нужно сменить, прежде чем подставлять. Для b = −5 в числителе пишут −(−5) = +5, а не −5. Самая частая арифметическая ошибка темы — забыть сменить знак b при подстановке.

### Шаг 5. Приведённое квадратное уравнение

**Суть.** Если a = 1, уравнение называют приведённым: x² + px + q = 0. Для него формула корней упрощается и коэффициенты называют уже не a, b, c, а p и q — это пригодится в следующем шаге, в теореме Виета.

**Правило.**
> Приведённое уравнение: x² + px + q = 0. Формула корней: x = −p/2 ± √((p/2)² − q). Любое неприведённое уравнение ax² + bx + c = 0 делением обеих частей на a превращается в приведённое: x² + (b/a)x + (c/a) = 0, то есть p = b/a, q = c/a.

**Мини-пример.** x² − 5x + 6 = 0 уже приведённое: p = −5, q = 6. x = 5/2 ± √((5/2)² − 6) = 5/2 ± √(25/4 − 24/4) = 5/2 ± √(1/4) = 5/2 ± 1/2 → x = 3 или x = 2 — те же корни, что в шаге 4, другим путём.

### Шаг 6. Теорема Виета (прямая)

**Суть.** Это самый важный приём темы для теста: не решая уравнение до конца, можно сразу сказать, чему равна сумма и произведение его корней — просто по коэффициентам. Это экономит время там, где в задаче спрашивают не сами корни, а что-то, что через них выражается.

**Наглядно.** Записать рядом формулу и проверку на уже решённом примере: «x² − 5x + 6 = 0 имеет корни 3 и 2. Сложим их: 3 + 2 = 5 — это коэффициент b = −5, взятый с обратным знаком. Умножим: 3 · 2 = 6 — это c». Теорема просто фиксирует закономерность, которая уже видна на числах.

**Правило.**
> Для приведённого уравнения x² + px + q = 0 с корнями x₁, x₂: x₁ + x₂ = −p, x₁x₂ = q.
> Для общего уравнения ax² + bx + c = 0 с корнями x₁, x₂: x₁ + x₂ = −b/a, x₁x₂ = c/a.
> Теорема работает только тогда, когда у уравнения действительно есть корни, то есть D ≥ 0.

**Мини-пример.** Для 3x² − 12x + 5 = 0 (a = 3, b = −12, c = 5), не решая уравнение: x₁ + x₂ = −(−12)/3 = 4, x₁x₂ = 5/3.

**Ловушка (сказать вслух).** Сумма корней равна −b/a, а не b/a — знак обязательно меняется. Проверка на уже решённом примере: в x² − 5x + 6 = 0 коэффициент b = −5, а сумма корней положительна и равна 5 = −(−5), а не −5.

### Шаг 7. Теорема Виета (обратная): устный подбор корней

**Суть.** Теорема работает и в обратную сторону: если нужно решить приведённое уравнение x² + px + q = 0 с целыми p и q, часто быстрее не считать дискриминант, а подобрать в уме два числа, сумма которых равна −p, а произведение равно q. Это именно тот навык «без калькулятора», который экономит время на тесте.

**Наглядно.** Записать уравнение и рядом — вопрос вслух: «ищу два числа: произведение −6, сумма −1. Начинаю с делителей числа 6: 1 и 6, 2 и 3. Нужно, чтобы один был отрицательным (произведение отрицательное). Пробую 2 и −3: произведение −6 ✓, сумма −1 ✓».

**Алгоритм.**
1. Разложить |q| на пары множителей.
2. Определить знаки обоих чисел по знаку q (произведение): если q > 0 — числа одного знака; если q < 0 — числа разных знаков.
3. Из подходящих по знаку пар выбрать ту, где сумма (с учётом знаков) равна −p.
4. Проверить подстановкой в исходное уравнение.

**Мини-пример.** x² + x − 6 = 0: p = 1, q = −6. Ищем два числа с произведением −6 и суммой −1 (= −p). Делители 6: 1 и 6, 2 и 3. Знаки разные (q < 0). Пробуем 2 и −3: 2·(−3) = −6 ✓, 2 + (−3) = −1 ✓. **Корни: 2 и −3.**

**Ещё пример.** x² + 2x − 15 = 0: p = 2, q = −15. Сумма должна быть −2, произведение −15. Делители 15: 1 и 15, 3 и 5. Пробуем 3 и −5: 3·(−5) = −15 ✓, 3 + (−5) = −2 ✓. **Корни: 3 и −5.**

**Ловушка (сказать вслух).** Этот способ подбора работает быстро только для целых корней с не слишком большими числами; если за 20–30 секунд пара не находится — переходить на формулу с дискриминантом (шаг 4), а не тратить время на подбор дальше.

### Шаг 8. Квадратный трёхчлен и его разложение на множители

**Суть.** Выражение ax² + bx + c без знака «= 0» (просто выражение, не уравнение) называется квадратным трёхчленом. Если у него есть корни x₁ и x₂, трёхчлен можно разложить на множители через эти корни — и это разложение используется дальше в неравенствах методом интервалов (М21) и в сокращении дробей.

**Наглядно.** Показать на уже решённом уравнении: «если x² − 5x + 6 = 0 имеет корни 3 и 2, то сам трёхчлен x² − 5x + 6 равен произведению (x − 3)(x − 2) — подставим x = 3: получится 0, и подставим x = 2: тоже 0 — всё верно, в этих точках трёхчлен действительно равен нулю».

**Правило.**
> ax² + bx + c = a(x − x₁)(x − x₂), где x₁, x₂ — корни уравнения ax² + bx + c = 0 (D ≥ 0). Если a ≠ 1, коэффициент a обязательно остаётся множителем перед скобками — его нельзя «забыть» или распределить только в одну скобку.

**Мини-пример.** 2x² − 2x − 4 = 0: по формуле (или подбором: сумма 1, произведение −2 → числа 2 и −1) корни x₁ = 2, x₂ = −1. Разложение: 2x² − 2x − 4 = 2(x − 2)(x − (−1)) = 2(x − 2)(x + 1). Проверка обратным раскрытием: 2(x − 2)(x + 1) = 2(x² − x − 2) = 2x² − 2x − 4 — совпало.

**Ловушка (сказать вслух).** Самая частая ошибка — забыть множитель a перед скобками, когда a ≠ 1: пишут 2x² − 2x − 4 = (x − 2)(x + 1) без двойки снаружи. Проверка обязательна: раскрыть скобки и сравнить со старшим коэффициентом исходного трёхчлена — если он не совпал, множитель a потерян.

### Чего сейчас не объясняем

- Квадратные неравенства и метод интервалов — отдельная тема М21, там именно разложение трёхчлена из шага 8 становится основным инструментом.
- Уравнения, сводящиеся к квадратному через замену переменной (биквадратные, дробно-рациональные) — темы М20 и М22, М24; там появляется техника замены, а решается получившееся уравнение уже по этой карточке.
- Квадратичная функция, её график (парабола) и то, как дискриминант связан с числом точек пересечения с осью x — тема М31, следующий блок (там дискриминант получает геометрический смысл).
- Уравнения с параметром (при каком значении параметра корень уравнения равен заданному числу и т. п.) — отдельно не тренируем на уровне «база», это материал для роста к 70+ баллам.
- Комплексные корни при D < 0 — вне программы ЦТ, для таких уравнений просто говорим «действительных корней нет».

## Опорный конспект

| Случай | Правило | Пример |
|---|---|---|
| Стандартный вид | ax² + bx + c = 0, a ≠ 0 | 3x² − 5x + 2 = 0: a=3, b=−5, c=2 |
| Неполное, c = 0 | ax² + bx = 0 → x(ax+b) = 0 → x=0 или x=−b/a | x² − 7x = 0 → x=0 или x=7 |
| Неполное, b = 0 | ax² + c = 0 → x² = −c/a → x = ±√(−c/a) | x² − 16 = 0 → x = ±4 |
| Дискриминант | D = b² − 4ac | x²−5x+6=0 → D=1 |
| Число корней | D>0 — два; D=0 — один; D<0 — нет | D=1>0 → два корня |
| Формула корней | x = (−b ± √D) / (2a) | x²−5x+6=0 → x=3 или 2 |
| Приведённое уравнение | x² + px + q = 0 (a=1) | x²−5x+6=0: p=−5, q=6 |
| Теорема Виета (приведённое) | x₁+x₂ = −p;  x₁x₂ = q | x²−5x+6=0: сумма 5, произв. 6 |
| Теорема Виета (общее) | x₁+x₂ = −b/a;  x₁x₂ = c/a | 3x²−12x+5=0: сумма 4, произв. 5/3 |
| Разложение трёхчлена | ax²+bx+c = a(x−x₁)(x−x₂) | 2x²−2x−4 = 2(x−2)(x+1) |

**Алгоритм решения квадратного уравнения (в этом порядке):**
1. Привести к стандартному виду ax² + bx + c = 0.
2. Проверить, не неполное ли оно (b = 0 или c = 0) — тогда решать быстрым способом из шага 2, не считая дискриминант.
3. Если уравнение полное и коэффициенты целые небольшие — попробовать устно подобрать корни по обратной теореме Виета (10–20 секунд).
4. Если подбор не даётся — посчитать D = b² − 4ac.
5. По знаку D сказать, сколько корней, и если D ≥ 0 — найти их по формуле.
6. Проверить корни подстановкой в исходное уравнение.

**Образец оформления.** Решить уравнение: 2x² + x − 6 = 0.
1) a = 2, b = 1, c = −6.
2) D = 1² − 4·2·(−6) = 1 + 48 = 49.
3) √D = 7. x = (−1 ± 7) / 4.
4) x₁ = (−1 + 7)/4 = 6/4 = 1,5;  x₂ = (−1 − 7)/4 = −8/4 = −2.
5) Проверка: 2·1,5² + 1,5 − 6 = 4,5 + 1,5 − 6 = 0 ✓; 2·(−2)² + (−2) − 6 = 8 − 2 − 6 = 0 ✓.
**Ответ: x = 1,5 или x = −2.**

## Разобранные примеры

### Пример 1 (уровень 1). Решите уравнение x² − 9 = 0

Неполное уравнение, b = 0: x² = 9 → x = ±3. **Ответ: x = 3 или x = −3.**

### Пример 2 (уровень 1). Решите уравнение x² − 7x = 0

Неполное уравнение, c = 0: выносим x: x(x − 7) = 0 → x = 0 или x − 7 = 0 → x = 7. **Ответ: x = 0 или x = 7.**

### Пример 3 (уровень 2). Решите уравнение x² − 7x + 12 = 0 по формуле

a = 1, b = −7, c = 12. D = (−7)² − 4·1·12 = 49 − 48 = 1. √D = 1. x = (7 ± 1)/2 → x₁ = 4, x₂ = 3. Проверка: 4² − 7·4 + 12 = 16 − 28 + 12 = 0 ✓. **Ответ: x = 4 или x = 3.**

### Пример 4 (уровень 2). Решите уравнение x² + 2x − 15 = 0 устным подбором по теореме Виета

p = 2, q = −15: ищем два числа с суммой −2 и произведением −15. Делители 15: 3 и 5, знаки должны быть разными (произведение отрицательно). Пробуем 3 и −5: 3 + (−5) = −2 ✓, 3·(−5) = −15 ✓. **Ответ: x = 3 или x = −5.**

### Пример 5 (уровень 3, формат части В — ответ целым числом). Корни x₁ и x₂ уравнения x² − 6x + 8 = 0. Найдите x₁² + x₂²

Не решаем уравнение до конца, а используем теорему Виета: x₁ + x₂ = 6, x₁x₂ = 8. По формуле квадрата суммы (тема М10): x₁² + x₂² = (x₁ + x₂)² − 2x₁x₂ = 6² − 2·8 = 36 − 16 = 20. **Ответ: 20.**

Для контроля: прямое решение даёт x = 4 и x = 2 (D = 36−32 = 4, √D = 2, x = (6±2)/2), и 4² + 2² = 16 + 4 = 20 — совпало.

### Пример 6 (уровень 3, формат ЦТ часть А — 5 вариантов ответа)

Сумма корней уравнения 3x² − 12x + 5 = 0 равна:

1) 4   2) −4   3) 12   4) 5/3   5) −5/3

**Решение.** a = 3, b = −12, c = 5. По теореме Виета сумма корней x₁ + x₂ = −b/a = −(−12)/3 = 12/3 = **4**. Верный вариант — 1).

**Разбор неверных вариантов (ловушки, подобранные под типичные ошибки):**
- 2) −4 — взяли b/a без смены знака: −12/3 = −4, забыв, что сумма равна именно −b/a, а не b/a;
- 3) 12 — забыли разделить на коэффициент a при x²: взяли −b = 12, но не поделили на 3;
- 4) 5/3 — посчитали не сумму, а произведение корней: c/a = 5/3;
- 5) −5/3 — посчитали произведение корней со знаком, который не нужен в этой формуле: −c/a = −5/3.

Ученику: эту задачу не нужно решать через дискриминант (D = 144 − 60 = 84, корень из 84 не круглое число) — теорема Виета даёт ответ за одно действие. Если корень из D не извлекается нацело, а спрашивают только сумму или произведение корней — это сигнал, что нужна теорема Виета, а не формула корней.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| Сокращают неполное уравнение на x и теряют корень | x² − 7x = 0 «=» x − 7 = 0 → x = 7 (потеряли x=0) | Правило «на переменную делить нельзя, если не доказано, что она не равна нулю»; всегда выносить множитель, не сокращать |
| Теряют знак ± в уравнении x² = число | x² = 16 → x = 4 (забыли −4) | Проговаривать: «у положительного числа два квадратных корня, оба идут в ответ» |
| Путают знак в дискриминанте при отрицательном c | x²+3x−4=0: D «=» 9−16=−7 вместо 9+16=25 | Переписывать −4ac как отдельное слагаемое со своим знаком до сложения с b² |
| Забывают сменить знак b в числителе формулы корней | для b=−5 пишут x=(−5±√D)/(2a) вместо x=(5±√D)/(2a) | Проговаривать «минус b» вслух и сразу менять знак при подстановке, прежде чем считать |
| Путают сумму корней −b/a с b/a (теорема Виета) | для 2x²−6x+3=0 пишут сумму корней −6/2 = −3 (без смены знака) или 6 (без деления на a) вместо −(−6)/2 = 3 | Проверка на уже решённом примере: подставить найденные по формуле корни и сравнить сумму с −b/a |
