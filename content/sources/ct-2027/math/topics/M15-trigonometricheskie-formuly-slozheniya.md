# M15. Тригонометрические формулы сложения и двойного угла

## Зачем эта тема

**Тема изучается, только если план идёт с опережением.** В плане под неё нет урока (0 часов урока, 3 часа дома), а карта теста не связывает её напрямую ни с одной позицией ЦТ. Поэтому за этой темой не стоят «свои» баллы: она нужна для запаса, когда вся обязательная тригонометрия (M13, M14) уже держится уверенно. Польза — в преобразованиях: формулы сложения позволяют найти синус и косинус «нетабличных» углов (15°, 75°) и свернуть громоздкое выражение в одно табличное значение. Если ученик отстаёт от плана, тему пропускаем без потерь.

Для ученика: *«Это бонус. Две формулы, и длинное выражение схлопывается в sin30°»*.

## Результат: после темы ученик умеет

- [ ] объяснить, почему sin(α + β) ≠ sinα + sinβ (sin(30° + 60°) = 1, а sin30° + sin60° ≈ 1,37);
- [ ] записать по памяти sin(α ± β) и cos(α ± β) и найти sin75°, cos15° через 45° и 30° (оба равны (√6 + √2)/4);
- [ ] узнать «развёрнутую» формулу и свернуть её (sin50°cos10° + cos50°sin10° = sin60° = √3/2);
- [ ] применить формулы двойного угла по известным sinα и cosα (sinα = 3/5, cosα = 4/5 → sin2α = 24/25, cos2α = 7/25) и выбрать вид cos2α, если известна одна функция (cosα = 1/3 → cos2α = 2·1/9 − 1 = −7/9);
- [ ] получить целый ответ в формате части В (25sin2α при sinα = 3/5, α во II четверти → −24).

## Теория: сценарий объяснения

### Шаг 1. Синус суммы — не сумма синусов

**Суть.** Хочется «раскрыть скобки»: sin(α + β) = sinα + sinβ. Это неверно, и проверить можно за 10 секунд на табличных углах.

**Наглядно.** На доске две колонки: слева sin(30° + 60°) = sin90° = 1, справа sin30° + sin60° = 1/2 + √3/2 ≈ 1,37. Синус вообще не бывает больше 1 — значит, правая колонка заведомо не синус угла.

> **Правило.** Синус и косинус — не множители, скобку «раскрыть» нельзя. Для суммы углов есть свои формулы.

**Мини-пример.** cos(60° − 60°) = cos0° = 1, а cos60° − cos60° = 0.

### Шаг 2. Косинус суммы и разности

**Суть.** Косинус «любит одинаковых»: перемножаем косинус с косинусом, синус с синусом, а знак между ними — противоположный знаку в скобке.

**Наглядно.** Записать формулу и стрелками соединить cos–cos и sin–sin; знак в скобке обвести и перечеркнуть, рядом написать обратный.

> **Правило.** cos(α + β) = cosα·cosβ − sinα·sinβ;  cos(α − β) = cosα·cosβ + sinα·sinβ

**Мини-пример.** cos(60° + 30°) = 1/2 · √3/2 − √3/2 · 1/2 = 0 = cos90°. Формула проверена на известном угле.

### Шаг 3. Синус суммы и разности

**Суть.** Синус «любит разных»: синус на косинус плюс косинус на синус, знак — тот же, что в скобке.

**Наглядно.** Схема «sin·cos ± cos·sin»: первым всегда стоит синус первого угла.

> **Правило.** sin(α + β) = sinα·cosβ + cosα·sinβ;  sin(α − β) = sinα·cosβ − cosα·sinβ

**Мини-пример.** sin75° = sin(45° + 30°) = √2/2 · √3/2 + √2/2 · 1/2 = (√6 + √2)/4.

### Шаг 4. Свернуть формулу обратно

**Суть.** В задачах формулу чаще дают уже «развёрнутой», а её надо узнать и свернуть в один синус или косинус. Признак: два произведения, в каждом те же два угла.

**Наглядно.** Подчеркнуть, кто с кем перемножен: sin·cos + cos·sin → синус суммы; cos·cos + sin·sin → косинус разности.

> **Правило.** Видишь sin·cos ± cos·sin — это sin(α ± β). Видишь cos·cos ∓ sin·sin — это cos(α ± β).

**Мини-пример.** cos70°cos10° + sin70°sin10° = cos(70° − 10°) = cos60° = 1/2.

### Шаг 5. Двойной угол

**Суть.** Двойной угол — это сумма α + α. Подставляем β = α в формулы шагов 2–3, ничего нового учить не нужно.

**Наглядно.** На доске: sin(α + α) = sinα cosα + cosα sinα = 2sinα cosα. Для косинуса — так же, а потом заменяем cos²α или sin²α через основное тождество.

> **Правило.** sin2α = 2sinα·cosα;  cos2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α.

Знаешь только cosα — бери 2cos²α − 1; знаешь только sinα — 1 − 2sin²α. Формулы читаются и справа налево: 2sinα·cosα → sin2α, cos²α − sin²α → cos2α.

**Мини-пример.** sinα = 3/5, cosα = 4/5: sin2α = 2 · 3/5 · 4/5 = 24/25; cos2α = 16/25 − 9/25 = 7/25. Обратно: 2sin15°cos15° = sin30° = 1/2.

### Чего сейчас не объясняем

- Тангенс суммы и двойного угла — громоздкие и редкие, для нашего ученика не окупаются.
- Половинный угол, понижение степени, суммы в произведение — выше нашей цели. Уравнения с двойным углом — только после уверенных простейших уравнений M14.

## Опорный конспект

| Формула | Как запомнить | Пример |
|---|---|---|
| sin(α ± β) = sinα cosβ ± cosα sinβ | «синус любит разных», знак тот же | sin75° = (√6 + √2)/4 |
| cos(α ± β) = cosα cosβ ∓ sinα sinβ | «косинус любит одинаковых», знак обратный | cos15° = (√6 + √2)/4 |
| sin2α = 2sinα cosα | сумма α + α | 2sin15°cos15° = 1/2 |
| cos2α = cos²α − sin²α = 2cos²α − 1 = 1 − 2sin²α | вид выбираем по тому, что дано | cosα = 1/3 → cos2α = −7/9 |

**Алгоритм «свернуть».** 1) Найти два произведения с одними и теми же углами. 2) Определить шаблон (sin·cos или cos·cos). 3) Записать один синус или косинус суммы/разности. 4) Взять табличное значение. 5) Умножить на коэффициент перед скобкой.

| Вопрос | Ответ |
|---|---|
| sin(α + β) | sinα cosβ + cosα sinβ |
| cos(α + β) | cosα cosβ − sinα sinβ |
| sin2α | 2sinα cosα |
| cos2α через cosα | 2cos²α − 1 |
| cos2α через sinα | 1 − 2sin²α |
| sin75° = cos15° | (√6 + √2)/4 |

## Разобранные примеры

### Пример 1 (уровень 2). Вычислите 8(sin20°cos10° + cos20°sin10°)

Шаблон sin·cos + cos·sin → sin(20° + 10°) = sin30° = 1/2. Тогда 8 · 1/2 = 4. **Ответ: 4.**

### Пример 2 (уровень 3, формат части В). sinα = 3/5, α во II четверти. Найдите 25sin2α

1) cos²α = 1 − 9/25 = 16/25; во II четверти косинус отрицателен → cosα = −4/5. 2) sin2α = 2 · 3/5 · (−4/5) = −24/25. 3) 25 · (−24/25) = −24. **Ответ: −24.**

### Пример 3 (уровень 2, формат части А)

Значение выражения 6cos²15° − 6sin²15° равно:

1) 6 2) 3 3) 3√3 4) 6√3 5) 3√2

**Решение.** 6(cos²15° − sin²15°) = 6cos30° = 6 · √3/2 = 3√3. **Ответ: 3.**

**Разбор неверных вариантов.** 1) 6 — спутал с основным тождеством (там плюс, а не минус); 2) 3 — взял sin30° вместо cos30°; 4) 6√3 — решил, что cos30° = √3; 5) 3√2 — взял cos45°, то есть не удвоил угол, а прибавил 30°.

## Типичные ошибки

| Ошибка | Пример | Как предупредить и проверить |
|---|---|---|
| «Раскрывает скобку» | sin(30° + 60°) = sin30° + sin60° | Проверка на табличных углах: синус больше 1 не бывает |
| Путает знак в косинусе | cos(α + β) = cosα cosβ + sinα sinβ | «Косинус — знак обратный»; проверить на cos(60° + 30°) = 0 |
| Забывает двойку | sin2α = sinα cosα | Проверка: sin60° = 2 · √3/2 · 1/2 = √3/2 |
| Путает cos2α с тождеством | cos²α − sin²α = 1 | «Плюс — единица, минус — косинус двойного» |
| Теряет знак по четверти | α во II четверти, а cosα = 4/5 | Перед формулой записать знаки sin и cos по четверти |
